プレミアム課金機能

買い切りIAP（¥480・非消耗型）。v1.5.0 で「広告除去」から商品内容を差し替え

v1.5.0機能ID: PZ-FEAT-SK

提供商品

項目内容
商品名プレミアム（買い切り）
Product IDcom.happyboy1002.BlockPuzzle.removeAds
形式非消耗型・買い切り（¥480）
Family Sharing対応
Product ID は v1.5.0 でも変更していない。 据え置いた理由は既存購入者の権利を確実に引き継ぐため。新 Product ID にすると既存購入者が特典を失うか、移行処理が必要になる。 そのため既存購入者は追加課金なしで自動的に新特典を得る。 ID 名に removeAds が残っているのは歴史的経緯であり、現在の商品内容は「広告除去」ではない。

特典無料プレミアム

商品内容の変遷

版商品内容背景

ユーザーから見た挙動

購入

  1. 設定画面の「プレミアムを購入する」、またはゲーム終了画面の訴求リンク、または限定テーマのタップから Paywall 画面へ遷移する
  2. Paywall で購入ボタンを押すと、システム標準の購入シートが表示される
  3. 購入が完了すると成功表示が出て、約2秒後に Paywall が自動で閉じる
  4. 戻った直後からプレミアム特典が反映される（限定テーマの鍵が外れ、アンドゥ残数が ∞ になる）

復元

  • 設定画面および Paywall の「購入を復元」からいつでも復元できる
  • 機種変更・再インストール後も、同じ Apple ID であれば特典が復帰する
  • 他端末での購入や Family Sharing による購入も自動的に反映される

購入状態の表示

状態設定画面の表示
未購入「プレミアムを購入する」＋「購入を復元」
購入済み「プレミアム購入済み」（購入導線は非表示）

ビジネスルール

  • 買い切りのため月額課金は発生しない。一度の購入で永続利用できる
  • Product ID は変更しない。既存購入者は自動的にプレミアム特典を得る
  • 既存7テーマは今後も全ユーザー無料。後から有料化しない
  • プレミアム購入者にはアンドゥの広告視聴を一切要求しない
  • 将来広告を導入した場合も、購入者には広告を表示しない（購入時の保証）
  • 復元はいつでも可能。未購入でも全機能の基本プレイは制限しない

エラー処理

発生条件ユーザーに見える対応
商品情報の取得に失敗エラーアラートを表示。購入は行われない
購入がキャンセル・失敗エラーアラートを表示し、購入前の状態を保つ（特典は付与しない）
復元で対象の購入が見つからないエラーアラートを表示。未購入状態のまま継続利用できる
購入検証・トランザクション処理などの内部実装詳細は本仕様書では扱わない（意図的に非記載）。
