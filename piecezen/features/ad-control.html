広告制御機能

広告配信は v1.5.0 で恒久停止（AdEnvironment による環境判定）

v1.5.0機能ID: PZ-FEAT-AD
現状: 広告は一切配信されていない。 2026-07-30、利用していた広告アカウントが「無効なトラフィック」を理由に恒久的に無効化され、再審査請求も却下された。 広告収益は永久にゼロであるため、AdEnvironment.isAdDeliveryAvailable = false として全広告を停止している。 別の広告ネットワークを導入するまでこの状態を維持する。

広告環境の判定（AdEnvironment）

判定内容
isAdDeliveryAvailable 広告配信が利用可能か。v1.5.0 では false 固定。広告に関わる全挙動の単一停止スイッチとして機能する
isProduction 本番の広告ユニットIDを使ってよい環境か。App Store 配信版のみ true。DEBUG ビルド・シミュレーター・TestFlight はすべて Google 公式のテスト広告IDを使う。判定は App Store レシートが sandboxReceipt かどうかで行う

本番広告を開発者自身が表示・タップすることがアカウント無効化の直接原因になり得るため、 広告表示の動作確認は必ずテスト広告で行い、本番広告は App Store 配信版でのみ配信する運用に改めた。

具体的な広告ユニットIDおよびパブリッシャー識別子は本仕様書には記載しない（コード側で管理する）。

広告構成と停止中の挙動

種類本来の表示タイミング配信停止中（v1.5.0 の現状）
バナー ゲーム画面下部に常時（未購入時のみ） 枠ごと非表示。高さ0ではなくビュー自体を配置しないため、盤面下に余白が残らない
インタースティシャル 3ゲームに1回、最低90秒間隔（未購入時のみ） 呼び出さない。広告リクエストも発生しない
リワード（もう1手 / アンドゥ追加） ゲーム終了時の救済・アンドゥ2回目以降 広告を挟まず報酬を即付与。1ゲームあたりの上限回数は維持

付随して停止するもの

対象停止中の挙動理由
トラッキング許可（ATT）ダイアログ 表示しない トラッキング許可は広告目的でしか求めていない。広告がない状態で許可を求めると「求める理由がない」状態になり審査リスクにもなる
広告SDKの初期化 行わない 広告リクエストを一切発生させないため

アプリ起動時の計測ログは、広告の有無とは独立して従来どおり実行する。

UI 文言への影響

箇所広告配信中の表記配信停止中の表記（現状）
ゲーム終了画面のリワードボタン広告を見てもう1手無料でもう1手（アイコンも gift.fill に変化）
アンドゥボタン（無料回数を使い切った後）戻す (広告)戻す

いずれも isAdDeliveryAvailable による分岐で、広告を再開すれば元の表記に戻る設計にしている。

ビジネスルール

  • 広告配信が停止している間は、広告枠を一切表示せず、広告リクエストも発生させない
  • リワードで与えていた報酬は広告なしで即付与する。ただし1ゲームあたりの上限回数は維持する
  • プレミアム購入者には広告を表示しない。将来別の広告ネットワークを導入した場合も表示しない（購入時の保証）
  • プレミアム購入者にはアンドゥの広告視聴を一切要求しない（アンドゥ無制限が特典のため）
  • 本番の広告ユニットIDを使うのは App Store 配信版のみ。それ以外の環境では必ずテスト広告IDを使う
  • 撮影モード（スクリーンショット自動撮影）では広告・ATT・計測をすべて抑止する
