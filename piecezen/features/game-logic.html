ゲームロジック

配置・消去・スコア・コンボ・ボーナスタイム・ゲームオーバー判定

v1.5.3機能ID: PZ-FEAT-LOGIC

グリッドサイズ

8×8（64マス、GridPosition で管理）

配置ルール

  • BlockShape.cells(at: anchor) で配置先セル群取得
  • すべてのセルが .empty かつグリッド範囲内なら有効
  • 配置時に grid[row][col] = .filled(blockColor)
  • 1マス = 1点（配置スコア）

タップで置くときの位置（v1.5.2〜）

タップで置く操作（ピースを選ぶ → マスをタップで仮置き → もう一度タップで置く。ゲーム画面参照）では、タップしたマスをピースのどのマスで覆うかを次の順に試し、最初に置ける位置を採用する。

  1. ピースを構成するマスを「上の段から、同じ段では左から」の順に並べる
  2. その順に「そのマスがタップしたマスに重なる位置」を置き場所の候補にする（先頭は、ピースの一番上の段の左端のマスがタップしたマスに来る位置）
  3. 候補のうち、盤面に収まり、すべて空きマスに乗るものを採用する。1つもなければ「ここには置けません」
  • どの候補を選んでも、タップしたマスは必ずピースで埋まる。＋・逆T・Z など左上が空いている形でも、タップしたマスがずれない
  • 盤面の端や、埋まったマスの隣をタップしても、収まる位置へずらして仮置きする

ドラッグで置くときは、運んでいるピースの見た目の位置から最も近いマスに合わせる（v1.5.2〜。詳細は ゲーム画面）。

スコア計算

項目得点
配置（1マス）+1
ライン消去（基本）20 × ライン数 × 連鎖の倍率（倍率は下表）
同時消しの加点: 十字（行と列を同時）+150（最優先。十字なら本数によらずこの加点のみ）
同時消しの加点: 4ライン以上+200
同時消しの加点: 3ライン+80
同時消しの加点: 2ライン+30
全消し（盤面が空になる）+1000（v2.0 で +500 から変更）。ボーナスタイム中の全消しは加点しない（v1.5.3〜。下記「ボーナスタイム」）

ボーナスタイム中は、基本点の「連鎖の倍率」がボーナスの倍率（×2〜×5）に置き換わる（v1.5.3〜）。同時消しの加点はそのまま加える。

連鎖の倍率

連鎖数倍率
1以下×1
2×2
3×4
4以上×8（上限）

例: 連鎖3で2ラインを消した場合 = 20 × 2 × 4 + 30 = 190点（＋置いたマス数）。

v1.0 の本表からの訂正（2026-09-29）: 基本点を「20 × ライン数 × max(1, comboCount)」、全消しを「+500」と記載していたが、実装と合っていなかった。 実装は倍率が 1→2→4→8 と倍々で上がり（上限 ×8）、全消しは v2.0 で +1000 に変更済み。本表は v1.5.2 の実装（GameEngine の updateScore・comboMultiplier・finalizePlacement）に合わせた。

コンボシステム（連鎖）

v1.5.3 の仕様（v1.5.2 までは、ラインが消えない手を1回置いただけで連鎖が 0 に戻っていた）。

  • ピースを置いてラインが消えたら、連鎖数（comboCount）を +1 し、見逃した回数（comboMissCount）を 0 に戻す
  • ラインが消えない手は1回だけ見逃す（GameEngine.comboGraceMoves = 1）。消えない手を置くと見逃した回数を +1 し、2回続けて消えなかったら連鎖数は 0 に戻る。連鎖数が 0 のときは数えない
  • 見逃した後（次に消えない手を置くと切れる状態）は、スコア欄の「コンボ」の見出しが「あと1手で切れる」に変わる（isComboAboutToBreak。ゲーム画面参照）
  • スコア欄の連鎖数は、1回消した時点（連鎖1）から表示する（v1.5.2 までは連鎖2から）
  • 連鎖2以上で倍率表示（×2・×4・×8）と、1ライン消しのときは褒め言葉（いいね！・すごい！・お見事！）を出す
  • ハプティクスは連鎖数に応じて段階化。効果音は連鎖の段階で音程が上がる（サウンド参照）
  • アンドゥで1手戻すと、連鎖数と見逃した回数の両方が戻す前の値に戻る
見逃しを入れた理由: 手持ち3個のうち1個を次の消去の仕込みに使うだけで連鎖が切れていたため、2連鎖以上にほとんど届かなかった。

ボーナスタイム（v1.5.3〜）

ラインを消してゲージをためると入る、時間制限つきの特別な盤面。制限時間の中で、用意された盤面を何回全消しできるかを競う。

ゲージ

  • ラインを1本消すごとに1目盛りたまる（同時消しは本数分）。満タンは 8目盛り（bonusGaugeCapacity）で、それ以上はためない
  • 満タンになったら、消去の演出が終わった後にボーナスタイムへ入る
  • 満タンからボーナスタイムに入るまでの間は、アンドゥできない（戻す前にボーナスタイムに入ってしまうため）
  • アンドゥで1手戻すと、ゲージも戻す前の値に戻る
  • ボーナスタイム中の消去は、ゲージにも最大コンボの記録（統計）にも数えない

流れ

  1. 入る: いまの盤面・手持ち・連鎖を保存し、型の盤面（下記）と3個のピースに切り替える。入る演出（1.4秒）の間は時計を止める
  2. 盤面を解く: 3個を置き切るか、残りのピースがどこにも置けなくなったら（回転も含めて判定）、その盤面は終わり。手持ちの補充とゲームオーバー判定はしない
  3. 次の盤面へ: 全消しできていれば倍率が1つ上がる。全消しできなくても次の盤面へ進む（倍率は据え置き）。盤面の切り替え（0.9秒）の間は時計を止める
  4. 時間切れ: まとめ（1.8秒）を見せてから、ボーナス前の盤面・手持ち・連鎖に戻す。ボーナスタイムでゲームオーバーにはならない。戻した盤面でゲームオーバー判定だけ行う

ボーナスタイムが終わるのは時間切れのときだけ。盤面を置き終えた時点で残りが1秒未満なら、次の盤面を出さずにそのまままとめへ進む（bonusMinimumTimeForNextBoard）。

制限時間と時計

項目仕様
制限時間15秒（bonusTimeLimit。実機での調整を前提とした初期値）
時計が止まる間入る演出・消去の演出（盤面が実際に空くまで）・盤面の切り替え・時間切れのまとめ・アプリが前面にない間（コントロールセンター・通知・ホームへ戻る）
残りわずかの合図残り3秒から1秒ごとに効果音と軽い振動

倍率と得点

盤面倍率
1枚目×2
全消し1回の後×3
全消し2回の後×4
全消し3回以上の後×5（上限。bonusMaxMultiplier）
  • ライン消去の基本点は 20 × ライン数 × ボーナスの倍率。同時消しの加点（十字・2〜4ライン）はそのまま加える。ボーナスタイムで得られる点に上限はない
  • 置いたマスの点（1マス1点）も通常どおり入る
  • ボーナス中の全消しは +1000 にしない（ごほうびは「次の盤面」と「倍率」）。通常の全消しで出る2秒のスローモーション演出も出さず、揺れ・振動・効果音だけにする
  • ボーナス中は連鎖の表示（スコア欄の連鎖数・倍率のポップアップ）を出さない。連鎖数そのものは1枚ごとに 0 から数え直し、効果音の音程が上がる流れに使う

ボーナス中の操作

  • アンドゥ不可。回転は可
  • 演出の最中（入る・盤面の切り替え・時間切れのまとめ）は、置く・回す・タップでの仮置きを受け付けない（isBonusInputLocked）

盤面の型（BonusTemplate）

  • 8×8 の盤面と、置けば必ずラインが消える3個のピースの組。3個を正しい場所に置くと最後に全消しになるように作ってある。置き場所は光らせず、ピースと同じ形の隙間を自分で見つける
  • 型は 24。回転4通り × 左右反転2通りの変化形からランダムに出す
  • 難しさは3段。分析ツールで手順を総当たりし、「毎回いちばん多く消える手を選んだときに全消しになる割合」で分けた
難しさ基準型の数出す盤面
素直（easy）毎回いちばん多く消える場所に置けば必ず全消し81〜2枚目
中くらい（medium）一度に多く消える置き方の一部が全消しを逃す（全消しになる割合3〜5割）83〜4枚目
罠あり（hard）一度に多く消える置き方を選ぶと必ず全消しを逃す（0%）85枚目から

同じボーナスタイムで使った型は、その段を使い切るまで出さない。使い切ったら隣の段（1〜2枚目は中くらい、3〜4枚目は素直、5枚目からは中くらい）から出し、それも使い切ったら同じ型を再び出す。

ゲームオーバー判定

トレイ内の全ブロックが「どの回転状態でも」配置不可なら gameOver。 GameEngine.canPlace(block:) が4回転すべてを試す（フェアネス設計）。

トレイ補充

  • 3ブロック全消費で refillTray() → BlockShape.generateTray()
  • フェアネス: 1トレイに5マス以上ブロックは最大1個

アンドゥ

  • UndoSnapshot で grid/blocks/score/comboCount をキャプチャ。v1.5.3 から連鎖の見逃し回数（comboMissCount）とボーナスのゲージ（bonusGauge）も含める
  • 新手を配置すると snapshot が上書き → 1手のみ復元可
  • 使えない場面（v1.5.3〜）: ボーナスタイム中／ゲージが満タンでボーナスタイムに入る直前／ボーナスタイムから戻った直後／「もう1手」で手持ちを入れ替えた直後
ユーザー区分1ゲームあたりの回数広告視聴
無料3回（v1.4 から変更なし）広告配信中は2回目以降に必要。配信停止中（v1.5.0 の現状）は不要
プレミアム購入者無制限（★ v1.5.0 特典）一切要求しない

「もう1手」（ゲーム終了後の救済）

  • ゲーム終了画面から使用し、手持ちを、いまの盤面に置けるピースを1個以上含む3個に入れ替えてプレイを継続する（v1.5.3〜。rescueWithReward）
  • 入れ替えた3個のうち1個は、いまの盤面に置ける形から選ぶ（空きマスがあれば1マスのピースは必ず置けるので、必ず続けられる）。残り2個は通常の補充と同じく、5マス以上のピースは1個まで
  • 入れ替えた後は「ピースを入れ替えました」と表示する。入れ替えの後はアンドゥできない（ゲームオーバー前の手に戻すと、入れ替えた手持ちまで元に戻るため）
  • 広告配信停止中は広告を挟まず報酬を即付与するが、1ゲームあたりの上限回数は維持する
  • 上限に達するとボタン自体が表示されなくなる
ユーザー区分1ゲームあたりの回数
無料1回（v1.4 から変更なし）
プレミアム購入者3回（★ v1.5.0 特典）
v1.5.2 までの方式: 埋まっているマスをランダムに1マス消すだけで、手持ちが置けるようになるかを見ていなかった。続けられたのはゲームオーバーの約14%で、残りは同じ手持ちのまますぐゲームオーバーに戻っていた。

プレイ記録と広告の数え方（v1.5.3〜）

  • プレイ記録（StatRecord）は1ゲーム1件。最初のゲームオーバーで記録を作り、「もう1手」で続けた後のゲームオーバーでは新しく足さずに同じ記録の点・最大コンボを更新する
  • 「もう1手」で続けている間は、置くたびに記録の点を更新する（2回目のゲームオーバーの前に画面を離れても、伸びた点が残る）
  • 広告の表示間隔に使うゲーム数のカウント（AdManager.gameCount）も、1ゲームにつき1回だけ数える
  • v1.5.2 までは、ゲームオーバーのたびに記録を足していたため、「もう1手」で続けたゲームが2回数えられ、統計のプレイ回数が多く出ていた
