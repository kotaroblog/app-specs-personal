ハプティクス機能（HapticManager）

UIFeedbackGenerator

v1.5.3機能ID: PZ-FEAT-HAPTIC

API

final class HapticManager {
    var isEnabled: Bool   // UserDefaults "isHapticEnabled"（未設定なら true）

    func blockPlaced()
    func selectionChanged()            // v1.5.2〜
    func lineCleared()
    func linesCleared(count: Int, isCross: Bool)
    func comboCleared(level: Int)
    func invalidAction()
    func perfectClear()
    func gameOver()
    func highScoreUpdated()
}

GameEngine がインスタンスを1つ持ち（engine.haptic）、画面からもこれを使う（シングルトンではない）。

振動パターン

イベント振動鳴らす場面
blockPlacedimpact（light）ピースを置いた・回転した・アンドゥした
selectionChanged（v1.5.2〜）selection（UISelectionFeedbackGenerator）タップで置く操作でピースを選んだ・仮置きした（置いたときの振動と区別できる軽い手応え）。v1.5.3〜 ボーナスタイムの残り3秒から1秒ごと
linesCleared（1ライン）impact（medium）1本消した
linesCleared（2ライン）impact（medium）2本同時に消した
linesCleared（3ライン）notification.success3本同時に消した
linesCleared（4ライン以上）impact（heavy）→ 0.08秒後に heavy4本以上同時に消した
linesCleared（十字）impact（heavy）→ 0.06秒後に rigid行と列を同時に消した（最優先）
comboCleared（連鎖2）impact（medium）連鎖2で消した（通常時のみ）
comboCleared（連鎖3）notification.success連鎖3で消した（通常時のみ）
comboCleared（連鎖4以上）impact（heavy）→ 0.08秒後に rigid連鎖4以上で消した（通常時のみ）
invalidActionnotification.warning置けない場所に離した・タップで仮置きできなかった
perfectClearheavy → success → heavy → rigid（間隔 0.12〜0.18秒）全消し。v1.5.3〜 ボーナスタイム中の全消しでも鳴らす
gameOvernotification.errorゲームオーバー
highScoreUpdatednotification.success → 0.2秒後に impact（heavy）初めてハイスコアを超えた。v1.5.3〜 ボーナスタイムに入るとき・時間切れのときにも使う

ボーナスタイムの振動（v1.5.3〜）

場面振動
ボーナスタイムに入るhighScoreUpdated
ボーナス中の全消しperfectClear（点の加算はなく、次の盤面と倍率がごほうび）
残り3秒・2秒・1秒selectionChanged（1秒に1回。効果音 sfx_bonus_tick と同時）
時間切れhighScoreUpdated

流れと時計の止まる条件は ゲームロジック の「ボーナスタイム」、音は サウンド を参照。

制御

設定画面の「ゲーム」の「ハプティクス」トグルで有効/無効を切り替える。値は UserDefaults のキー isHapticEnabled に保存し、未設定なら有効。無効のときはどのイベントでも何もしない。
