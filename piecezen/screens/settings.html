限定テーマのロック仕様

状態表示タップ時の挙動
未購入 一覧に鍵アイコン付きで表示。プレビュー色は不透明度 45% に落ち、テーマ名も控えめな文字色になる Paywall 画面へ遷移する。テーマは選択されない
購入済み 無料テーマと同じ表示（選択中はチェックマーク） 通常どおり選択・即適用される

ロック中の行は支援技術に対して「（テーマ名）（プレミアム限定）」と読み上げ、「プレミアム購入画面を開きます」というヒントを提供する。

限定テーマの色品質担保

追加した3テーマ × ブロック色12色 = 36ケースについて、空セル背景に対する WCAG 1.4.11 非テキストコントラスト 3:1 以上を自動テストで検証している。 初期案では和み・琥珀の indigo がそれぞれ 2.37:1 / 2.41:1 で基準未満だったため、明度を上げて是正済み。

見やすいモード（seniorContrast）の色仕様

「見やすいモード」は空セル背景との間で WCAG コントラスト比 3:1 以上を確保する高コントラストテーマ。v1.4.0 にて indigo / blue の明度を調整し、WCAG 基準への非準拠（コントラスト不足）を是正した。

色名旧 HSL新 HSL（v1.4.0〜）変更内容
indigohsl(250, 80%, 40%)hsl(250, 80%, 60%)明度を上げ、空セル背景に対し 3:1 以上を確保。見た目はやや明るいインディゴ〜ペリウィンクル寄りに変化
bluehsl(220, 95%, 45%)hsl(220, 95%, 50%)明度を微調整し基準を充足

テーマカード選択時のCTAボタンデザインは全画面共通仕様を適用（→ ゲームオーバー画面 CTAボタン仕様 参照）。

プレミアムセクション（v1.5.0〜）

箇所変更前（v1.4 まで）変更後（v1.5.0〜）
セクション名広告除去プレミアム
購入導線広告を除去するプレミアムを購入する
購入済み表示広告除去済みプレミアム購入済み

購入済みの場合は購入導線を表示せず、「プレミアム購入済み」の表示のみになる。 商品は買い切り（¥480）で、Product ID は v1.5.0 でも変更していないため、既存購入者は追加課金なしで新特典を得る。

実装メモ

  • @AppStorage で各設定値を直接バインド
  • テーマ変更時に GridView 自動再描画（BlockColor の動的参照）
  • ロック判定は ColorTheme.isPremiumOnly と StoreManager.isPremium の組み合わせ
  • ロック中の行は Button ではなく Paywall への NavigationLink として構成し、誤ってテーマが切り替わらないようにしている
