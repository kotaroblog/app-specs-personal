Paywall画面（PaywallView）

プレミアム（買い切り）の購入画面。フルスクリーンモーダル

v1.5.0画面ID: PZ-PAY-01

目的・役割

買い切りIAP「プレミアム」の価値を伝えて購入に導く画面。 v1.5.0 で商品内容が「広告除去」から「じっくり考えて遊ぶための特典」へ転換したため、訴求軸も全面的に差し替えた。

提供商品

商品Product ID形式
プレミアム（買い切り）com.happyboy1002.BlockPuzzle.removeAds非消耗型・買い切り（¥480）
Product ID は v1.5.0 でも変更していない（既存購入者の権利を確実に引き継ぐため）。 そのため既存購入者は追加課金なしで自動的に新特典を得る。

UI 構成

要素説明
ヘッダーアイコン深色基調 + テーマ accent
見出しラベル「プレミアム」＋ 主見出し 「じっくり考えて遊ぶ」＋ サブ「快適なプレイ体験をあなたに」
特典一覧4項目（下表）
価格表示買い切り価格。月額課金ではないことを明示

法的リンク利用規約・プライバシーポリシー

配色は深色基調に固定してテキストの視認性を確保する（テーマによらずダーク表示）。

見出しの変更（v1.5.0）

箇所変更前（v1.4 まで）変更後（v1.5.0〜）
主見出し広告を除去するじっくり考えて遊ぶ

広告が存在しなくなったため「広告を消す」訴求を廃し、「納得いくまで考えられる」という体験価値を主軸に変更した。

特典一覧（4項目・v1.5.0〜）

#特典説明文
1アンドゥが無制限何度でも戻せるので、納得いくまで考えられます
2「もう1手」が3回にゲーム終了後の復活が1回から3回に増えます
3限定テーマ3種和み・琥珀・若草。既存のテーマは今後も全員無料です
4一度の購入で永続利用月額課金なし。今後広告を導入しても表示されません
4つ目の「今後広告を導入しても表示されません」は、「広告除去」として購入した既存ユーザーへの保証を明文化したもの。 将来別の広告ネットワークを導入した場合でも、購入者には広告を表示しない。

3つ目に「既存のテーマは今後も全員無料です」と併記しているのは、 無料で提供していたテーマを有料化したのではないことを購入前に明確にするため。

遷移

操作遷移先

閉じる呼び出し元へ戻る

本画面への流入経路

  • 設定画面の「プレミアムを購入する」
  • 設定画面でプレミアム限定テーマ（未購入時）をタップ
  • ゲーム終了画面のプレミアム訴求リンク

エラー処理

発生条件ユーザーに見える対応
商品情報の取得に失敗エラーアラートを表示。購入は行われない
購入がキャンセル・失敗エラーアラートを表示し、購入前の状態を保つ
復元で対象の購入が見つからないエラーアラートを表示。未購入状態のまま継続利用できる

実装メモ

  • サブビュー構成（ヘッダー / 見出し / 特典 / 価格 / 価値比較 / 購入 / 復元 / 法的リンク）を維持
  • 購入状態の変化を検知して成功オーバーレイを出し、自動 dismiss する
  • 深色基調に固定（preferredColorScheme(.dark)）
購入検証・トランザクション処理などの内部実装詳細は本仕様書では扱わない（意図的に非記載）。
