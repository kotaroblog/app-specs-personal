UI 構成

要素説明

スコア表示現在スコア + ベストスコア
NEW BEST バッジ更新時のみ表示
「もう1手」ボタン残り回数がある場合のみ表示。無料は1回/ゲーム、プレミアムは3回/ゲーム

「もう1手」ボタン（v1.5.0〜）

項目広告配信中の仕様広告配信停止中（v1.5.0 の現状）
ラベル広告を見てもう1手無料でもう1手
アイコンplay.rectangle.fillgift.fill
挙動リワード広告を視聴後に救済広告を挟まず即救済

広告配信は v1.5.0 で恒久停止したため、現状は常に「無料でもう1手」として動作する。 ラベル・アイコン・挙動はいずれも広告配信可否による分岐で、広告を再開すれば元の仕様に戻る。

回数上限

ユーザー区分1ゲームあたりの上限
無料1回（v1.4 から変更なし）
プレミアム購入者3回（★ v1.5.0 のプレミアム特典）
広告なしで報酬を付与するようになっても、1ゲームあたりの上限回数は維持する。 上限に達するとボタン自体が表示されなくなる。

プレミアム訴求リンク（v1.5.0〜）

項目変更前（v1.4 まで）変更後（v1.5.0〜）
文言広告を除去して快適にプレイプレミアムでアンドゥ無制限・もう1手3回

未購入時のみ表示され、タップすると Paywall 画面をフルスクリーンで開く。

救済機能

「もう1手」を選択すると、ランダムで1セルを消去してゲームを継続する。残り回数を使い切るとボタンは表示されない。

CTAボタン デザイン仕様

本画面の主要CTAボタン（もう1手 / Restart）は、ストリーク報酬モーダル・チュートリアル・テーマ選択の計4画面で共通のボタンデザインを採用している。見た目の統一により画面間で一貫した操作感を実現する。

項目仕様
デザイン共通化対象ゲームオーバー / ストリーク報酬モーダル / チュートリアル / テーマ選択
枠線・LED ライン不透明度全画面で統一（旧ストリーク報酬ボタンの個別値を是正）
