記録カレンダー（DailyCalendarView）

日別ベストスコアの振り返りと、過去日デイリーへの入口

v1.4.0画面ID: CR-CAL-01Premium

目的・役割

デイリーチャレンジの日別ベストスコアを月表示で振り返る画面。 同時に、プレミアム特典である過去日デイリー（アーカイブ）のプレイ入口も兼ねる。 「記録の可視化」と「アーカイブの入口」を1画面に統合し、遊ばなかった日が視覚的に分かる状態から そのままプレイへ入れる導線にしている。

UI 構成

要素説明
累計サマリー「プレイした日」「最高スコア」「連続記録」の3タイル。全期間で集計
月ナビゲーション前月 / 次月ボタンと「YYYY年M月」表示。第1回の月より前・未来の月へは移動不可（ボタンは無効化＋淡色表示）
曜日ヘッダ日〜土。VoiceOver では読み上げ対象外
カレンダーグリッド7列。各セルに日付と、記録があればその日のベストスコアを表示
日付セル（記録あり）ベストスコアをアクセントカラーで表示。セル背景もアクセント寄りに強調
日付セル（未購入・プレイ可能な過去日）鍵アイコンを表示。タップでプレミアム購入画面へ
日付セル（本日）枠線で強調。日付を太字表示
日付セル（未来日）淡色表示・タップ不可
プレミアム訴求カード未購入時のみカレンダー下部に表示。「過去のデイリーに挑戦できます」→ タップで購入画面
閉じるボタンナビゲーションバー左。シートを閉じてゲーム画面へ戻る

状態

状態表示・挙動
プレミアム購入済みプレイ可能な過去日をタップ → その日のデイリーを開始（シートは閉じる）
未購入プレイ可能な過去日をタップ → プレミアム購入画面（sheet）。カレンダー下部に訴求カードを表示
本日 / 未来日アーカイブ対象外。タップしてもプレイは開始しない（未来日はタップ自体を無効化）

遷移

操作遷移先
ゲーム画面の「記録を見る」本画面（sheet）
過去日タップ（購入済み）本画面を閉じてゲーム画面でアーカイブ開始
過去日タップ（未購入）／訴求カードタッププレミアム購入画面（sheet）
「閉じる」ゲーム画面へ戻る

使用するデータ

データ用途
日別ベストスコア（日付キー別に保存）各セルのスコア表示・累計サマリーの集計
デイリーチャレンジの起算日（第1回の公開日）アーカイブ対象範囲の下限・月移動の下限
連続記録（ストリーク）サマリータイルの「連続記録」
プレミアム購入状態過去日のロック / アンロック判定

実装メモ

  • アーカイブ対象は「第1回の公開日以降・本日より前」。本日と未来日は対象外
  • 累計サマリーは起算日から本日までを走査し、記録がある日だけを対象に集計する
  • 月移動ボタンは範囲外で disabled にし、透明度でも無効を示す
  • 日付セルには VoiceOver 用ラベル（「M月D日、今日、ベストN、タップで挑戦」）を付与
  • 月移動ボタンのタップ領域は 44pt 以上を確保
  • アーカイブのプレイ結果はその日のベストのみ更新し、本日ベスト・累計完了数・連続記録には影響させない
