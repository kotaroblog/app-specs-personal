オンボーディング（OnboardingView）

初回起動時の4ステップチュートリアル（設定画面から再表示可）

v1.3画面ID: CR-ONB-01

説明1枚の構成（1.4.3〜・未公開）

以前は閉じられない4枚（WATCH / TAP / BEAT / おすすめ設定）で、遊び始めるまで約6タップかかっていた。1.4.3 から1枚にし、「はじめる」で 4パネル×NORMAL の1ゲームをすぐ始める。
要素内容
見出し「光った順にタップ」
図（OnboardingDiagramView）4パネルが 1→2→3 と光る図
説明光るパネルの順番を覚えて同じ順番でタップすること、成功するたびに1つずつ長くなること
補足最初は4パネル・NORMAL で始まり、パネル数と速さはあとで変えられること
ボタン初回は「はじめる」（4パネル×NORMAL の1ゲームを開始）。設定の「遊び方を見る」から開いたときは「閉じる」（ゲームを始めずに閉じるだけ）
スクロール小型端末・大きな文字でも画面外に出ないようスクロール可能

トラッキング許可（ATT）は遊ぶ前には出さず、初回の結果画面を閉じた後に出す（何のアプリか分からないまま判断させないため）。詳細は 画面遷移図・広告制御。初回の流れの進み具合は FirstRunState（単体テストあり）が持つ。

4ステップ構成（1.4.2 まで・記録として残す）

  1. WATCH — シーケンス観察の説明
  2. TAP — パネルタップ操作の説明
  3. BEAT — 速度加速ルールの説明
  4. おすすめ設定 — 「最初は4パネルとNORMALがおすすめです」のヒント

UI 構成

要素説明
TabView (PageStyle)4ページの順次遷移。コンテンツエリアはScrollView化（小型端末・大フォントサイズ対応）
アイコン各ステップのアイコンサイズ: 64pt（旧: 80pt）
「次へ」ボタン（ステップ1〜3）ScrollViewの外に固定配置。ホームインジケーター対応の余白あり（旧ラベル: 「NEXT」）
「はじめる」ボタン（ステップ4）ScrollViewの外に固定配置。タップで終了（旧ラベル: 「START PLAYING」）
interactiveDismissDisabledスワイプで閉じられない（初回起動時）

遷移

「はじめる」タップで hasSeenOnboarding = true → GameView

設定画面の「遊び方を見る」タップ → OnboardingView（sheet。この場合は interactiveDismissDisabled を適用しない）

実装メモ

  • 設定画面から再表示する場合は hasSeenOnboarding をリセットせず、sheet 表示のみ行う
  • 初回とリプレイでスワイプ閉じ禁止の挙動が異なるため、呼び出し元から allowDismiss フラグを渡す実装を推奨
  • コンテンツエリアを ScrollView 化し、SE（1st gen）等の小型端末・Dynamic Type 最大サイズでもボタンが隠れない設計
  • ボタンを ScrollView 外の VStack 最下部に固定し、 .safeAreaInset(edge: .bottom) でホームインジケーター非干渉
