トレーニング記録画面（WorkoutSessionView）

1日分のトレーニングセッションを入力・編集する中心画面

v1.4 画面ID: WD-TRAINING-01

画面イメージ （fastlane snapshot 自動撮影 / iPhone 17 Pro Max）

目的・役割

選択した日付のトレーニングセッションを表示・編集する画面。種目ごとにセットを追加し、PR検出・ルーティン適用・インターバルタイマー・シェアを操作できる。アプリの主機能画面。v1.1.0 でホーム画面を全面リデザインし、最速記録 UX を実現した。1.4.0 で画面上部に月カレンダー（MonthCalendar）を置き、1.4.2 でカレンダータブを廃止して月の表示をこの画面に統合した（タブは4つ: トレーニング・種目・統計・設定。WD-010）。

UI 構成（アプリ 1.4.2 時点）

要素種類説明

ツールバー左「ルーティン」Menu「ルーティンから追加」「ルーティンを編集」「ルーティンを保存」（記録がない日は保存を無効）

ルーティンボタンの見出し（アプリ 1.4.2〜・WD-010）

記録がない日に出すルーティンのボタンの1行目は、選択日によって次のように出し分ける。ボタンは以前から選択日の曜日で出ていたが、見出しはどの日も「今日のルーティン」だった。1.4.2 でカレンダータブ（これからの日の予定の点）を外したので、その代わりをこの1行が担う（行は増やさず、文言だけを変える）。

選択日見出し（日本語）見出し（英語）文言キー
今日今日のルーティン: ○○Today's routine: ○○routine.today.title
今日以外（過去・未来）この曜日のルーティン: ○○Routine for this weekday: ○○routine.thisWeekday.title

2行目は種目名の要約。種目が2つまでは区切って並べ、3つ以上は「先頭2つ＋残りの数」（日本語「ベンチプレス・スクワット 他3種目」／英語「Bench Press, Squat +3 more」）。区切りは日本語「・」、英語「, 」（common.middleDotSeparator。1.4.2 の WD-016 で、英語表示でも全角「・」が出ていたのを修正）。見出しと要約の組み立ては WorkoutSessionViewModel.routineTitle(for:now:) / routineSummary(exerciseNames:) に置き、単体テスト（RecordScreenTextTests）で固定している。

使用するデータモデル

@Model final class WorkoutSession {
    var id: UUID
    var date: Date
    var note: String
    @Relationship(deleteRule: .cascade, inverse: \WorkoutSet.session)
    var sets: [WorkoutSet] = []
}

@Model final class WorkoutSet {
    var id: UUID
    var exercise: Exercise?
    var weight: Double
    var reps: Int
    var order: Int
    var session: WorkoutSession?
    var duration: Double  // 有酸素: 分
    var distance: Double  // 有酸素: km
}

// ルーティン機能（v1.1.0）
@Model final class WorkoutTemplate {
    var id: UUID
    var name: String
    var createdAt: Date
    var assignedWeekdays: [Int] = []  // 0=日, 1=月, ..., 6=土。空配列=曜日固定なし
    var entries: [TemplateEntry] = []

    func appliesTo(date: Date) -> Bool  // 曜日判定メソッド
}

  • v1.1.0: 日付セレクターに「今日」バッジ（Capsule、AppTheme.accent）
  • v1.1.0: RoutineSuggestionService で todaysRoutine を算出してエンプティCTAに反映

  • v1.2.1: PRCelebrationView/AchievementCelebrationView の見出し .white → .primary（ライトモード白文字バグ修正）
  • v1.2.1: 祝福オーバーレイに明示的「閉じる」ボタン・.accessibilityAddTraits(.isModal)・@Environment(\.accessibilityReduceMotion) 対応
