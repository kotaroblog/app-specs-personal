オンボーディング（11ステップ）

初回起動時のウィザード形式セットアップ

v1.0画面ID: WD-ONBOARDING-01

目的・役割

初回起動時に目標・経験・頻度を入力して、ルーティンやリマインダーを最適化するためのウィザード。 1.4.5（未公開）からは課金画面を出さず、通知ステップで終えて記録画面（今日のルーティン）へ入る。

6ステップの構成（1.4.5〜・未公開）

記録に触れる前の待ちと課金画面が初回体験の減点だったため、Loading（3秒の「プランを作成しています」）と Paywall を外した。課金画面は設定とシェア画像の鍵から開く既存の入口だけに残す。あわせて「週週3日」の誤字を直した。
  1. Welcome — アプリの紹介
  2. Goal — 目標選択
  3. Experience — 経験レベル
  4. Frequency — 週間頻度（「次へ」で選択を保存。以前は Loading の最後で保存していた）
  5. Result — 結果表示
  6. Notification — 通知許可リクエスト。ボタンは「記録をはじめる」（「あとで」も可）。ここで初回設定を終える

ページはスワイプでも送れるため、頻度の「次へ」を通らなかった場合に備えて完了時にも選択を保存する。完了フラグは従来どおり @AppStorage("onboardingCompleted")。完了の分析イベントは通知ステップの完了時に送る。

トラッキング許可（ATT）の事前説明は、初回設定の直後ではなく統計タブを初めて開いたときに出す（広告参照）。

終えた直後の記録画面では、記録がない日の「今日のルーティン」を人型の絵の上（カレンダー直下）に大きく出す（トレーニング記録参照）。

11ステップの構成（1.4.4 まで・記録として残す）

  1. Welcome — アプリの紹介
  2. Goal — 目標選択（筋肥大 / 減量 / 健康 / 筋力）
  3. Experience — 経験レベル（初級 / 中級 / 上級）
  4. Frequency — 週間頻度（2 / 3 / 4 / 5+ days）
  5. Loading — 解析中演出
  6. Result — 解析結果表示
  7. Prediction — 達成予測
  8. Features — アプリの主要機能紹介
  9. Commit — 「始める」コミット
  10. Notification — 通知許可リクエスト
  11. Paywall — サブスク提示

実装メモ

  • 完了時に insertDefaultTemplates() で目標・経験別の初期テンプレ挿入
  • 通知ステップで UNUserNotificationCenter 許可リクエスト
  • Paywall ステップでスキップ可（強制購入なし）— 1.4.5 で Paywall ステップ自体を廃止（PaywallStepView・PaywallFAQSection・LoadingStepView を削除）
  • 1.4.5: OnboardingViewModel.finish() で選択の保存と完了イベント。NotificationStepView は onFinish を受け取る形に変更
