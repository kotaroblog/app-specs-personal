カレンダー画面（CalendarView）【1.4.2 で廃止】

月単位のトレーニング履歴を部位ヒートマップで可視化

廃止（アプリ 1.4.2）画面ID: WD-CALENDAR-01
この画面（カレンダータブ / CalendarView）はアプリ 1.4.2 (21)（2026-10-08 審査提出）で廃止した。タブは5つから4つ（トレーニング・種目・統計・設定）になった（WD-010・本人決定）。
理由: 1.4.0 でトレーニング記録画面の上部に月カレンダー（MonthCalendar）を置き、タブの中身がほぼ重複した。タブ単体は開かれていなかった。
CalendarView・CalendarViewModel・FlowLayout はコードから削除した。この画面にあった役割の行き先は次のとおり。
  • 日の詳細の閲覧と共有 → 記録画面の月カレンダーで日をタップし、その日の記録を開く（共有も記録画面から）
  • これからの日の予定の点 → 記録がない日の見出しを、今日以外は「この曜日のルーティン: ○○」にした（今日は従来どおり「今日のルーティン: ○○」）。詳細はルーティン機能
  • 部位の色の凡例 → 種目カードの色の点・種目タブの色の帯とバッジ（既存）で代える
  • 部位の判定（CalendarViewModel.categoriesPerformed）→ WorkoutSession.performedCategories へ移した（記録画面の月カレンダーの点の色に使う）
  • PR の祝福表示 → 中身を設定する処理が無く、一度も表示されていなかったため代替なしで削除
以下は廃止前の仕様の記録として残す。

画面イメージ （fastlane snapshot 自動撮影 / iPhone 17 Pro Max）

目的・役割

月単位のカレンダーでトレーニング日を部位カラーで可視化し、過去のセッションへ素早くアクセスする閲覧専用画面。v1.1.0 では編集機能を撤廃して閲覧に特化し、部位ヒートマップ・BottomSheet 詳細・ルーティン予定ドット・凡例セクションを追加した。

UI 構成（v1.1.0 リデザイン後）

要素種類説明
月ナビゲーションHStack前月・次月・年月表示
カレンダーグリッドLazyVGrid日付グリッド。各セルに部位カラードット（最大3つ）を表示。ドットはその日にトレーニングした部位の色（ExerciseCategory.color）
予定ドット（未来日）カレンダーセル内 枠線スタイルドット未来日かつ実績なしの日に、曜日ルーティンから導出した予定ドット（枠線のみ、塗りなし）を表示
部位カラー凡例カレンダー下部 HStack8部位（胸・背中・肩・腕・脚・腹筋・有酸素・その他）のカラーと名称をラベル表示
ストリーク表示Text「連続Nログイン」
日付タップ BottomSheetsheet(.fraction)日付タップ時に表示。日付・部位タグ（カラーピル）・サマリ統計（種目数/総セット/最大重量）・種目リスト（閲覧専用）・本日のルーティンセクション（曜日ルーティンがある場合）を表示
v1.1.0 廃止事項
以下の要素は v1.1.0 で撤廃し、カレンダーを閲覧専用画面に変更した。
- 「ワークアウトを記録／編集」ボタン
- 種目タップ → AddWorkoutView 遷移
- PRセレブレーションオーバーレイ（カレンダー上）
編集はトレーニング記録画面（WorkoutSessionView）で一元管理する。
