ホーム画面ウィジェット（3種）

Summary / Weekly / CategoryTracker

v1.0.5画面ID: WD-WIDGET-01〜03仕様書 v1.1

目的・役割

ホーム画面に配置できるウィジェット3種。週間進捗・継続日数・カテゴリ別トラッキングを表示。

3種類のウィジェット

ウィジェットサイズ表示内容
SummarySmall今週のセッション数・最終トレーニング日・ストリーク
WeeklyMedium週間サマリ + トップ種目
CategoryTrackerMediumカテゴリ別の今週セッション数

週間ウィジェット（Weekly）の部位の表示（アプリ 1.4.2〜）

表示箇所内容
各曜日の下の1文字その日の最初の部位の表示名の頭文字（日本語なら「胸」「背」など）
前回の部位（最大3つ）部位の表示名を区切りでつなぐ。区切りは日本語「・」、英語「, 」（common.middleDotSeparator）
WD-017 / WD-016 の修正（アプリ 1.4.2）: 共有データの部位は保存値（"chest" など）で持っているため、そのまま出すと日本語表示でも英字（「c」「chest・back」）で出ていた。表示時に WidgetData.localizedCategoryName で表示名に直す。あわせて区切りの全角「・」の直書きを、言語ごとの区切りに替えた。

// AppGroup UserDefaults

}
