広告機能（Unity LevelPlay）

Banner + Rewarded 広告

v3.0機能ID: WD-FEAT-AD

2026-08-20 広告基盤を AppLovin MAX から Unity LevelPlay へ移行

AdMob アカウントが「無効なトラフィック」により恒久的に無効化（2026-07-30）され、再審査請求も却下された。 その後 AppLovin MAX へ移行したが、publisher アカウントの承認が下りなかったため断念し、Unity LevelPlay へ再移行した。

WorkoutDiary は App Key と広告ユニットIDが未設定（空）のため、 現時点で広告は一切ロードされない（後述の安全機構により、未設定の間は自動的に無効）。

時期基盤結果

Unity Ads は 2026-04-01 以降、直接統合だと配信性能が落ちるため、LevelPlay（メディエーション）経由の bidder として利用する。直接統合は使わない。

概要

本アプリは Banner と Rewarded の2種類の広告を活用。プレミアムユーザーは非表示。 Rewarded 視聴で1回限りプレミアム機能を一時解放できる導線あり。

広告を出してよい環境の判定（再発防止の中枢）

AdMob 停止の原因は、開発中・TestFlight 検証中に本番の広告IDでインプレッションが発生していたことだった。 ネットワークを変えても同じ規約（自己クリック・他者への視聴依頼の禁止）が適用されるため、同じ事故を構造的に防ぐ。

AdEnvironment.isAdDeliveryAvailable = !appKey.isEmpty && isProduction（App Key が設定済み かつ App Store 配信版）

環境広告のロード・表示
DEBUG ビルド / シミュレーター / TestFlight一切リクエストしない
App Store 配信版（App Key 設定済み）配信する
  • 判定は App Store レシートの種別（sandboxReceipt かどうか）で行う。ビルド構成の設定ミスでは破れない
  • LevelPlay にもテスト広告IDの概念がないため、開発中は広告を出さない方式を採用した
  • SDK の初期化完了前は広告をロードしない（LevelPlay は初期化前の loadAd() が失敗するため）。初期化完了は @Observable な AdReadiness で SwiftUI に伝播する
  • SDK 初期化自体も配信可能な環境でのみ実行する

広告配信が無効な期間の挙動

  • バナーは枠ごと非表示（空白を残さない）
  • リワードはロードしない。その結果 isAdReady が false のままとなり、 「広告を見て1回無料」の導線はシェア画面側で自動的に非表示になる（UI 側の追加分岐は不要）

広告の種類と配置

種類配置無料/プレミアム
Banner（LPMBannerAdView / アダプティブ）ContentView 下部無料のみ
Rewarded（LPMRewardedAd）能動視聴（シェア機能の一時解放）常時利用可

広告ユニットID の構成

Unity ダッシュボード（LevelPlay）で発行した値をコード側に設定する。 未設定（空）の間は広告を一切ロードしない（差し替え漏れで意図しない挙動にならないための安全弁）。

※ 実際のIDは本仕様書には記載しない（コード上で管理する）。

RewardedAdManager API

@Observable @MainActor
final class RewardedAdManager {
    var isAdReady: Bool
    private var adContinuation: CheckedContinuation<Bool, Never>?

    func loadAd()
    func showAd() async -> Bool  // true=報酬獲得
}

continuation leak 対策

LevelPlay の delegate ベースAPI を CheckedContinuation でブリッジ。 重複表示・メモリリーク防止のため、表示完了時に必ず1度だけ resume + nil 化する。 didRewardAd と didCloseAd は nonisolated デリゲートから呼ばれ MainActor への到達順が保証されないため、 報酬フラグはデリゲート内で同期的に確定させる（そうしないと「広告は見たのに報酬が付かない」取りこぼしが起きる）。

ビジネスルール

  • Banner はプレミアムユーザーには表示しない
  • Rewarded はプレミアム判定不要（常時表示可）
  • Rewarded 視聴で tempPremiumExpiresAt を保存し時限解放
  • 広告のロード・表示は App Store 配信版のみ（AdEnvironment.isAdDeliveryAvailable）。DEBUG・シミュレーター・TestFlight では一切リクエストしない
  • ATT ダイアログも同じゲートの内側。広告を配信しない間は表示しない
  • ロード失敗時は指数バックオフ（上限64秒）で再試行し、再試行タスクは1本に束ねる
