Widget機能

3種ウィジェット（Summary/Weekly/CategoryTracker）と本体同期

v1.0.5機能ID: WD-FEAT-WIDGET仕様書 v1.1

概要

iOS ホーム画面に3種類のウィジェットを提供。AppGroup UserDefaults 経由で本体・Widget間でデータ同期。

関連画面

  • Widgets画面仕様

3種類のウィジェット

ウィジェットサイズ表示
SummarySmall今週セッション数 / 最終日 / ストリーク
WeeklyMedium週間サマリ + トップ種目
CategoryTrackerMediumカテゴリ別の今週セッション数

週間ウィジェット（Weekly）の部位の表示（アプリ 1.4.2〜）

表示箇所内容
各曜日の下の1文字その日の最初の部位の表示名の頭文字（日本語なら「胸」「背」など）
前回の部位（最大3つ）部位の表示名を区切りでつなぐ。区切りは日本語「・」、英語「, 」（common.middleDotSeparator）
WD-017 / WD-016 の修正（アプリ 1.4.2）: 共有データの部位は保存値（"chest" など）で持っているため、そのまま出すと日本語表示でも英字（「c」「chest・back」）で出ていた。表示時に WidgetData.localizedCategoryName で表示名に直す。あわせて区切りの全角「・」の直書きを、言語ごとの区切りに替えた。

共有データ

// AppGroup UserDefaults
struct WidgetSharedData {
    let weeklyCount: Int
    let lastWorkoutDate: Date?
    let currentStreak: Int
}

struct WeeklySummaryData {
    let weekStart: Date
    let weekEnd: Date
    let totalSessionCount: Int
    let topExercises: [TopExercise]
    let currentStreak: Int
    let streakUnit: StreakUnit  // .days / .weeks
}

同期タイミング

  • 本体起動時 → AppGroup 書き込み + WidgetCenter.reloadAllTimelines()
  • セッション保存後 → AppGroup 書き込み + WidgetCenter.reloadAllTimelines()
  • 翌日0時 → Timeline policy で自動再取得

ビジネスルール

  • Single Source of Truth は AppGroup UserDefaults
  • Widget は本体に依存しない（AppGroup nil でも空表示で動作）
  • Widget Bundle Identifier: com.happyboy1002.WorkoutDiary.widget
