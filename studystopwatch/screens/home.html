ホーム画面（HomeView）

今日の要約カード＋勉強・計画・ふりかえりの一覧

1.4.2 (22)（TestFlight 配信済み・未公開）画面ID: SS-HOME-01

目的・役割

起動して最初に見る画面。「今日、次に何をやるか」と「開始」を1か所にまとめた要約カードと、 勉強・計画・ふりかえりの入口を並べた一覧の2段で構成する（1.4.2 で B 案に作り直し。SS-030）。

計測はホームの「開始」か、一覧の「科目を選んで計測」から始める。計測中は計測画面に切り替わる。

UI 構成（1.4.2）

順部品中身
0週のふりかえりカード（WeeklyReviewCard）日曜18時から、ふりかえるか × で閉じるまで一番上に出す（WeeklyReviewService.startHour = 18）
1今日の要約カード（HomeSummaryCard）上段次にやること＋開始ボタン。出し分けは下の表
1今日の要約カード 下段（HomeSummaryStats）今日の合計と目標（達成率）／試験まで／連続日数。目標をタップで今日の目標の編集、試験をタップで試験日の画面
2習慣づくりのカード（HabitSetupCard）初めて記録したあとに1回だけ。1日の目標と通知を理由つきで提案
3一覧「勉強する」科目を選んで計測（科目数）／計測せず手動で記録／ポモドーロで計る（スイッチ。オンなら「N分集中 → N分休憩」）
3一覧「計画する」今日やること（終えた数/全体・無ければ「なし」）／学習計画（「進み N%」・無ければ「作る」）／試験日（月日・「今日」・「期間中」・「未設定」）／予定（学校・塾・小テスト）「足した予定はカレンダーで見られます」／目標（今日・今週・今月）（「今週 N%」・無ければ「未設定」）
3一覧「ふりかえる」週のふりかえり（日曜の夜からは「できます」、それ以外は「日曜の夜」）

要約カード上段の出し分け（HomeDashboard.Lead）

条件表示
未完了のやることがある日「次にやること」1件（前回のメモがあれば添える）＋開始。2件目以降は「ほかN件」→ 今日やることの画面
やることが無く、今日の1科目（フォーカス科目）を設定しているその科目＋開始＋「変更」（今日の1科目を選ぶシート）
やることが無く、記録がある前回学習した科目＋開始
記録がまだ無い先頭の科目＋開始
科目が1つも無い「科目が登録されていません」＋「科目を追加」。開始は出さない（計測には科目が要る）

「試験まで」の表示（ExamSchedule.phase）

状態表示
未設定「設定する」
開始日の前残り N日（「テストまで」「試験まで」は種別による）
複数日の試験の期間中N日目／全M日
1日だけの試験の当日今日は試験当日
終わった後「次を設定」

計算は ExamSchedule 1か所（ホーム・カレンダー・週のレポート・ウィジェットで同じ答え）。詳細は試験の期間。

遷移

操作先
要約カードの「開始」やることなら、そのやることの計測（科目はやることの科目 → 前回の科目 → 先頭の科目）。科目ならその科目の計測
「ほかN件」／一覧「今日やること」今日やることの画面（HomeTaskListScreen・push）
要約カードの目標目標の編集（今日）
要約カードの試験／一覧「試験日」試験日の画面（sheet）。保存後に「学習計画を作りますか？」
一覧「科目を選んで計測」科目を選ぶ画面（HomeSubjectListScreen・計測モード）。行の「…」から手動の記録・編集・削除
一覧「計測せず手動で記録」科目を選ぶ画面（手動モード）→ 手動の記録
一覧「学習計画」計画があれば学習計画の画面（HomePlanScreen・進み具合と新しい計画の作成）、無ければ直接学習計画の作成
一覧「予定」予定の追加（sheet）
一覧「目標」目標の管理（GoalManagementView・push）
ふりかえりカード／一覧「週のふりかえり」週のふりかえり（sheet）
やることから始めた計測の完了計測を終えたあとの画面
科目から始めた計測の完了短い計測後の画面（RecordedSummarySheet）。「次にやることを決める」で計測を終えたあとの画面へ

実装メモ

  • HomeView を分割（HomeView+Content・HomeView+Modifiers・HomeSummaryCard／Leads／Stats・HomeMenuList・HomeDestinationScreens・TimerRunningView・TimerControls・SubjectRow・UndoToast）。2,000行超から各200行前後へ
  • 計測の完了まわり（保存・取り消し・計測後の画面の出し分け）は HomeViewModel、上段の出し分けや集計は HomeDashboard に置く（シミュレーターなしでテストできる側）
  • 開始ボタンはホームで1か所。文言は「開始」、色は AppTheme.startButton（#368002）に固定。以前は「開始」「計測スタート」が混ざり、科目の色によっては白文字が読めなかった（UX チェック #11）。科目の色はアイコンで見せる
  • 一覧の行は homeMenu.<項目> の accessibilityIdentifier を持つ（UI テスト用）
  • 「試験当日」の読み上げは共通の文言にそろえた
  • タイマーの永続化（UserDefaults・24時間境界）・Live Activity 連動・起動時の科目参照の修復（SS-022）は従来どおり

以前の並びとの違い

1.4.1 までは「試験日カウントダウン → 開始CTA（またはやることのカード）→ 今日の目標 → 科目候補 → 今週／今月 → ポモドーロ → 連続日数」を縦に並べていた。 1.4.2 では試験・目標・連続日数を要約カードの下段に、科目・計画の入口を一覧に寄せ、開始の場所を1つにした。 試験日の設定 → 学習計画の提案の流れ（ExamPlanFlow）は残している。
