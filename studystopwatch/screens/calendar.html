カレンダー画面（CalendarScreen）

日 / 週 / 月の3ビュー切替で学習実績と期限タスクを一体管理するカレンダー

v1.4.0（TestFlight・未提出） 画面ID: SS-CAL-02

目的・役割

旧 CalendarHeatmapView（SS-CAL-01）を置き換える新カレンダー画面（v1.1.0 で初導入、v1.2.0 で大幅刷新）。 日・週・月の3ビューをタブで切り替え、試験日カウントダウン・学習タイムライン・月次グリッドを統合する。 v1.2.0 で期限日ベースの StudyTask と完全統合し、計画（タスク）と実績（学習時間）を同一画面で管理できるようにした。 また学習計画自動配分（StudyPlanSheet）へのアクセス導線を右上ツールバーに追加した。

v1.4 で役割を「先の予定を見通す場所」に絞った（SS-019〜021）。今日のことはホームに任せ、最初に開く表示を週にして、 週は曜日ごとのやること一覧にした。「いつ勉強したか」の時間表は記録を見るものなので分析タブへ移した。 あわせて学習計画の進み具合と「残りを配り直す」をここに出す（学習計画の進み具合と配り直し）。

WeekCalendarView（週ビュー）— v1.4 で最初に開く表示

v1.4 変更（SS-019）: v1.3 の3段階構成（① 今日のやること＋取りこぼし ② 科目別の件数（SubjectProgressRow）③ 6時〜23時の「いつ勉強したか」時間表）をやめ、 曜日ごとのやること一覧にした。今日のやることはホームと今日タブにあるので3度目に見せない。時間表は分析タブの週間表示へ移した （移す際、区切り時刻を使う人で列が1日ずれていた不具合も解消）。

この週のやること（WeekTaskListCard）

グループ対象
期限切れ（N件）表示中が今週のときだけ。期限がこの週より前で未完了、かつ直近7日分まで。見出しはオレンジ
今週中期限の種類が「今週中」で、期限（その週の日曜）がこの週のやること（完了済みも含む）
月〜日の各日期限の種類が「その日」で、期限がその日のやること。未完了が先、次に並び順・作成順。無い日は「なし」。今日には「今日」の印
操作動き
各日の「＋」その日を期限にしてやることを追加（TaskCreationSheet 新規）
行の左の丸完了／未完了の切り替え
行をタップやることの編集（TaskCreationSheet 編集）
日付を押すその日の日ビューへ移る

各行は科目の色の点・題名（完了は打ち消し線）・説明の行（未完了のみ。「科目・昨日の分・今週中・途中まで・学習計画／前回決めた／先週から」など。ホームと同じ TaskScheduling.metaLabel）。

使用するデータモデル

// 学習セッション
@Model final class StudySession {
    var id: UUID
    var startTime: Date
    var endTime: Date?
    var duration: TimeInterval
    var subject: Subject?
}

// 科目
@Model final class Subject {
    var id: UUID
    var name: String
    var colorHex: String
}

// ユーザー設定（試験日カウントダウン用）
@Model final class UserSettings {
    var dailyGoalMinutes: Int?
    var examDate: Date?
}

// やることリスト（v1.2〜: 期限日ベース）
@Model final class StudyTask {
    var id: UUID
    var title: String
    var isCompleted: Bool
    var dueDate: Date?            // v1.2〜: 期限日（日ビューは dueDate == selectedDate でフィルタ）
    var linkedSessionID: UUID?
    var completedAt: Date?
    var sortOrder: Int
    var createdAt: Date

    // 後方互換フィールド（v1.2 以降は非推奨）
    var periodRawValue: String    // 旧: "day" / "week" / "month"
    var periodStart: Date
    var periodEnd: Date

    // v1.4 追加（すべて既定値つき）
    var planID: UUID?             // 学習計画のやること
    var planAmount: Int?
    var dueScopeRawValue: String  // "day" / "week"（今週中。dueDate はその週の日曜）
    var originRawValue: String    // manual / plan / next / carried / migrated
    var handoffNote: String?
}

// 学習計画（v1.4 追加）
@Model final class StudyPlan {
    var id: UUID
    var title: String
    var subject: Subject?
    var totalAmount: Int
    var unit: String
    var startDate: Date
    var endDate: Date
    var splitModeRawValue: String
    var weekdaysText: String
    var createdAt: Date
    var isArchived: Bool
}

実装メモ

  • 旧 CalendarHeatmapView / DayDetailSheet は削除済み。SS-CAL-01 の画面IDは旧仕様として残す
  • CalendarScreen が親 View。ViewModeTabs の選択状態を @State で保持
  • selectedDate は CalendarScreen が管理し、各子ビューに Binding で渡す
  • v1.4 既定の表示は @State private var viewMode: CalendarViewMode = .week
  • v1.4 週の時間表（WeekTimelineCard）は Views/Report/ へ移し、分析タブの週間表示で使う
  • MonthCalendarView の inline 展開は AnyLayout / if selectedDate != nil で制御
  • テーマカラーは AppTheme.accent（#58CC02）。カードは cardShadow() 修飾子で統一
  • 日ビューの StudyTask @Query: dueDate が selectedDate と同日のタスクを取得（startOfDay/endOfDay で範囲フィルタ）
  • v1.4 週ビューのやることは WeekTaskListCard。期限切れは TaskScheduling.overdueWindowDays（7日）までに絞る。「今日」は学習日の区切りで決める
  • v1.4 週ビューの完了切り替えは TaskFlowService.complete / reopen を通す
  • 月ビューのタスクバッジ: 月内全タスクを取得し、日付ごとに Dictionary でグルーピングして未完了件数を算出
  • StudyPlanSheet は .sheet(isPresented: $showPlanSheet) で表示
  • CountdownCard の残り日数: Calendar.current.dateComponents([.day], from: today, to: examDate).day で算出
