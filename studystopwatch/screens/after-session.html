計測を終えたあとの画面（AfterSessionSheet）

1回の勉強の終わりに「終わった？」「次はいつ・何を？」「メモ」を残すシート

v1.4.0（TestFlight・未提出） 画面ID: SS-AFTER-01

目的・役割

塾で授業の終わりに「今日やったこと」「次回の宿題」を書いて次の授業で見返していたのと同じことを、1回の勉強の終わりにする画面。 v1.3 までは「次回やること」やメモを入力できても、入力シート以外のどこにも表示されず（SS-017）、 やること（StudyTask）と計測（StudySession）をつなぐ linkedSessionID も一度も代入されていなかった（SS-018）。 この画面で「計測 → 次のやること」を作り、ホームの「今日やること」で次の勉強の前に見せる。

開く経路

開始元開くタイミングモード
ホームの「今日やること」の「開始」（やることから始めた計測）計測の完了ボタンを押すと毎回開くやることモード（task != nil）
科目から始めた計測（開始CTA・科目一覧・フォーカス科目）自動では開かない。完了後の取り消しトーストにある「次にやることを決める」を押したときだけ開く科目モード（task == nil）
科目から始めた計測の取り消しトーストは、この導線を押す時間を取るため表示時間を延ばした（記録したとき 8秒、目標達成の演出を挟んだとき残り 4秒。破棄のときは従来どおり 5秒）。 「次にやることを決める」を押すとトーストの自動消去とレビュー依頼の予約を止め、レビュー依頼はこの画面を閉じたあとに出し直す。

UI 構成

要素やることモード科目モード
ナビゲーションタイトル「おつかれさまでした」
見出し（AfterSessionHeader）「記録しました」＋「科目名・時間」。右に「取り消す」（この計測を記録しなかったことにする）
終わった？「このやること、終わった？」＋やることの題名＋「終わった／途中まで」（既定: 終わった）—
何をやった？—自由入力（例：教科書 p.20〜25・任意）。入力はメモとして扱う
次はいつやる？（AfterSessionNextSection）「明日／あさって／今週中／日付を選ぶ」（既定: 明日）。「日付を選ぶ」は明日〜365日後、初期値は3日後。学習計画のやることのときは出さない
次に何をやる？下書きを自動で入れる（下表）。利用者が書き換えたあとは自動で上書きしない空欄
補足「空のままにすると、次の予定は作りません」
学習計画の次の予定（AfterSessionPlanInfo）学習計画のやることのときだけ、「次はいつ／何を」の代わりに出す。「次の予定（学習計画どおり）」＋次のやること（例: 10/1（木）　英単語帳: 10語（4日目/30日））。最後なら「この計画のやることは、これで最後です」。途中までを選ぶと「このやることは、残りを明日に回します」。末尾に「計画の日程を変えるときは、カレンダーの学習計画から配り直せます」—
メモ（任意）最初は「メモを残す（任意）」ボタンだけ。押すと入力欄が開く。「次にこのやることを開いたとき『前回のメモ』として出ます」—（「何をやった？」がメモを兼ねる）
保存する主ボタン（下部固定）
スキップ（時間だけ記録）弱いボタン。計測の記録は残し、次の予定は作らない

「次に何をやる？」の下書き

条件下書き例
終わった（既定）題名の末尾にある範囲を、同じ幅で次の範囲にずらす（TaskScheduling.nextRangeTitle）。範囲が無い題名はそのまま「青チャート 例題45–48」→「青チャート 例題49–52」／「p.31–40」→「p.41–50」
途中まで題名＋「の続き」（すでに「の続き」で終わっていれば付けない）「青チャート 例題45–48の続き」

範囲の区切りは - – − 〜 ~ ～ を受け付け、題名の中で最後の数字の範囲だけを対象にする。範囲の無い題名で同じ題名が入るのは決めた仕様どおり（コードレビューの🟡指摘を仕様として残した）。

保存したときの動き

開始元選択データへの反映お知らせの文言
やること（学習計画以外）終わった・次の題名ありやることを完了にして計測と紐づけ、次のやることを新しく作る（origin = next・期限は選んだ日。今週中なら期限はその週の日曜で dueScope = week・科目は元のやること、無ければ計測の科目）「明日の『やること』に入れました」など
終わった・次の題名が空やることを完了にするだけ「やることを完了にしました」
途中まで同じやることの期限を付け替える（新しく作らない）。題名は「次に何をやる？」の内容（既定「〜の続き」）に置き換える「明日の『やること』に回しました」など
やること（学習計画）終わったやることを完了にする。次の予定は作らない「次は計画どおり 10/1（木）」／最後なら「計画の最後のやることでした」
途中まで同じやることを明日へ付け替える（題名・量は変えない）「残りを明日のやることに回しました」
科目次の題名あり次のやることを新しく作る（origin = next・科目は計測の科目）「〇〇の『やること』に入れました」
次の題名が空何も作らない「記録しました」
  • メモ（科目モードでは「何をやった？」）が入っていれば、計測の記録（StudySession.note）に入れる。あわせて次のやること（途中までなら同じやること）の handoffNote に入れ、ホームで「前回のメモ」として出す
  • やることモードでは、どの選択でも計測と紐づける（linkedSessionID）。紐づいた未完了のやることは、ホームで「途中まで」と表示され、ボタンが「続き」になる
  • 「今週中」を選んだときのお知らせは「今週の『やること』に…」、日付を選んだときは「9/29（火）の『やること』に…」

状態

状態表示内容
やることモード（学習計画以外）見出し → 終わった？ → 次はいつ・何を → メモ（閉じた状態）
やることモード（学習計画）見出し → 終わった？ → 学習計画の次の予定 → メモ（閉じた状態）
科目モード見出し → 何をやった？ → 次はいつ・何を
「日付を選ぶ」を選択日付の選択欄を出す
保存・スキップ・取り消しを受け付けた後2回目以降の操作は無視する（保存の連打で次のやることが2件できるのを防ぐ）

遷移

操作遷移先閉じたあと
保存するシートを閉じてホームへお知らせ「保存しました」＋上表の文言
スキップ（時間だけ記録）シートを閉じてホームへお知らせ「記録しました」＋「科目名・時間」
下へスワイプして閉じるホームへスキップと同じ扱い（やることとの紐づけは残す）。お知らせ「記録しました」＋時間
取り消すシートを閉じてホームへ計測の記録を削除し、お知らせ「記録を取り消しました」。完了回数（completedSessionCount）を1戻す。広告・祝賀・レビュー依頼は出さない

お知らせ（FlowToast）は4秒で消える。VoiceOver 利用者にも届くよう読み上げを送る。取り消しはこの画面の中だけで行う（お知らせからは取り消せない）。

広告・祝賀・レビュー依頼の順番

やることから始めた計測では、広告を保存画面より先に出さない。 完了ボタンの時点では目標達成とレビュー依頼の判定だけ済ませ、広告・祝賀・レビュー依頼はこの画面を閉じたあとに出す。 広告を出すのは「やることモード かつ レビュー依頼の回でない かつ 目標達成の回でない」とき（AfterSessionContext.showsAdAfter）。 目標達成・レビュー依頼の回に広告を出さない決まりは v1.3 までと同じ。
科目から始めた計測は従来どおり、完了の時点で広告（出す回なら）→ 取り消しトーストの順。トーストからこの画面を開いたときは、閉じたあとにレビュー依頼だけを出し直す。

閉じたあとの祝賀は 0.5秒後に表示して 3秒で閉じ、レビュー依頼はその 1秒後。あわせて週のふりかえりカードの表示を更新する。

使用するデータモデル

StudySession（note に保存）

AfterSessionViewModel {                 // @Observable @MainActor
    session: StudySession
    task: StudyTask?                    // 科目から始めた計測では nil
    doneChoice: .finished | .partial
    whenChoice: NextWhen                // tomorrow / dayAfterTomorrow / thisWeek / custom
    customDate: Date
    memo: String
    nextText: String
    nextPlanTask: StudyTask?            // 同じ計画の、期限が同じか後の未完了のやること（いちばん近いもの）
}
enum AfterSessionResult { case saved(message:), skipped(message:), undone }

実装メモ

  • 計測中のやることは TimerViewModel.currentTaskID で持ち、UserDefaults（activeTimer_taskID）にも保存する。アプリを終了して計測を復元しても、やることとの紐づけが残る
  • 完了時に currentTaskID のやることが見つからない（計測中に消した等）ときは、科目から始めた計測と同じ流れになる
  • 「今日」は学習日の区切り（StudyDay.resetHour）で決める。深夜1時・区切り4時の人が「明日」を選ぶと、学習日の翌日が期限になる
  • 書き込みは TaskFlowService（complete / reschedule / createTask / link）を通す。画面から StudyTask のプロパティを直接書き換えない
  • シートは sheet(item:) で開き、閉じたあとに使う内容を activeAfterSession に別で持つ（閉じると afterSession は nil になるため）
  • 保存・スキップ・取り消しは isFinishing で1回だけ受け付ける
  • 計測イベント: 開いたとき after_session_shown、保存 after_session_saved、スキップ・スワイプで閉じたとき after_session_skipped（内容は送らない。ロギング方針参照）
