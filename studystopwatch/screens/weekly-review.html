週のふりかえり（WeeklyReviewCard / WeeklyReviewView）

日曜の夜に、やることの結果・終わらなかったこと・この週のメモを1画面で見て、来週へつなぐ

v1.4.0（TestFlight・未提出） 画面ID: SS-REVIEW-01

目的・役割

「やること（計画）→ 計測 → 振り返り」の3か所目。勉強の前（ホームの今日やること）と後（計測を終えたあとの画面）に加えて、週に1回、 予定に対してどうだったかを見て、終わらなかったことを来週へ回す（SS-017 の決定 ⑤⑥）。 分析タブの「先週のふりかえり」（WeeklyCoachReport・Premium）とは別物で、こちらは無料で使える。

いつ出すか

項目仕様
出し始め日曜18時（WeeklyReviewService.startHour = 18）から、その週（月〜日）のふりかえりをホームに出す
出し終わり「ふりかえる」で終えるか、カードの × で閉じるまで。月曜以降も閉じるまで前の週のふりかえりが残る
対象の週今が日曜18時以降ならその週、それより前なら前の週（reviewWeekStart）
見出し対象の週が今の週なら「今週のふりかえり」、前の週なら「先週のふりかえり」（週の途中でこの版に更新した人には前の週が出るため）
回す先の言い方今の週をふりかえるときは「来週へ」、前の週をふりかえるときは「今週へ」
出さない条件その週を閉じた（UserDefaults weeklyReview_closedWeekStart がその週の月曜）／中身が無い（予定のやること0件・勉強時間0・終わらなかったもの0件・学習計画の遅れ0件のすべて）
表示の更新ホームを開いたとき・アプリが前面に戻ったとき・計測を終えたあとの画面を閉じたとき・ふりかえりを終えたとき
通知毎週日曜18時に「今週のふりかえり」を通知する（v1.3 までの月曜9時から変更。通知参照）

UI 構成 — ホームのカード（WeeklyReviewCard）

ホームの試験日カウントダウンのすぐ下、「今日やること」より上に出す。

要素説明
見出し「今週のふりかえり」または「先週のふりかえり」
説明予定があれば「やること 8 / 12件。3分で終わります」、無ければ「終わらなかったことを整理して、来週につなげよう」
× ボタンその週のふりかえりを閉じる（以後その週は出さない）
「ふりかえる」ふりかえり画面をシートで開く

UI 構成 — ふりかえり画面（WeeklyReviewView）

要素説明
ナビゲーションタイトルカードと同じ見出し
「あとで」（左上）何も反映せずに閉じる。カードは残る
やることカード週の範囲（例: 9/28（月） 〜 10/4（日））、「8 / 12件 終わった」、進捗バー、「勉強時間 9時間40分（先週より＋1時間10分）・勉強した日 5日」。前の週が0、または差が1分未満のときは（先週より…）を出さない
終わらなかったこと（N件）「最初は全部『来週へ』になっています。要らないものだけ『消す』に」。各行に科目の色・題名・「科目・期限 9/30（水）」（今週中のやることは「9/28（月）の週のうち」）・「来週へ／消す」の選択
学習計画の遅れ学習計画の終わっていないやることがあるときだけ。「学習計画の終わっていないやることがN件あります。カレンダーの『学習計画』から、残りを今日からの日程に配り直せます」
この週のメモその週の計測の記録に残したメモ（新しい順・最大10件）。「9/30（水）　数学」＋本文
終えるボタン（下部固定）回すものがあれば「3件を来週へ回して閉じる」、無ければ「閉じる」

数え方

項目対象
予定の数（分母）期限がその週（月〜日）のやること。学習計画のやること・完了済みを含む
終えた数（分子）上のうち完了しているもの
終わらなかったこと未完了で、期限がその週と、その前の7日のやること。学習計画のやることは含めない（付け替えると計画の進み具合が狂うため）。期限の古い順
学習計画の遅れ（件数）同じ期間の、未完了の学習計画のやること
勉強時間・勉強した日学習日の区切りで数えた、その週と前の週の計測の記録
終わらなかったことを「その前の7日」までに絞るのは、途中でやめた学習計画などの古いやることを一括で付け替えないため。それより古いものはデータとして残る（消さない）。

終えたときの動き

選択データへの反映
来週へ（今週へ）期限をふりかえった週の翌週の日曜にし、期限の種類を「今週中」（dueScope = week）にする。作られた元が「自分で追加」「前回決めた」「旧・次回やること」のものは「先週から」（origin = carried）にする
消すそのやることを削除する（利用者が明示的に選んだときだけ）

反映後、その週を閉じた扱いにしてカードを消し、ホームにお知らせ「ふりかえりを終えました」＋「3件を来週の『やること』に回しました」を出す。

状態

状態表示内容
日曜18時より前（前の週は閉じ済み）カードを出さない
日曜18時以降「今週のふりかえり」カードを出す
月曜〜日曜18時で、前の週を閉じていない「先週のふりかえり」カードを出す（回す先は「今週へ」）
終わらなかったこと0件終わらなかったことのカードを出さない。ボタンは「閉じる」
学習計画の遅れ0件学習計画の案内を出さない
メモ0件この週のメモを出さない

遷移

操作遷移先
カードの「ふりかえる」ふりかえり画面（sheet）
カードの ×同画面（カードを消す）
「あとで」ホーム（反映しない・カードは残る）
終えるボタンホーム（反映してカードを消す・お知らせ）
週次通知をタップアプリが開く（特定のタブへは移さない。カードはホームに出ている）

使用するデータモデル

StudyTask（dueDate / dueScopeRawValue / originRawValue を更新、または削除）
StudySession（startTime / duration / note / subject を読むだけ）

struct WeeklyReviewData {
    weekStart: Date                 // ふりかえる週の月曜（カレンダー日）
    plannedCount: Int
    doneCount: Int
    leftovers: [StudyTask]
    memos: [Memo]                   // 最大10件
    totalSeconds / previousWeekSeconds: TimeInterval
    studyDayCount: Int
    title: String                   // 今週のふりかえり / 先週のふりかえり
    planBehindCount: Int
    carriesToCurrentWeek: Bool      // true なら「今週へ」
}

実装メモ

  • 判定と集計は WeeklyReviewService（純粋な計算 buildReview と読み込み availableReview を分けている）、画面の状態は WeeklyReviewViewModel
  • ふりかえり画面は sheet(item:) で開く。別の Bool で開くと、開く瞬間に中身が空として扱われ真っ白になる
  • 終えるボタンは isFinishing で1回だけ受け付ける
  • 計測イベント: カードを出したとき weekly_review_shown、終えたとき weekly_review_completed（回した件数・消した件数）、× で閉じたとき weekly_review_dismissed

関連

  • ホーム画面（カードの位置）
  • 計測を終えたあとの画面（メモの入口）
  • 学習計画の進み具合と配り直し
  • 週次ふりかえりレポート（分析タブ・Premium）
  • 通知（日曜18時の週次通知）
  • やることリスト機能
