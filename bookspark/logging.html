ロギング方針

os.log / Logger の subsystem・category と、実在する出力箇所（コミット 17e9969 を grep した結果）

基本方針

print() は禁止。Logger（os.log）を使用する（CLAUDE.md 準拠）。17e9969 時点でアプリターゲットに print( は 0 件。

subsystem と category

subsystem は全箇所で文字列リテラル "com.happyboy1002.BookSpark"（Bundle.main.bundleIdentifier ではない）。 共通の extension Logger は持たず、各型が private static let logger を1つずつ持つ。

次の失敗は画面表示のみ、または表示もログも無い。追加するなら category を増やさず上記3つか、新たに Data / Network を切る。

プライバシー対応

本のタイトル・メモ本文・アクション文言・OCR テキストはログに出さない（現状どの行も出していない）。 通知の本文にはアクション文言が入るが、ログには通知 ID（UUID）しか出さない。

確認方法

macOS の Console.app でデバイスを選び、subsystem:com.happyboy1002.BookSpark でフィルタする。category で絞る場合は category:Notification などを追加する。
