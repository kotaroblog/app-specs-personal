テキスト書き出し

本1冊分のメモとアクションをプレーンテキストにして、共有シートで外へ出す（Pro）。

実装済 機能ID: BS-F04

概要

アプリに閉じ込めず、メモアプリやノートに貼れる形で取り出すための機能。Pro 限定。 書式は Markdown 風のプレーンテキストで、そのまま貼っても読めることを優先する。

関連画面

  • 本の詳細（BS-S04） — 右上「…」→「テキストで書き出す」
  • Paywall（BS-S07） — 無料時

処理フロー

sequenceDiagram participant U as User participant D as BookDetailView participant E as MemoExporter participant S as ShareSheetView U->>D: テキストで書き出す alt 無料 D-->>U: Paywall（general） else Pro D->>E: export(book) E-->>D: String D->>S: シートで表示（medium / large） U->>S: 共有ボタン（ShareLink） end

書式

# {書名} / {著者}

## {メモの日付 M月d日}
- {要点1}
- {要点2}
> {フレーズ}
☑ {完了したアクション}
□ {未完了のアクション}（{M/d} まで）

## {次のメモの日付}
...

例

# エッセンシャル思考 / グレッグ・マキューン

## 9月26日
- より少なく、しかし、より良く
> 最も重要なことを見極め、それ以外を捨てる勇気を持つ。
□ 今週のタスクを上位3つに絞る（9/29 まで）
☑ 不要な会議を1つ断る

ビジネスルール

  • 見出し: 著者が空（空白のみを含む）なら # {書名} だけ
  • メモは古い順（読んだ順）。本の詳細の表示（新しい順）とは逆
  • 各メモの中は 要点 → フレーズ → アクション の順。空の要点・空のフレーズは出さない
  • アクションはメモ内で作成順（本の詳細の「流れた → 期限順 → 完了」ではない）
  • 完了は ☑ {文言}、未完了は □ {文言}（{M/d} まで）。期限が無いものは期限を付けない。流れたと期限内は区別しない（どちらも □）
  • ブロックの間は空行1つ、末尾に改行1つ
  • 写真・読み取ったテキスト（OCR）は出さない

外部連携

連携先用途備考
SwiftUI ShareLinkOS の共有シート書き出しシート右上のアイコン。本文はテキスト選択（コピー）も可

エラー処理

発生条件対応
無料プランPaywall（general）を開く
メモが0件見出し行だけのテキストになる（エラーにしない）

実装メモ

  • 生成は純粋関数 MemoExporter.export(book:)。MemoExporterTests で書式を検証
  • 書き出しシート（ShareSheetView）は等幅 12pt でプレビューし、左上「閉じる」・右上に共有アイコン
  • 日付の書式は Date.shortJapanese（M月d日）と Date.shortSlash（M/d）。どちらも ja_JP 固定の共有 DateFormatter
