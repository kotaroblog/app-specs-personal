無料枠と Pro

無料は読書中2冊まで。買い切りの Pro で冊数無制限・書き出し・8週推移を開放する。

実装済 機能ID: BS-F02

概要

マネタイズは買い切り ¥600 の非消耗型1本（com.happyboy1002.BookSpark.pro）。サブスク・広告・無料トライアルは無い。 無料でもアプリの核（メモ・期限つきアクション・今週の週次レビュー）はすべて使え、制限は「同時に読書中にできる冊数」だけに置く。

  • 本棚（BS-S02） ／ 本の登録（BS-S03） ／ 本の詳細（BS-S04）
  • 週次レビュー（BS-S06） ／ 設定（BS-S08）

無料と Pro の差

機能無料Pro判定関数
読書中の本2冊まで（読了は数えない）無制限EntitlementRules.canAddBook(readingCount:isPremium:)
テキスト書き出し不可可EntitlementRules.canExport(isPremium:)

無料枠の判定規則

static let freeReadingBookLimit = 2

static func canAddBook(readingCount: Int, isPremium: Bool) -> Bool {
    if isPremium { return true }
    return readingCount < freeReadingBookLimit
}

「本を1冊、読書中の状態で増やしてよいか」だけを判定する。readingCount は status == .reading の本の数。

判定を通す箇所

#場所数え方超過時
1本棚の＋（登録ダイアログを開く前）@Query の本から読書中を数えるPaywall（bookLimit）
2バーコード登録の「この本を登録する」BookLimitChecker（fetchCount + #Predicate）Paywall（bookLimit）を重ねる。本は作らない
3手動登録の「登録する」同上同上
4本の詳細で 読了 → 読書中 に戻す同上Paywall（bookLimit）。ステータスは変えない

抜け道対策

  • 登録の瞬間に再判定（#2・#3）: ＋で判定したあとにシートの中で状況が変わっても、確定時にもう一度数える
  • 読了 → 読書中の判定（#4）: 読了で枠を空けて新しい本を足し、元の本を読書中へ戻して3冊目にする、という経路を塞ぐ
  • 空状態の登録ボタンとオンボーディングは #1 を通らないが、0冊なので必ず枠内で、かつ #2・#3 は必ず通る

仕様として許容しているもの

  • 読了の本にもメモ・アクションを追加できる（制限は冊数のみ）
  • 本を削除すれば枠が空く

購入・復元の処理フロー

sequenceDiagram participant U as User participant P as PaywallView participant M as StoreKitManager participant S as App Store P->>M: loadProducts() M->>S: Product.products(for: [proID]) S-->>M: Product（displayPrice） U->>P: 「{価格} で購入」 P->>M: purchase(product) M->>S: product.purchase() S-->>M: success / userCancelled / pending M->>M: 取引を完了させ、Pro 状態を更新 M-->>P: PurchaseOutcome P-->>U: 成功なら閉じる／文言を出す U->>P: 購入を復元 P->>M: restore() M->>S: AppStore.sync() M->>M: Pro 状態を更新 P-->>U: Pro なら閉じる／「見つかりませんでした」

ビジネスルール

  • Pro 状態は端末に保存しない。起動時と取引の更新を受け取ったときに、StoreKit の現在の購入権から判定し直す
  • 起動直後、判定が終わるまでのごく短い間は無料として扱われる
  • 取引の監視（Transaction.updates）は StoreKitManager の生成時に始める。承認待ちの購入や他端末での購入はここで反映される
  • 価格は displayPrice を表示するだけで、コードに金額を持たない
  • スクリーンショット撮影モードでは Pro 状態の確認をしない（常に無料表示）

エラー処理

発生条件対応
商品取得の失敗・商品が返らない「価格を取得できませんでした」＋「再試行」（取得失敗は StoreKit カテゴリに error ログ）
購入の例外「購入できませんでした: {エラー内容}」
承認待ち／結果不明／キャンセルBS-ERR-013〜015
復元の失敗・該当なし「復元できる購入が見つかりませんでした」（処理失敗は error ログ）
