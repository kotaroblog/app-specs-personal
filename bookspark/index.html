BookSpark

読んだ知識を、行動に変える読書メモ · Bundle ID: com.happyboy1002.BookSpark

概要

  • カテゴリブック
  • 対応OSiOS 18.0+（iPhone のみ・縦固定・ライト固定）
  • 言語日本語
  • マネタイズ買い切り ¥600（非消耗型 com.happyboy1002.BookSpark.pro）。広告なし。
    無料＝読書中 2 冊まで（読了は数えない）／Pro＝冊数無制限・テキスト書き出し・週次レビューの 8 週推移
  • ステータス開発中（実装完了・ASC 未登録）。Debug/Release ビルド緑・ユニットテスト 77 件
  • リリース時期未定
  • 技術スタックSwift 6 / SwiftUI / SwiftData / XcodeGen / StoreKit 2 / Vision / AVFoundation / EventKit
  • 仕様の基準ios-apps/BookSpark コミット 17e9969（仕様書と食い違う場合はコードが正）
コンセプト:「読んだ知識を、行動に変える」。
本を登録 → ページを撮る（任意）→ 要点（最大3）・アクション（最大3、期限つき・既定3日後）・フレーズを自分で書く → 期限を過ぎた未完了は「流れた」→ 週次レビューで達成／流れたを数える。
記録するだけのアプリは「失敗しえない」ので続かない。アクションに期限を持たせ、失敗が見える形にしたのが v1.0 の核。
AI は使わない。要点もアクションも本人が書く。OCR は端末内の Vision で走らせ、メモ編集画面に「読み取ったテキスト」として参考表示するだけ（品質判定で止めない）。
旧設計（Claude API による AI 整理・月額サブスク）は 2026-09-26 に撤去済み。本ポータルの旧版もその前提だったため全面的に作り直した。

プライバシー / データの扱い

項目内容
通信Google Books API のみ（ISBN から書名・著者・表紙画像を取得）。アカウント登録なし・自前サーバーなし
保存先本・メモ・アクションは SwiftData で端末内に保存。表紙とページ写真は外部ストレージ属性（@Attribute(.externalStorage)）
PrivacyInfo.xcprivacyNSPrivacyTracking: false / 収集データ型なし / UserDefaults を CA92.1 で宣言
権限カメラ（バーコード読取・ページ撮影）／通知（期限・週次）／カレンダー書き込みのみ（アクションを予定に登録するとき）
輸出コンプライアンスITSAppUsesNonExemptEncryption: false
