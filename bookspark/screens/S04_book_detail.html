本の詳細（BookDetailView）

1冊分のメモと、全メモを横断したアクション一覧。アクションの完了・期限の引き直し・カレンダー登録はここで行う。

実装済 画面ID: BS-S04

目的・役割

書いたメモを見返し、アクションを片づける画面。アクションは「流れた → 期限の近い順 → 完了」で固定の順に並べ、 やり残しが常に一番上に来るようにする。本の読書ステータス（読書中／読了）の切り替え、書き出し、本の削除もここに置く。

UI 構成

要素種類説明
ヘッダーBookDetailHeader表紙 52×70（なければアクセント色グラデーション＋タイトル先頭2文字）・書名・著者・チップ「メモ N件」「アクション 完了数/全数」
読書ステータスMenu + Picker（44pt）ラベル「読書中 ▾」／「読了 ▾」。▾ の見た目どおりメニューで選ばせる（トグルではない）
メモ セクションMemoRow の列新しい順。サムネイル 36pt（写真なしはテキストアイコン）・1行目（要点1行目 → なければアクション1件目 → なければ「メモ」、2行まで）・日付「M月d日」・「…」メニュー（削除）。長押しでも削除。タップしても開かない（保存後のメモ編集は無い）
アクション セクションActionItem の列book.sortedActions の順（流れた → 期限内 → 完了）。下表
メモを追加FAB（右下・44pt・square.and.pencil）ダイアログ「メモを追加」: 撮影して書く／書くだけ／キャンセル
その他ToolbarItem Menu（右上「…」）「テキストで書き出す」／「この本を削除」（破壊的）

アクション行（ActionItem）

要素説明
チェック見た目 16pt・当たり判定 44pt。ActionService.setDone で完了／未完了を切り替え（通知も連動）。流れたアクションにも付けられる
文言タップでその場編集。改行キーまたはフォーカスが外れた時点で確定（空・変更なしは無視）。完了済みは取り消し線＋薄色
期限チップ未完了のときだけ「M/d まで」。流れたら暖色の文字＋「流れた」バッジ。タップで「期限を選ぶ」シート
カレンダー未完了かつ未登録なら calendar.badge.plus（タップで登録シート）。登録済みなら calendar.badge.checkmark（操作不可）
「…」メニュー「期限を変える」／「削除」。長押しの contextMenu にも同じ項目。アクションの削除は確認なしで即時

期限を選ぶシート（DueDatePickerSheet）

プリセット（今日／明日／3日後／1週間）＋ グラフィカルな DatePicker（今日以降のみ）＋「この日にする」。選んだ日の 23:59 を期限にする。 流れた期限を引き直すときは、初期値を今日に寄せる。

カレンダー登録シート（CalendarSheet・medium）

  • 日付の初期値 = 期限日、時刻の初期値 = 9:00。注記「この日に変えると、アクションの期限も同じ日になります」
  • 「カレンダーに登録」で既定カレンダーに「[BookSpark] {アクション}」を30分の予定として作成（書き込みのみの権限を要求）
  • 成功: 「カレンダーに登録しました（削除はカレンダー側で）」を出し 1.5 秒後に閉じる。期限をその日に付け替え、通知許可が未決定ならここで求める
  • 失敗: 「カレンダーへの登録に失敗しました」（BS-ERR-011）

使用するデータモデル

let book: Book
book.memos                      // 新しい順に並べて表示
book.sortedActions              // 流れた（期限昇順）→ 期限内（期限昇順）→ 完了（完了時刻降順）
Action.state / dueDate / isDone / calendarEventID
ActionService.shared            // setDone / updateText / changeDueDate / delete / deleteMemo / deleteBook

実装メモ

  • アクションの状態変更は必ず ActionService を通す（View から isDone.toggle() や NotificationService を直接呼ばない）。規則は BS-F01
  • 読書ステータスの切り替え: 読書中 → 読了は常に可。読了 → 読書中は無料枠を判定（読了で枠を空けて戻す抜け道を塞ぐ）
  • メモ削除・本の削除は確認アラートを出し、ActionService.deleteMemo / deleteBook で配下の通知を解除してから消す
  • ScrollView の中なので swipeActions は使わず、「…」メニュー（44pt）と contextMenu の両方を出す
  • アクション一覧は本の全メモを横断する。どのメモから生まれたアクションかは表示しない
  • ヘッダーの「アクション N/M」は完了 ÷ 全件で、週次の「達成率」とは別物（用語集）
