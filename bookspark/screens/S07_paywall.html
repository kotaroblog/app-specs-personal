Paywall（PaywallView）

買い切り1本（BookSpark Pro）の購入画面。価格は StoreKit の displayPrice だけを出す。

実装済 画面ID: BS-S07

目的・役割

無料枠に当たったとき、または Pro 限定機能に触れたときに開く。一度の購入でずっと使えることだけを伝え、 無料トライアルや利用者数などの訴求文言は置かない。オンボーディングからは開かない。

使用するデータモデル

enum PaywallReason: String { case general, bookLimit }   // notice で一言を出し分け
StoreKitManager.shared.proProduct   // com.happyboy1002.BookSpark.pro（非消耗型）
StoreKitManager.PurchaseOutcome     // success / cancelled / pending / unknown

実装メモ

  • 価格はコードに持たない。Product.displayPrice をそのまま出す（ストアの価格改定・地域差に追従）
  • ローカル確認用の BookSpark.storekit（displayPrice 600）はアプリのバンドルから除外し、scheme 側で指定している
  • 購入・復元の処理と取引の監視は BS-F02
  • ASC 上の非消耗型商品はまだ作成していない（2026-09-26 時点）。作成するまで、Xcode の StoreKit 設定を使わない実行（TestFlight 等）では商品が返らず「価格を取得できませんでした」になる
  • 旧設計の「7日間無料」「1,200人以上」などの文言は v1.0 で削除済み
