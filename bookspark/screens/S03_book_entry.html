本の登録（BarcodeScannerView / ManualBookEntryView）

バーコードで書誌を引くか、手で入力して本を1冊登録する。登録の瞬間に無料枠を判定する。

実装済 画面ID: BS-S03

目的・役割

本を作る唯一の経路。バーコードは速いが失敗しうる（カメラ拒否・書誌が無い）ので、 どの失敗状態からも「手動で登録する」に抜けられるようにしている。 本棚（BS-S02）とオンボーディング（BS-S01）の両方から同じ画面を使う。

UI 構成: バーコードスキャン

NavigationStack のシート。タイトル「バーコードスキャン」、左上に ×（閉じる）。

要素種類説明
カメラプレビューUIViewControllerRepresentable（AVCaptureSession）EAN-13 / EAN-8 を検出。最初の1件だけ受け付け、セッションを止めて書誌取得へ。プレビュー枠はレイアウト変更に追従
書誌の確認VStack表紙（高さ160pt、取れた場合のみ）・書名・著者・「この本を登録する」・「もう一度スキャン」
取得中ProgressView「書籍情報を取得中...」
取得失敗VStack警告アイコン・「書籍情報が見つかりませんでした」・「もう一度スキャン」・「手動で登録する」
カメラ拒否VStackカメラアイコン・「カメラを許可すると読み取れます」・「設定アプリの「BookSpark」からカメラをオンにしてください」・「設定を開く」・「手動で登録する」

UI 構成: 手動登録

NavigationStack のシート。タイトル「手動登録」、左上に ×（閉じる）。

要素種類説明
タイトルTextField（必須）プレースホルダー「本のタイトル」
著者TextField（必須）プレースホルダー「著者名」
ISBN（任意）TextField（数字キーボード）空なら nil で保存
登録するButtonタイトル・著者が空白のみなら無効（グレー）

状態（バーコード・カメラ権限3状態）

状態表示内容
CameraAccess.unknownProgressView。.notDetermined ならこの間に OS の許可ダイアログを出す
CameraAccess.grantedカメラプレビュー
CameraAccess.denied拒否・制限。黒画面にせず案内（設定を開く／手動で登録する）
取得中 → 確認書誌が取れたら確認表示。表示の優先順は 確認 > 取得中 > 取得失敗 > 拒否 > プレビュー
取得失敗通信失敗・該当なしを区別せず同じ表示（BS-ERR-003）

遷移

操作遷移先
この本を登録する／登録する（枠内）本を作成してシートを閉じる。本棚から開いた場合は本棚に戻り、オンボから開いた場合は本の詳細 → メモ編集へ直行
同上（無料枠超過）Paywall（BS-S07）をこのシートの上に重ねる・理由 bookLimit。本は作らない
もう一度スキャン書誌・エラーを消してプレビューに戻る
手動で登録する（バーコード画面内）手動登録シートを重ねる。手動で登録できたらスキャナごと閉じる
設定を開く設定アプリ（UIApplication.openSettingsURLString）
×何も作らずに閉じる

使用するデータモデル

Book(title:author:isbn:coverImageData:)   // status は reading で作られる
BookInfo(title, author, coverImageData)    // Google Books の結果（authors は ", " で連結）
BookLimitChecker.canAddBook(context:)      // 読書中の件数を fetchCount で数えて判定

実装メモ

  • 書誌は GoogleBooksService.fetchBookInfo(isbn:)。https://www.googleapis.com/books/v1/volumes?q=isbn:{読み取った数字} の先頭1件を使い、表紙サムネイルは http を https に置き換えてダウンロードし、Data として本に保存する（URL を持たない）
  • 読み取った数字が ISBN かどうかは検証しない。書籍以外の EAN は「見つからない」になる
  • 無料枠は本棚の＋でも見ているが、登録の瞬間にもう一度判定する（シートを開いたあとに状況が変わっても抜けられない）。判定規則は BS-F02
  • 手動登録は前後の空白（改行は含まない）を削ってから保存する
  • 登録は modelContext.insert のみで、明示的な save() は呼ばない（自動保存に任せる）
  • シミュレーターにはカメラが無いため、バーコードは実機でのみ確認できる
