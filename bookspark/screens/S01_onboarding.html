オンボーディング（OnboardingView）

初回起動時だけ出る。ウォークスルー3ページ → 最初の1冊。登録できたらその本のメモ編集まで直行する。

実装済 画面ID: BS-S01

目的・役割

アプリの型（1ページ分だけ残す → アクションに期限 → 週に一度数える）を3枚で伝え、 最初のメモを書き終えるところまで手数を減らして連れていく。 読まれない質問で手数を増やさないため、パーソナライズ質問は置かない。オンボーディング内に Paywall も出さない。

UI 構成

ステップ1: ウォークスルー

要素種類説明
スキップButton（右上・44pt）ウォークスルーを飛ばして「最初の1冊」へ
ページ本体TabView（page スタイル・標準インジケーター非表示）SF Symbol 56pt・見出し（明朝系 24pt）・説明文。横スワイプでも送れる
ページインジケーター自前の Circle ×3現在ページはアクセント色、ほかは薄いグレー
次へ ／ はじめるButton（幅240・アクセント色）最終ページだけ「はじめる」。押すと「最初の1冊」へ
ページアイコン見出し説明
1square.and.pencil本を読んだら、1ページ分だけ残す要点3つとアクションを、自分の言葉で。写真は添えても添えなくても。
2clock.badge.exclamationmarkアクションには期限がつく3日以内に動く。流れたら流れたと分かる。
3chart.bar週に一度、ふり返る達成と流れたを数える。読書を行動に変える。

ステップ2: 最初の1冊（OnboardingFirstBookView）

要素種類説明
見出しText「最初の1冊を／登録しましょう」＋「登録したら、そのままメモを書きます」
バーコードで登録Button（主ボタン）BarcodeScannerView をシートで開く
手動で登録Button（副ボタン）ManualBookEntryView をシートで開く
あとで登録するButton（テキスト・44pt）登録せずにオンボーディングを終える

状態

状態表示内容
初期表示ウォークスルー1ページ目
ウォークスルー中ページ番号に応じてボタン文言が「次へ」／「はじめる」
最初の1冊ステップ2。シートを閉じただけ（未登録）ならこの画面に戻る
完了hasCompletedOnboarding = true。以後は起動時に表示しない

遷移

操作遷移先
スキップ／はじめるステップ2（同一画面内）
バーコードで登録 → 登録完了本棚 → 本の詳細 → メモ編集（書くだけ）に直行
手動で登録 → 登録完了同上
あとで登録する本棚（BS-S02）の空状態

使用するデータモデル

@AppStorage("hasCompletedOnboarding") var hasCompletedOnboarding: Bool  // UserDefaults
AppRouter.shared.pendingFirstMemoBookID: UUID?   // 最初の1冊の直行先
Book  // S03 で作成される

実装メモ

  • 最初の1冊の直行: 登録シートの onRegistered で AppRouter.pendingFirstMemoBookID = book.id を立て、両シートを閉じてオンボ完了。本棚が出現時にその本を path に push し、本の詳細が onAppear でフラグを下ろして「書くだけ」のメモ編集を開く
  • 登録は S03 と同じ画面を使うので、無料枠判定もそこで通る（この時点では 0 冊なので常に通る）
  • スクリーンショット撮影モード（-uiTestSnapshot）ではオンボ完了フラグを先に立て、本棚から起動する
  • 通知許可はここでは求めない（最初のメモの保存直前に求める。BS-F03）
