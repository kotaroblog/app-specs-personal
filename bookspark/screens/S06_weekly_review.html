週次レビュー（WeeklyReviewView）

今週（月曜始まり）の達成と流れたを数え、達成率と定型のひとことを出す。Pro は過去8週の推移も見られる。

実装済 画面ID: BS-S06

目的・役割

「読んだことを行動に変えられたか」を週に一度だけ数える場所。数えるのは達成と流れたで、 その比率（達成率）を見せる。ひとことは AI ではなく、数字の組み合わせで出し分ける定型文。

統計グリッドの定義

カード数える対象（now = 画面を開いた時刻、週頭 = 今週の月曜 0:00）色
件 今週のメモcreatedAt ≥ 週頭 のメモ通常
個 達成完了済みで completedAt ≥ 週頭アクセント（緑）
個 流れたいま流れていて（未完了・dueDate < now）、dueDate ≥ 週頭1件以上で暖色
個 期限内いま期限内の全アクション（週で絞らない）通常

達成率 = 達成 ÷（達成 ＋ 流れた）を百分率にして四捨五入。分母が0なら nil。期限内は分母に入らない。

今週のひとこと（出し分け）

条件文言
決着0件・メモ0件今週はまだメモがありません。1ページ分でいいので、要点とアクションを残すところから始めましょう。
決着0件・メモ n 件今週は{n}件のメモを残せました。アクションの期限が来るのはこれからです。決めた日に手をつけましょう。
達成率 80% 以上達成率{r}%。読んだことをきちんと行動に変えられています。この粒度のまま来週も続けましょう。
達成率 40〜79%達成率{r}%。半分以上は動いています。流れた{m}件は「いつやるか」を先に決めると通ります。
達成率 40% 未満達成率{r}%。{m}件が流れました。来週は数を減らして、1つに絞ってみましょう。

使用するデータモデル

struct WeeklyStats {
    var bookCount, memoCount, doneCount, overdueCount, openCount: Int
    var totalCount: Int { doneCount + overdueCount }   // 決着
    var achievementRate: Int? { totalCount > 0 ? round(done / total * 100) : nil }
}
struct WeeklyBucket { startOfWeek, doneCount, overdueCount, achievementRate: Int? }
WeeklyHistory.weeklyBuckets(actions:weeks: 8, now:calendar:)   // 古い順・最後が今週

実装メモ

  • 集計は .task で1回だけ（画面を開いている間に完了にしても再計算しない）
  • 週は firstWeekday = 2（月曜始まり）で統一。WeeklyHistory.startOfWeek と Date.weekRangeJapanese は同じ規則
  • 8週推移の各週: 達成 = その週に completedAt がある完了、流れた = 未完了で dueDate がその週にありかつ now より前
  • 流れたアクションを後から完了にすると、流れたから消えて完了した週の達成に移る（過去週の数字も変わる）
  • WeeklyStats.bookCount（読書中の冊数）は計算しているが画面には出していない
  • ひとことの 40〜49% 帯でも「半分以上は動いています」と出る（閾値と文言がずれている）
  • 推移の閲覧可否は EntitlementRules.canSeeHistory(isPremium:)
