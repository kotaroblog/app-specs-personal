本棚（BookShelfView）

アプリのホーム。登録した本を並べ、ヘッダーで「期限内」「流れた」の件数を常に見せる。

実装済 画面ID: BS-S02

目的・役割

本を開く入口であり、流れたアクションが残っていることを毎回目に入れる場所。 旧版の「達成率」チップは、レビュー修正（17e9969）で「期限内 N／流れた N」に置き換えた。 アプリ全体の NavigationStack はこの画面が持つ（通知やオンボーディングから本の詳細を push するため）。

並び順

読書中を上、読了を下。それぞれの中は lastMemoDate（最後にメモを書いた日。メモが無ければ登録日）の新しい順。

使用するデータモデル

@Query private var books: [Book]
// Book.status / lastMemoDate / openActionCount / overdueActionCount / achievementRate

enum ActiveSheet: Identifiable {   // 本棚から開くシートを1本に排他
    case barcode, manual, settings, weeklyReview
    case paywall(PaywallReason)
}

実装メモ

  • シートは ActiveSheet 1状態＋ .sheet(item:) 1本で出す。本の登録ダイアログだけは confirmationDialog
  • ScrollView + LazyVStack では swipeActions が効かないため、削除は contextMenu（長押し）で出す
  • 削除は ActionService.deleteBook 経由（配下の全アクションの通知を解除してから削除）
  • consumeRouterRequests() を onAppear と、AppRouter の2フラグの onChange で呼ぶ。週次通知（pendingWeeklyReview）と最初の1冊（pendingFirstMemoBookID）の2つを処理する
  • ＋の枠判定は @Query の読書中件数で EntitlementRules.canAddBook を呼ぶ（BS-F02）
  • スクリーンショット撮影モードでは .task で SnapshotSeeder.seed がサンプルの本4冊（読書中2・読了2、流れたアクション1件を含む）を投入する
  • チップの件数は state を描画時に計算するため、画面を開いたまま期限をまたいでも再描画されるまで数字は変わらない
