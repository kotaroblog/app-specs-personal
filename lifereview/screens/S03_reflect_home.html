ふりかえりタブ（S03）

週/月/年のリズムカード・道具箱・これまでの軌跡を集約するアプリ中核タブ。

実装済 画面ID: LR-S03

目的・役割

「ふりかえり」タブはこのアプリの中核（★メイン機能）。日々の記録を素材として、 週・月・年の節目に「立ち止まり、言葉にする」振り返りセッションへの入口を提供する。 また道具箱（カレンダー・統計）でデータを俯瞰する機能と、 過去の振り返りを蓄積した「これまでの軌跡」タイムラインへの導線も集約する。

C案規律（グロー禁止・金は線でのみ）: 金面は使わない。「そろそろ」の格上げは 最優先の1枚だけに限り、 goldDim 枠線（1px）＋広い余白（padding 20）＋見出し moonWhite の3点で静かに行う。グロー・星・絵文字は出さない。

UI 構成（ReflectHomeView）

要素種類説明
NavigationStackコンテナ.minchoNavigationTitle("ふりかえり")（明朝インライン）。背景は screenBackground()。
ヒーローブロック（hero）VStack テキスト「すこし、立ち止まって\nみませんか」（明朝 26pt・moonWhite・lineSpacing 16）＋サブテキスト「日々の記録を見返して、心に残ったものを言葉にする時間です。」（14pt・textMuted）。
リマインダー提案カード（ReminderOfferCard）AppCard（goldDim 枠）・条件表示振り返りを完了してホームへ戻った直後にのみ表示。「週に一度、そっとお知らせしましょうか」＋「今はしない」/「設定する」（各 minHeight 44）。カードの表示自体では通知許可を要求しない。
リズムカード群（rhythmCards）VStack（spacing 12）週次・月次・年次の 3 枚の RhythmCard。各カードにタップで振り返りセッション（fullScreenCover）を起動。
区切り線Rectangle（cardBorder 1px）リズムカードと道具箱の間の仕切り。
道具箱セクション（toolbox）VStack + NavigationLinkセクション見出し「道具箱」。カレンダー（LR-TOOLBOX-CAL）・統計（LR-TOOLBOX-STATS）への ToolCard 導線。
これまでの軌跡（trajectory）VStack + NavigationLinkセクション見出し「これまでの軌跡」。振り返り履歴が空なら EmptyStateView（moon.stars・「まだ星のない夜」）。履歴ありなら TrajectoryPreview（最新1件プレビュー）→ ReflectionTimelineView へ。

RhythmCard（リズムカード）の詳細

要素説明
SF Symbol アイコン週次: calendar / 月次: moon / 年次: moon.stars（26pt・常に textMuted）
見出しテキスト「週の振り返り」「月の振り返り」「年の振り返り」（16pt semibold・強調時 onSurface・それ以外 onSurfaceVariant）
「そろそろ」バッジ強調カード（1枚）のみ表示。文字は textMuted に沈め、金は capsule の細罫だけ。
メタテキスト「前回から ○日」／当日なら「前回から 今日」／未実施なら「はじめての振り返り」「今月をふりかえる」「一年をふりかえる」（12.5pt・textMuted）
カード枠線強調: goldDim 1px（padding 20）／通常: cardBorder 1px（padding 16）
chevron.right右端に常時表示（outline 色）

isDue（そろそろ促進）判定ロジック

種別判定条件
週次（weekly）前回の completedAt から 7 日以上経過（または未実施）
月次（monthly）前回の completedAt が今月ではない（または未実施）
年次（yearly）前回の completedAt が今年ではない（または未実施）
強調は1枚だけ（emphasizedType）: 複数が isDue でも、格上げするのは 週 > 月 > 年 の優先順で最初の1種のみ。 最も低コストな儀式から習慣を作るため。3枚とも金罫になると「1画面1点」が構造的に破れる。

サブ画面（ふりかえりタブから遷移）

振り返りセッション（ReflectionSessionView）— fullScreenCover

5 ステップフロー + 完了画面。詳細は LR-SESSION-01 および 機能仕様書 を参照。

stepサブ画面内容
0ReflectionStepReview対象期間のログ一覧を表示（期間ラベル付き）。「次へ」で次へ。
1ReflectionStepChoose「心に残った記録」を複数選択 → ReflectionSession.highlightLogIds に保存。記録0件の期間ではこのステップを飛ばす。
2ReflectionStepPrompts「静かな問い」3 問への自由記述回答。
3ReflectionStepMood期間の総括感情（5 種）を選択。
4ReflectionStepNote気づきの自由記述（任意）＋「振り返りを終える」で保存。
完了画面ReflectionCompletionView星がひとつ灯る（唯一許可するグロー）。「軌跡を見る」「閉じる」ボタン。
STEP 番号は進行位置から動的に振る（2026-07-26）: 記録0件の期間は「選ぶ」を飛ばすため、各ステップ側に番号を固定しているとアイブロウの「STEP n」とプログレス表示（n/m）が食い違う。 activeSteps（0件なら [0,2,3,4]／それ以外は [0,1,2,3,4]）の中での位置から stepLabel と進捗を同じ値で作る。 古い下書きが飛ばすべき step を指していた場合は onAppear で補正し、空画面へ戻さない。
中断＝下書き保存（2026-07-26 変更）: 入力あり（ハイライト選択・回答・感情・ノートいずれか）の状態で閉じようとすると 「振り返りを中断しますか？」アラートを表示し、選択肢は「続ける」／「下書きを保存して閉じる」。 入力内容は端末内（ReflectionDraftStore）に保存され、次回同じ振り返りを開いたときに再開できる（旧仕様の「破棄」から変更）。

リマインダー提案（F12）

項目仕様
表示条件セッションが完了保存され（中断では発火しない）、ホームへ戻った時点で hasOfferedReminder == false かつ reminderEnabled == false。
「設定する」通知許可を要求 → 許可されたら「いま振り返りをした曜日」の 21:00 に週次リマインダーを登録し、AppStorage を更新。
「今はしない」hasOfferedReminder = true にしてカードを閉じる（二度と自動提案しない。以後は設定画面から）。
実装onCompleted コールバックで justCompleted を立て、onChange(of: sessionType) が nil になった時に判定する（完了画面上では出さない）。

使用するデータモデル

// 振り返り履歴（completedAt 降順）
@Query(sort: \ReflectionSession.completedAt, order: .reverse)
private var history: [ReflectionSession]

// セッション起動管理
@State private var sessionType: ReflectionType?   // nil = 表示なし
@State private var justCompleted = false          // 完了保存されたか（中断では立たない）

// リマインダー提案・設定（@AppStorage）
//   hasOfferedReminder / reminderEnabled / reminderWeekday / reminderHour / reminderMinute

// ReflectionSession（SwiftData @Model）
//   var typeRaw: String           // ReflectionType.rawValue
//   var periodStart / periodEnd: Date
//   var moodSummaryRaw: String?   // LogMood.rawValue
//   var answers: [ReflectionAnswer]
//   var highlightLogIds: [UUID]   // ハイライトの唯一の真実源
//   var note: String?
//   var starSeq: Int              // 星図の採番（挿入時に一度だけ）
//   var completedAt: Date

// isDue 判定（例: 週次）
//   Calendar.current.dateComponents([.day], from: last.completedAt.startOfDay,
//                                   to: now.startOfDay).day >= 7
// 強調は1枚だけ
//   [.weekly, .monthly, .yearly].first(where: isDue)

アクセシビリティ対応

  • リズムカードはボタンとして実装（Button + .buttonStyle(.plain)）。VoiceOver は「週の振り返り、ボタン」等で読み上げ。
  • 道具箱 ToolCard は NavigationLink（ボタン扱い）。chevron.right は装飾のためアクセシビリティ非対象。
  • セクション見出し（SectionHeader）には accessibilityAddTraits(.isHeader) を付与（SectionHeader 共通コンポーネント側で設定）。
  • ReflectionSessionView 内の ProgressBar に accessibilityLabel / accessibilityValue を設定。閉じる（×）は 44×44 で .accessibilityLabel("振り返りを閉じる")。
  • 本文・ラベルは scaledFont、見出し・問いは AppFont.mincho(_:relativeTo:) で Dynamic Type に追従。リマインダー提案の2ボタンは minHeight 44。
  • ナビタイトルは principal に自前描画するため .accessibilityHidden(true)。読みは navigationTitle 側に寄せ、二重読みを避ける。

実装メモ

  • ReflectHomeView は NavigationStack を持つ。ReflectionSessionView のみ fullScreenCover（他は NavigationLink push）。
  • セッション完了後の「軌跡を見る」は dismiss + コールバックのパターン（ネストした NavigationStack を避けるため）。onViewTimeline: (() -> Void)? に渡す。
  • navigateToTimeline の navigationDestination(isPresented:) で ReflectionTimelineView へ push する。
  • isDue 判定と meta テキストは ReflectHomeView 内の private func で計算。history（@Query）から latest(_ type:) で最新セッションを取得する。
  • グロー・星エフェクトはセッション完了画面（ReflectionCompletionView）にのみ許可。ReflectHomeView 本体には一切出さない。
  • 背景・ナビタイトルは共通部品（screenBackground() / minchoNavigationTitle(_:)）に寄せる。セッション画面だけは自前の ZStack + grainOverlay()（ナビバーを持たない全画面表示のため）。
