道具箱: 統計

サマリー4カード・カテゴリ円グラフ・感情の移ろい（月別スタック棒）・カテゴリ内訳。

実装済 画面ID: LR-TOOLBOX-STATS

目的・役割

日々の記録（LogEntry）を集計し、カテゴリ分布・記録の積み重なり・感情の移ろいをビジュアルで把握する画面。 振り返りの「道具箱」として「自分はどんなことをよく記録しているか」「感情がどう変化しているか」を俯瞰する用途。 ふりかえりタブ（LR-S03）の道具箱セクションから NavigationLink で push される。

この画面が集計するのは記録（LogEntry）だけ。 振り返り（ReflectionSession）側の集計 —「これまでの振り返り」「振り返った週」「残したハイライト」の3指標 — は これまでの軌跡（LR-TIMELINE-01）が持つ。統計画面には振り返り回数の指標を置かない。
「記録率」は廃止（2026-07-26）。 旧仕様の4枚目は「今月記録した日 ÷ 今月の経過日数」の達成率だったが、 毎日書かない使い方を自動的に「未達」と表示してしまう評価的な指標だった。 現在は totalRecordedDays（記録した日の累計・同一日に何件書いても1日）に置き換えている。 増えるだけで減らない、淡々とした積み重ねの指標にする。

UI 構成（StatsView）

ログが1件以上あるときの縦積み順は サマリー → 円グラフ → 感情の移ろい → カテゴリ内訳（ScrollView / VStack spacing 24 / padding 16）。

要素種類説明
画面の地screenBackground()背景色（night1）＋フィルムの粒（grainOverlay）を一括で敷く共通 modifier。

サマリーカード（4枚）LazyVGrid × SummaryCard総記録数 / 今月記録した日 / 最多カテゴリ / 記録した日（累計）。列数は Dynamic Type に応じて可変（下記）。
カテゴリ別割合（円グラフ）Swift Charts SectorMarkドーナツ型。innerRadius: .ratio(0.5) / angularInset: 1.5 / cornerRadius: 3。高さ 200。見出しは明朝16pt。
カテゴリ凡例LazyVGrid（adaptive minimum 96）円グラフ直下。10×10 の角丸（cornerRadius 2）色サンプル＋カテゴリ名（12pt・textMuted）。breakdown と同じ件数降順で並ぶ（0件のカテゴリは出ない）。
感情の移ろいSwift Charts BarMark（スタック棒）見出し「感情の移ろい」（明朝16pt）＋サブテキスト「直近6か月の記録から」（12pt・textMuted）。グラフ高さ 180。
感情凡例（MoodLegend）LazyVGrid（adaptive minimum 78）グラフの 16pt 下。LogMood.allCases の5種を常に全部表示（その月に出現しない感情も並ぶ）。色サンプル10×10＋ラベル12pt。
カテゴリ内訳リストForEach + HStack件数降順。アイコン（20pt・カテゴリ色・幅24）＋カテゴリ名（14pt）＋件数（14pt semibold）＋割合（13pt・幅56右寄せ・小数1桁）。
空状態EmptyStateViewログ0件時のみ。chart.bar（64pt）＋「記録をつけると統計が表示されます」。この場合サマリー・グラフ・内訳は一切描画しない。

集計ロジック

指標計算方法
totalCount（総記録数）logs.count。全期間・フィルタなし。
breakdown（カテゴリ内訳）全ログを log.category で数え上げ → LogCategory.allCases の順に写す → 0件を除外 → 件数降順ソート。[(category:, count:)]。
topCategory（最多カテゴリ）breakdown.first?.category。ログが0件のときは画面ごと空状態なので実質 nil にならない。
monthlyRecordDays（今月記録した日）今日と同じ year かつ month のログを抽出 → day の Set のカウント。今月内の日数のみ。
totalRecordedDays（記録した日・累計）Set(logs.map { calendar.startOfDay(for: $0.date) }).count。全期間・同一日の複数記録は1日。
割合（内訳リスト）count / totalCount × 100。String(format: "%.1f%%") で小数1桁。totalCount が0なら0。
totalRecordedDays は static func totalRecordedDays(_ logs:calendar:) として View から切り離した純粋関数になっている（カレンダーを引数で受けるためタイムゾーン固定でテストできる）。 ユニットテスト2件（同一日2件＋別日1件 → 2 / 空配列 → 0）で担保。

感情の移ろい（直近6か月）

項目仕様
集計単位MoodMonth { month: Date, counts: [LogMood: Int] }。常に6要素（今月から5か月前まで）を古い→新しい順で作る。
対象ログlog.mood != nil のログのみ。感情タグなしの記録はどの帯にも入らない。
X軸月（"n月"）。AxisValueLabel 11pt・textMuted。
Y軸件数。AxisMarks(position: .leading, values: .automatic(desiredCount: 3))。グリッド線 cardBorder、ラベル10pt・textMuted。
棒（記録あり）LogMood.allCases の順（喜び→充実→穏やか→疲れ→不安）に、件数0の感情は BarMark を出さずに積み上げる。各帯 cornerRadius(1.5) で境界に切れ目を作り、積み上げの対応付けを助ける。
棒（記録なしの月）その月の合計が0なら、高さ 0.4 の薄い土台を1本だけ surfaceContainer 色で描く。「棒がない＝データがない」ことを空白でなく形で伝えるため。
凡例Swift Charts の自動凡例は .chartLegend(.hidden) で消し、自前の MoodLegend（5種固定）をグラフ下に置く。
空状態6か月すべて合計0（＝感情タグ付きの記録が直近6か月に1件もない）の場合、グラフと凡例の代わりに AppCard を1枚表示: 「記録に感情を添えると、／ここに移ろいが見えてきます。」（13pt・textMuted・中央揃え・lineSpacing 7）。

カテゴリ8色（C案・和色の輝度階段）

LogCategory.color。識別は「色相差」＋相対輝度の8段階段で行う（OKLab 明度 0.80→0.52 をほぼ等間隔に配分）。 原色・紫・マゼンタは使わない。彩度は金 #C2894B より必ず低く保つ（金がこのアプリで最も彩度の高い色である序列を崩さないため）。 以前は彩度だけでなく明度も揃えてしまい、8色が狭い輝度帯に密集して experience × creation が実質同一色になっていた。 低彩度の代償は二次符号 — 円グラフの角丸インセットによる隙間・凡例・内訳リストの件数表示 — が支払う。

状態

状態表示内容
ログ0件EmptyStateView（chart.bar 64pt / 「記録をつけると統計が表示されます」）のみ。ScrollView ごと出さない。
ログあり・直近6か月に感情タグなしサマリー → 円グラフ＋凡例 → 感情セクション（AppCard の案内文） → カテゴリ内訳。
ログあり・感情タグありサマリー → 円グラフ＋凡例 → 感情の移ろい（スタック棒＋MoodLegend） → カテゴリ内訳。
6か月のうち一部の月だけ記録がある記録がある月は積み上げ棒、無い月は高さ 0.4 の薄い土台1本。X軸ラベルは6か月分すべて出る。
Dynamic Type 拡大（accessibility1 以上）サマリーカードが2列→1列に切り替わる。凡例の LazyVGrid は adaptive(minimum:) の値が固定（96 / 78）なので列数は文字サイズでは変わらず、幅に応じてラベルが折り返す。

使用するデータモデル

@Query private var logs: [LogEntry]              // 全ログ（期間フィルタなし）
@Environment(\.dynamicTypeSize) private var dynamicTypeSize

// 集計（すべて computed var。ログ件数が少ない前提で毎回計算する）
//   totalCount: Int                              // logs.count
//   breakdown: [(category: LogCategory, count: Int)]  // 0件除外・件数降順
//   topCategory: LogCategory?                    // breakdown.first?.category
//   monthlyRecordDays: Int                       // 今月の記録日の Set カウント
//   totalRecordedDays: Int                       // 記録した日の累計（同一日は1）
//   moodTrend: [MoodMonth]                       // 常に6要素・古い→新しい順

// 感情の月次集計（純粋値オブジェクト）
struct MoodMonth: Identifiable {
    let month: Date                 // その月の startOfMonth
    let counts: [LogMood: Int]
    var id: Date { month }
    var total: Int { counts.values.reduce(0, +) }
}

// 記録した日の累計（テスト可能な純粋関数として切り出し）
static func totalRecordedDays(_ logs: [LogEntry], calendar: Calendar = .current) -> Int {
    Set(logs.map { calendar.startOfDay(for: $0.date) }).count
}

アクセシビリティ対応

  • 3つのセクション見出し（カテゴリ別割合 / 感情の移ろい / カテゴリ内訳）に .accessibilityAddTraits(.isHeader) を付与。VoiceOver のローター見出し送りで各ブロックへ跳べる。
  • サマリーの値・ラベル、凡例、内訳リストのテキストを scaledFont(_:weight:) にして Dynamic Type に追従させる。見出しは AppFont.mincho(16, relativeTo: .headline) で追従。例外: グラフの軸ラベル（Y 10pt / X 11pt）とアイコン（サマリー24pt・内訳20pt）は .font(.system(size:)) の固定サイズのままで、文字サイズ設定には追従しない。
  • サマリーカードは固定高ではなく minHeight 96。文字が拡大しても値・ラベルが切れずカードが伸びる。
  • accessibility1 以上でサマリーグリッドを1列に落とし、2列のまま横方向に潰れるのを避ける。
  • ナビタイトルは principal に自前描画するため .accessibilityHidden(true)。読みは navigationTitle 側に寄せて二重読みを避ける。
  • この画面にタップ可能な要素は無い（閲覧専用）。44pt のタップ領域要件に該当する部品を持たない。

実装メモ

  • Swift Charts（import Charts）を使用。iOS 16+ が必要だが本アプリは iOS 18+ のため問題なし。
  • SummaryCard / MoodTrendChart / MoodLegend は StatsView と同ファイル内の private struct。MoodMonth のみテストとプレビューから触れるよう非 private。
  • breakdown・moodTrend は computed var で毎回再計算する（ログ数が少ないため許容。件数が増えたらメモ化を検討）。
  • 感情グラフの色は .chartForegroundStyleScale ではなく、各 BarMark に直接 .foregroundStyle(mood.color) を指定する。標準凡例は隠して自前の MoodLegend を出すため、スケール定義を持つ必要がない。
  • 背景とナビタイトルは共通部品（screenBackground() / minchoNavigationTitle(_:)）に寄せる。この画面で個別に背景色や grain を書かない。
  • 金（amber / goldDim）はこの画面では使わない。「1画面1点」の金の予算は人生タブの週グリッド「今週」マーカーに割り当てている。

v1.0.0 で実装しないもの

  • 期間フィルタ（今年だけ／去年だけ等）。サマリー・円グラフ・カテゴリ内訳はすべて全期間を対象とし、期間を絞れるのは感情の移ろい（直近6か月固定）だけ。
  • 振り返り頻度のグラフ。ReflectionSession を素材にした集計は「これまでの軌跡」に置いており、統計画面には持ち込まない。
  • グラフのタップによる詳細表示・値ツールチップ。閲覧専用のまま置く。
