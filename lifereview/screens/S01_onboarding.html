オンボーディング（S01）

初回起動時に一度だけ出す1画面。「一行でいい。今日を、ひとつ残す。」と「はじめる」だけで、入力は求めない（1.1.0〜）。

実装済 画面ID: LR-S01 1.1.0 (11)

目的・役割

初めて開いた人を入力なしで、すぐ今日タブの一行入力へ送る。 アプリが「毎日ひとこと（写真は1枚でも）を残し、週末に見返す一言日記」であることを、文と3行の箇条書きだけで伝える。

1.1.0 の変更（2026-10-20・コミット b9a54bf）: 1.0.x では初回画面で生年月日と目標年齢の入力を求め、UserProfile を作ってから始めていた。 「最初に書くまでの距離」が長く、書く前に離脱する原因になっていた（使いやすさの評価 2026-10-20）。 入力を外し、生年月日・目標年齢は人生タブの「人生の時間を表示する」から入れる形に移した（LR-S04 の ProfileSetupSheet）。 このため 1.1.0 以降は UserProfile が無い状態が普通にある（残り時間・人生の週は、入れた人だけに出す）。
表示の条件: @AppStorage("onboardingCompleted") が false（未設定を含む）のとき、 LifeReviewApp の WindowGroup が RootTabView の代わりにこの画面を出す（1.0.x の fullScreenCover ではなく、ルートの出し分け）。 「はじめる」で true にすると、その場で今日タブへ切り替わる。

UI 構成

要素種類説明
全体背景ZStack / Color + grainOverlayAppColors.background で塗り、最上層にフィルムの粒を敷く。暗い表示では Launch 画面と同色（night1）で起動時の白フラッシュを防ぐ。
ウェルカムブロックVStack テキスト群（上余白 88pt）ラベル「人生アルバム」（明朝 15pt・tracking 4・textMuted）＋ヒーロー文「一行でいい。\n今日を、ひとつ残す。」（明朝 24pt・moonWhite）＋サブコピー「毎日ひとこと、写真は1枚でも。\n週末に、その週の一行を見返します。」（13.5pt・textMuted）。
区切りの細罫Rectangle（40 × 1px）warmShadow2。金は CTA に集約するため陰翳の罫にする。上下 36pt。
フィーチャーリストVStack + HStack 箇条書き「毎日、一行と写真1枚で残す一言日記」「週末に、7日分の一行を見返す」「人生の時間の表示は、あとから設定できます」の3行（13.5pt・textMuted）。各行先頭に細線（12 × 0.75px・warmShadow2）。3行目で、生年月日を後から入れられることを先に知らせる。
はじめるボタン（主CTA）LineButton（safeAreaInset .bottom）金は面で塗らない——面＋goldDim 細罫＋amber 文字（minHeight 52pt）。押すと isCompleted = true。常に押せる（入力が無いので無効状態は無い）。

1.0.x にあった入力ヒント・入力カード（生年月日ホイール・目標年齢 Stepper）・現在年齢の表示・バリデーション文言・保存エラーアラートは、すべて ProfileSetupSheet（LR-S04）へ移した。

状態

状態表示・挙動
初期表示文と箇条書きと「はじめる」だけ。データの読み書きはしない。
「はじめる」後onboardingCompleted = true → ルートが RootTabView に切り替わり、今日タブが開く。記録が0件なので今日タブの一行入力に最初からカーソルが入る（LR-S02）。

遷移

操作遷移先
「はじめる」RootTabView（今日タブ）

使用するデータモデル

なし（SwiftData を読み書きしない）。@Binding var isCompleted（= @AppStorage("onboardingCompleted")）を立てるだけ。 UserProfile は人生タブの ProfileSetupSheet で、入れたい人だけが作る（データモデル）。

アクセシビリティ対応

  • 本文は scaledFont、ラベルとヒーロー文は AppFont.mincho(_:relativeTo:) で Dynamic Type に追従する。fixedSize(horizontal: false, vertical: true) で大きな文字でも切れない。
  • ScrollView に載せ、CTA は safeAreaInset(edge: .bottom) で常に画面下に固定する（大きな文字で内容が伸びても押せる）。
  • CTA は minHeight: 52（LineButton 側）。
  • グレインは .accessibilityHidden(true) + .allowsHitTesting(false)。

実装メモ

  • この画面は共通の screenBackground() ではなく、ZStack で背景を自前に敷いて grainOverlay() を直に呼ぶ。
  • 表示の明るさ（明るい／暗い／端末に合わせる）は LifeReviewApp の preferredColorScheme が効くので、この画面も設定に従う（初回は既定の「暗い」）。
  • DEBUG ビルドのサンプルデータ（PreviewSeed）は、RootTabView が出た時点で投入する。
