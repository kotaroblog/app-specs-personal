これまでの軌跡（星図タイムライン）

振り返りの数だけ星を灯す星図・タリー3値（振り返りの数／振り返った週／残したハイライト）・縦タイムライン。

実装済 画面ID: LR-TIMELINE-01

目的・役割

蓄積された振り返りそのものを、このアプリ固有の価値資産として提示する画面。 過去の振り返りを時系列カードで積み上げ、読み返せる「振り返りの軌跡」にする。 「星＝あなたの振り返り」と定義し、C案「ダーク天体」の差別化要素として星図を上部に置く。 壁紙としての星は持たず、振り返り1回ごとに意味のある1粒が灯る。

非評価トーンの規律（2026-07-26）: この画面の数字は「積み上がる」ものだけを出す。 途切れるとゼロに戻る指標（旧「連続した週」）は、進捗に良し悪しを付けない本アプリのトーンの中で唯一の異物だったため廃止した。

UI 構成（ReflectionTimelineView）

要素種類説明
画面の地共通 modifierscreenBackground()（背景色＋フィルムの粒）。minchoNavigationTitle("これまでの軌跡") で明朝インラインタイトルを principal に自前描画。
StarMapViewCanvas 描画各セッションを Star(index: starIndex, type:) に写して渡す。高さ 150、角丸16 + cardBorder 1px 枠。
キャプションText（明朝11.5）「あなたが振り返った夜の数だけ、星が灯る」（textMuted）。星図の下 10pt。
星の凡例HStack（spacing 20）ドット＋ラベルで「週 / 月 / 年」。ドットは実際の描画色・直径（2.2 / 4.0 / 5.6）に一致させる。
タリーカードAppCard（padding 0）3セル横並び。これまでの振り返り／振り返った週／残したハイライト。数値は 24pt semibold・monospacedDigit、ラベル 11pt。セル間は cardBorder 1px（幅1・高さ52）。
縦タイムラインForEach + ReflectionTilecompletedAt 降順で全件。先頭／末尾のフラグを渡して縦罫の描き分けをする。
空状態（emptyNight）枠付きブロック + ボタン「まだ星のない夜」（明朝16・onSurfaceVariant）＋「最初の振り返りを終えると、この空に星がひとつ灯ります。」（12.5・textMuted）。下に「最初の振り返りを始める」ボタン。

レイアウトの余白: 外周 EdgeInsets(top: 8, leading: 16, bottom: 32, trailing: 16)、 キャプション 10 / 凡例 10 / タリー 24 / タイムライン 32 の順に上マージンを取る。

StarMapView 描画仕様

座標の決め方（2026-07-26 全面変更）

星は自分の場所を持つ: 以前は配列インデックスと共有の乱数ストリーム（シード固定の SeededGenerator）から座標を作っていたため、 振り返りを1件足すだけで降順の並びが繰り上がり、空の配置が丸ごと変わっていた。 「振り返った夜の数だけ星が灯る」という約束を守るため、座標は ReflectionSession.starSeq（挿入時に一度だけ採番）だけから決める。
項目仕様
星の数渡された stars の件数（= 振り返りセッション数）。空なら何も描かない。
採番（starSeq）セッションを新規 insert する時に 既存の最大 starSeq + 1 を一度だけ設定。以後変更しない。既定値は -1（未採番）。
未採番のフォールバックstarIndex は starSeq >= 0 ならその値、未採番なら id の先頭8バイトを畳んだ値の % 4096。UUID.hashValue は起動ごとにシードが変わり星が動くため使わない。採番のフェッチに失敗した場合も -1 のままにして、このフォールバックへ委ねる（0 を返すと既存の星と衝突する）。
正規化座標Halton 低差異列。n = starIndex + 1（n=0 は (0,0) になるため1始まり）、x は base 2、y は base 3。
余白（inset）左右 8、上 12、下 24。正規化値をこの内側の矩形に写す。
件数・並び順からの独立座標は他の星の有無・Canvas の高さ・削除・ソート順に一切依存しない。既存の星は動かない。
重なり回避Halton は本質的に均等散布するため棄却サンプリング不要（高さ150のまま200件でも最近接 4.6pt を維持）。
グロー禁止（外周 shadow 相当は一切使わない）。

種別呼称radius（直径）色opacity

monthly（月次）明星2.0（4.0）moonWhite #EAE6DC0.85

タリー集計（TimelineTally）

純粋値オブジェクト。init(sessions:existingLogIds:) で3値を算出する。

表示ラベルプロパティ算出
これまでの振り返りtotalsessions.count（週次・月次・年次の合計）
振り返った週reflectedWeeksweekly セッションの periodStart をその週の月曜 0:00 に正規化し、Set に入れた件数（ユニーク週数）。重複・順序に依存しない。
残したハイライトhighlightCount各セッションの survivingHighlightCount(in: existingLogIds) の総和。元の記録が削除された分は数えない。
「連続した週」は廃止（2026-07-26）: 旧仕様の streakWeeks（降順にひと続きの週数・途切れたら 0）は削除した。 置き換えた「振り返った週」は、統計画面の「記録した日（累計）」と同じ淡々と積み上がる指標。
ハイライト件数は実体ベース（2026-07-26）: highlightLogIds.count をそのまま出すと、元の記録を消しても数字が減らず、 詳細画面（resolvedHighlightLogs 経由の実表示）と食い違う。表示は必ず survivingHighlightCount(in:) を通す。 加えて記録の削除時に LogDetailView 側で highlightLogIds から当該 id を外す（発生源で断つ二重の備え）。

照合用の existingLogIds（Set<UUID>）は画面で @Query を1回だけ引いて作り、 ForEach の外でローカル変数に束ねてからタイルへ配る。計算プロパティのままクロージャ内で参照すると タイル1枚ごとに全ログ分の Set を作り直してしまう。

ReflectionTile（タイムライン1行）

要素説明
行全体NavigationLink（.buttonStyle(.plain)）で ReflectionDetailView へ push。accessibilityIdentifier("reflectionTile.<id>")。
左の縦罫（TimelineRail）幅1・cardBorder の縦線＋ノード（直径5・onSurfaceVariant 0.7・上端から 20）。先頭はノードより上を描かず、末尾はノードまでで止める。
種別バッジ（TypeBadge）「週 / 月 / 年」の一字（明朝11・textMuted）＋ Capsule の cardBorder 細罫。
対象期間週次「M/D – M/D」／月次「YYYY年M月」／年次「YYYY年」（12pt・monospacedDigit・textMuted）。
総括感情あれば SF Symbol を上段の右側に表示（16pt・textMuted）。色分けはしない。
chevron上段の右端に chevron.right（13pt・outline）を常時表示し、タップして開けることを示す。
引用（quote）note が非空ならそれ、無ければ最初の非空 answer。明朝15.5・lineSpacing 8・最大5行。カギ括弧「」のみ amber。上段から 12pt 下。
区切り罫引用とメタ行の間に cardBorder 1px の横罫（上 14 / 下 12 の余白）。
メタ行「ハイライト N」（生存分のみ）／「問い N に回答」／「総括：ラベル」（総括はある場合のみ）。11.5pt・textMuted、数値だけ onSurfaceVariant + monospacedDigit。

振り返り詳細（ReflectionDetailView）

タイルをタップして push する表示専用画面。保存済み振り返りの編集はここでは行わない。

セクション内容

使用するデータモデル

@Query(sort: \ReflectionSession.completedAt, order: .reverse)
private var sessions: [ReflectionSession]

// ハイライトの生存照合用。タイル毎に引くと「タイル数 × 全ログ」になるので画面で1回だけ。
@Query private var allLogs: [LogEntry]
private var existingLogIds: Set<UUID> { Set(allLogs.map(\.id)) }

// ForEach の外で1回だけ束ねてから配る
let logIds = existingLogIds
let tally = TimelineTally(sessions: sessions, existingLogIds: logIds)

StarMapView(
    stars: sessions.map { StarMapView.Star(index: $0.starIndex, type: $0.type) }
)

// ReflectionSession（星図・ハイライトに関わる部分）
//   var starSeq: Int = -1              // 挿入時に一度だけ採番（-1 = 未採番）
//   var starIndex: Int                 // starSeq >= 0 ならそれ／未採番は id 先頭8バイト % 4096
//   var highlightLogIds: [UUID]        // ハイライトの唯一の真実源
//   func survivingHighlightCount(in: Set<UUID>) -> Int
//   func resolvedHighlightLogs(from: [LogEntry]) -> [LogEntry]

// 採番（ReflectionSessionView の保存時・新規 insert のときだけ）
//   session.starSeq = (all.map(\.starSeq).max() ?? -1) + 1

アクセシビリティ対応

  • StarMapView は accessibilityLabel("振り返りの星図")、値は「N件の振り返り。週x件、月y件、年z件」（0件時は「まだ星がありません」）。
  • タリーの各セルは accessibilityElement(children: .combine) で1要素にまとめ、label＝ラベル名／value＝数値。数値と説明が別々に読まれるのを防ぐ。
  • タリー数値は lineLimit(1) + minimumScaleFactor(0.7)。accessibility1 以上では3値を縦積みに切り替える。
  • 本文・ラベルは scaledFont、見出し・引用・問いは AppFont.mincho(_:relativeTo:) で Dynamic Type に追従（小さな装飾アイコンは固定サイズのまま）。
  • ナビタイトルは principal に自前描画するため .accessibilityHidden(true)。読みは navigationTitle 側に寄せて二重読みを避ける。
  • ReflectionTile は NavigationLink（ボタン扱い）。UIテスト用に reflectionTile.<id> の identifier を持つ。

実装メモ

  • StarMapView は SwiftUI の Canvas で静的描画。アニメーションもタイマーも持たない。
  • Halton 列の実装は 2〜3行の整数演算のみ（外部依存なし）。halton(n, base:) が 0..<1 を返す。
  • 背景・粒・タイトルは共通部品（screenBackground() / minchoNavigationTitle(_:)）に寄せる。粒は子ビューへ継承されないため、画面ごとに2行書く運用ではなくこの1行に集約している。
  • ユニットテスト: survivingHighlightCount（生存2・削除1 → 2）と TimelineTally（total 2・highlightCount 1）を検証済み。
  • グローはセッション完了画面（ReflectionCompletionView）にのみ許可。この画面には出さない。
