道具箱: カレンダー

記録の積み重なりをヒートマップで可視化し、日付選択でその日のログを展開する。

実装済 画面ID: LR-TOOLBOX-CAL

目的・役割

振り返りの「道具箱」として、記録（LogEntry）を時間軸で俯瞰する画面。 月カレンダーのヒートマップで「どの日に何件記録したか」を藍の深浅で示し、 日付をタップするとその日のログ一覧を下部に展開する。 振り返りセッションの STEP「見返す」前に下調べする用途にも使える。

金は使わない画面（例外は「今日」の1点）: 記録の「量」を金で語らせない。 ヒートマップは night2 から始まる藍の階段で量を表し、amber は今日を指す 4pt のドットだけに使う。

UI 構成（CalendarView）

要素種類説明
画面コンテナScrollView + VStack（spacing 8）背景は screenBackground()（background + grainOverlay）。タイトルは minchoNavigationTitle("カレンダー")。下端に padding 24。

曜日ラベル行（weekdayLabels）HStack（spacing 0）月曜起点の7列（月・火・水・木・金・土・日）。scaledFont 12 semibold。左右 padding 16。

日付セル（dayCell）Button + RoundedRectangle（角丸 8）記録件数に応じたヒートマップ色で塗る。日付数字（scaledFont 14）とマーカー（4pt）の VStack。maxWidth: .infinity × minHeight: 44。
ヒートマップ凡例（heatmapLegend）HStack（spacing 10）グリッド直下に 5段階すべてのスウォッチ（角丸 3・12×12）＋ラベルを左寄せで並べる。ラベルは scaledFont 10.5・textMuted。
選択日ログ展開（selectedEntries）VStack（spacing 8）日付選択時のみ表示。cardBorder 1px の区切り線＋「金曜日 6/15 — N件」見出し（Date.weekdayWideMD＝曜日は完全形「EEEE M/d」・scaledFont 15 bold・onSurfaceVariant）＋ LogCardView × N。
ログカードNavigationLink + LogCardViewタップで LogDetailView へ push。今日タブと共通のカード部品。

ヒートマップ配色（5段階）

件数トークン16進相対輝度 L備考
0件heatmap0（= night2）#161C28.0115カード面と同じ地の色
1件heatmap1#20293C.0222ヒートマップ専用値（night3 の流用をやめた）
2件heatmap2#26324A.0319
3件heatmap3#3A4A66.0676ここから日付数字を moonWhite に切り替え

heatmap1 を専用値へ切り離した理由: 以前 heatmap1 は押下面トークン night3（#1B2333）を流用しており、 0件（#161C28・L=.0115）との輝度差が .0052 しかなく「0件と1件」が見分けられなかった。 night3 は「沈み／押下面」の意味を持つトークンでヒートマップの尺度とは別物のため、#20293C を専用に切り出した。 現在は 5 段が相対輝度でほぼ均等な階段（.0115 → .0222 → .0319 → .0676 → .1213）になっている。

一般的なカレンダーの「土＝青／日＝赤」は使わない。C案の禁止色（原色）を避け、和色鼠に寄せた土日色を当てている。

カレンダーグリッド計算ロジック

  • 月の1日の weekday（1=日…7=土）から月曜起点のオフセットを求める: offset = (firstWeekday + 5) % 7。
  • totalCells = offset + daysInMonth、rows = ceil(totalCells / 7)。
  • 各マスの日付は day = row * 7 + col - offset + 1。1未満・月末超は Color.clear のプレースホルダ。
  • dailyCounts(year:month:): ログを year × month でフィルタし、日ごとの件数 [Int: Int] を作る。
  • 件数は LogEntry の実体数。ハイライトかどうかは関与しない（カレンダーは「記録した量」だけを見る道具）。

月送りの規約

項目仕様
タップ領域chevron は .buttonStyle(.plain) でパディングが付かず、実効タップ領域がアイコンサイズ（約20pt）しかなかった。44×44 の frame と contentShape(Rectangle()) を明示して確保している。アイコン自体は 18pt 固定。
未来月への遷移表示中が今月のとき「次の月」を disabled にし、色を outline に落とす（未来の空カレンダーへ進めない）。
月を変えたときselected = nil にして選択日を解除する（表示月と展開中のログがずれるのを防ぐ）。
アクセシビリティラベル「前の月」「次の月」。

Dynamic Type の扱い

  • 文字はすべて scaledFont(_:weight:)（基準サイズを保ったまま Dynamic Type に追従する @ScaledMetric ベースの modifier）。.font(.system(size:)) の直書きは chevron アイコンのみ。
  • 日付セルは 固定高ではなく minHeight: 44。文字サイズを上げると行の高さが伸びて数字が切れない。
  • 月外のプレースホルダも同じ minHeight: 44 を持たせ、行の高さが揃うようにしている。
  • 横幅は maxWidth: .infinity の7等分。セルは正方形に固定していない。

状態

状態表示内容
日付未選択（初期）月ナビ＋曜日ラベル＋グリッド＋凡例のみ。selected == nil。
日付選択・記録あり凡例の下に区切り線＋「金曜日 6/15 — N件」（曜日は完全形）＋ LogCardView を件数分表示。
日付選択・記録なし「この日の記録はありません」（scaledFont 14・outline 色・上下 padding 16）。
今月表示中「次の月」ボタンが無効（outline 色）。

アクセシビリティ対応

  • 日付セルの読み上げは「N日、記録N件」＋該当時に「、今日」「、選択中」を連結。数字と塗りの意味を音声だけで判別できる。
  • 月送りボタンは 44×44 の contentShape ＋ accessibilityLabel（「前の月」「次の月」）。
  • 凡例は 5 段すべてを常時表示し、色の濃淡が何件を意味するかを画面上で明示する。
  • 今日／選択中を色だけでなく形（丸／角丸四角）と外周ストロークでも区別する。
  • ナビタイトルは principal に自前描画するため .accessibilityHidden(true)。読みは navigationTitle 側に寄せる。

実装メモ

  • month は常に startOfMonth（その月の1日 0:00）を保持する。
  • 曜日ラベルは固定配列 ["月", "火", "水", "木", "金", "土", "日"]（月曜起点）。
  • ヒートマップ色は AppColors.heatmap0〜4 に集約。View 側に16進を直書きしない。
  • 背景とフィルム粒は screenBackground() の1行に束ねる（背景色 + grainOverlay 2.5%）。
  • ナビタイトルは minchoNavigationTitle("カレンダー")。iOS 26 でカスタムフォントのラージタイトルが描画されないため、ToolbarItem(placement: .principal) に明朝17ptで自前描画している。
  • LogDetailView・LogCardView は今日タブ（Today）と共有のコンポーネント。
  • この画面自体には記録の作成・編集・削除のコントロールを持たない（閲覧専用の道具）。編集・削除は push 先の LogDetailView のツールバーメニューから行う。
