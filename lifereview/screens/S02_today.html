今日タブ（S02）

毎日開いて軽く記録する入口。残り時間ミニ表示・記録 CTA・直近の記録・○年前の今日を集約する。

実装済 画面ID: LR-S02

目的・役割

ユーザーが毎日起動したときの最初の受け皿。「記録する」という行動を最小摩擦で促すことが主目的。 主役は画面最上部の「今日を記録する」CTA。 直近 3 件の記録プレビューと「過去の今日」で、過去の記録との縦断的なつながりも提供する。 残り時間のミニ表示は画面最下部に置き、設定でオフにもできる（有限性を毎日突きつけない）。

C案規律（1画面1点の金）: 金は面で塗らない。CTA は LineButton（night2 の面＋goldDim 細罫＋amber 文字）で立てる。 画面で最も明るい「面」は明朝見出しの moonWhite。グロー効果・星・絵文字は出さない。

UI 構成（上から順）

要素種類説明
NavigationStackコンテナ.minchoNavigationTitle("今日")（明朝インライン・principal 自前描画）。ツールバーの「+」ボタンは廃止（入口は主CTAに一本化）。
背景screenBackground()AppColors.background ＋ フィルムの粒（2.5%）。
「今日を記録する」CTALineButton「square.and.pencil」アイコン＋テキスト（15pt semibold・amber）。面は night2・角丸 14px・goldDim 1px 罫・minHeight 52pt。タップで LogFormView（新規）をシート表示。
今日の記録状態（todayStatusSection）Text当日の記録が1件以上あるとき「今日は○件残しました」（13pt medium・textMuted）。0件のときは何も出さない（空状態は直近の記録セクションが担う）。
直近の記録セクション（recentSection）VStack + ForEach見出し「直近の記録」（明朝 18pt）＋総件数。右端に「記録カレンダー ›」導線（CalendarView へ push）。直近 3 件を LogCardView で表示。各カードは NavigationLink → LogDetailView。記録0件のときは EmptyStateView（moon.stars・「今日のことを、ひとつ残してみませんか」）。
過去の今日セクション（onThisDaySection）VStack + ForEach見出し「過去の今日」（明朝 18pt）。同月日の過年度記録を「○年前」バッジ付きの LogCardView で表示。最大5件。該当が無ければセクションごと非表示。
残り時間ミニカード（RemainingTimeMiniView）NavigationLink → LifeTimelineScreen「のこり時間」ラベル（caption・tracking 2）＋残り年数・ヶ月数（monospacedDigit）＋ThinProgressBar（amber 細線）。タップで人生の週グリッド全画面へ。UserProfile があり、かつ showLifeCountdown == true のときのみ表示。
2026-07-26 の変更（配置と導線）
  • 残り時間ミニを最上部から最下部へ移動し、設定「表示」のトグル（showLifeCountdown）で丸ごと隠せるようにした。毎日開く画面で有限性を先頭に置かない。
  • ナビバーの「+」を廃止し、記録の入口を主CTAだけにした。
  • 「記録カレンダー」導線は文字だけだと押せると分からず、タップ領域も文字高しか無かった。シェブロンを添え、minHeight: 44 + contentShape で 44pt を確保。
  • 「○年前の今日」→「過去の今日」に改称。

サブ画面（Today タブから遷移）

記録フォーム（LogFormView）

要素説明
カテゴリ選択（必須）8種（体験・達成・人間関係・作品・創作・学び・旅・日常の幸せ・その他）を LazyVGrid（adaptive minimum 104）のチップで選択。未選択時は「保存」ボタン disabled。チップは minHeight: 44。
気持ち選択（任意）5種（喜び・充実・穏やか・疲れ・不安）をアイコン＋ラベル縦並びチップで選択（minHeight: 44）。同じチップの再タップでも解除できる。「クリア」ボタンは minHeight: 44 + contentShape でタップ領域を確保。
メモ入力（任意）TextEditor（minHeight 120）。最大 500 文字想定。プレースホルダー「今日、心に残ったことを書いてみましょう」を重ねて表示（allowsHitTesting(false)）。
写真（任意・最大3枚）PhotosPicker（matching: .images・maxSelectionCount は残り枠）。88×88 のサムネイル横スクロール。取り消しの「×」は見た目 20pt のまま当たり判定を 44pt に広げる。実体は ImageStore がアプリ内領域へ保存し、パスのみ imagePaths に持つ。
日付選択（任意）DatePicker（in: ...Date()・displayedComponents: .date）。既定は本日。過去日付への記録も可能。
ツールバー「閉じる」（cancellationAction）・「保存」（confirmationAction）・キーボード上「完了」（フォーカス解除）。
編集モードLogEntry を引数に渡すと編集モード（既存値でフォームを初期化）。タイトル「記録を編集」／新規は「新しい記録」。
  • 未保存の選択済み写真は id で管理する。ForEach(enumerated(), id: \.offset) の index で消すと、2枚の「×」を同時にタップされたとき縮んだ配列に古い index が適用されて範囲外クラッシュする。
  • 保存手順: 新規画像をディスクへ書く → SwiftData を更新 → save() 成功後に取り消された旧画像を削除。save 失敗時は書き込んだ新規ファイルを掃除して rollback()。
  • チップの文字色にカテゴリ色を使わない（暗い色が night2 面で本文可読性に届かないため）。識別は色罫（不透明度 0.4／選択時 lineWidth 2）＋面 0.14 が担う。

記録詳細（LogDetailView）

要素説明
ヘッダーカテゴリアイコン（48px 円バッジ・カテゴリ色 14%透過）＋カテゴリ名＋感情タグ（任意）。
本文テキストentry.content が空でない場合のみ表示。
添付写真96×96 サムネイルの横スクロール。タップで PhotoViewer（fullScreenCover・左右スワイプ切替）。
ツールバーメニュー「ellipsis.circle」メニューボタン → 「編集（pencil）」「削除（trash・destructive）」。削除は確認アラートを経由。
タイトル日付（ymd フォーマット）を明朝インラインで表示。
削除時の cascade cleanup（2026-07-26 追加）: 記録を削除する際、その id を参照している全 ReflectionSession の highlightLogIds からも id を取り除く。 表示側も生存照合しているので二重の備えだが、参照を残すと「消えた記録の id」が振り返りに永久に溜まり続けるため発生源で断つ。 掃除に失敗しても削除自体は続行し、Logger にのみ記録する。
削除順序: ハイライト参照を外す → modelContext.delete → save() 成功後に画像ファイルを消す（失敗時は rollback するのでファイルは残す）。

使用するデータモデル

// TodayView — 読み取り専用
@Query(sort: \LogEntry.date, order: .reverse) private var logs: [LogEntry]
@Query private var profiles: [UserProfile]
@AppStorage("showLifeCountdown") private var showLifeCountdown = true

// 直近 3 件
private var recent: [LogEntry] { Array(logs.prefix(3)) }

// 当日の記録
private var todayLogs: [LogEntry] { logs.filter { Calendar.current.isDateInToday($0.date) } }

// 過去の今日（同月・同日かつ今年より前）。logs は date 降順なので
// prefix で「最も近い過去の年」から順に残る。最大 5 件。
private static let onThisDayLimit = 5

// LogEntry（SwiftData @Model）
//   var date: Date

アクセシビリティ対応

  • 残り時間ミニカード: .accessibilityElement(children: .combine) ＋ .accessibilityLabel("のこり時間") ＋ .accessibilityValue("\(years)年\(months)ヶ月")。
  • セクション見出し（「直近の記録」「過去の今日」）: .accessibilityAddTraits(.isHeader)。
  • LogFormView のカテゴリ／気持ちチップ: .accessibilityAddTraits(isSelected ? .isSelected : [])。写真の取り消しは .accessibilityLabel("写真を外す")、詳細のサムネイルは「写真○枚目」。
  • LogDetailView のメニューボタン: .accessibilityLabel("記録の操作メニュー")。PhotoViewer の閉じるは「閉じる」。
  • Dynamic Type: 本文・ラベルは scaledFont（基準サイズを保ったまま追従）、見出しは AppFont.mincho(_:relativeTo:)。
  • 44pt タップ領域: 主CTA（minHeight 52）・記録カレンダー導線・カテゴリ/気持ちチップ・気持ちの「クリア」・写真の取り消し。

実装メモ

  • TodayView は NavigationStack を持つ。今日タブ内のすべての遷移はこの NavigationStack 内で完結する。
  • 背景は共通の screenBackground()（背景色＋グレイン）。ナビタイトルは minchoNavigationTitle(_:)。この2つを画面ごとに手で書かない（漏れを構造的に防ぐための共通部品）。
  • LogFormView は新規・編集兼用。entry: LogEntry? = nil が nil なら新規、non-nil なら編集。
  • onThisDay の計算は @Query の結果（逆順全件）をフィルターしているため、記録件数が増えると計算コストが上がる。将来的にはクエリを分離すること。
  • PhotoViewer には screenBackground() を付けない。 グレインは白ノイズを .overlay 合成で乗せるため、明るい写真のハイライトを飛ばす（素の黒地のまま）。
