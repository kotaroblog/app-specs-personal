LifeReview（人生アルバム）

一言日記・写真日記と、週末の振り返り · Bundle ID: com.happyboy1002.LifeReview

概要

  • カテゴリライフスタイル / 仕事効率化（App Store 提出時に選択）
  • 対応OSiOS 18.0+
  • 言語日本語のみ（ローカライズファイルを持たず、locale も ja_JP 固定）
  • マネタイズv1.0 は無料・広告なし。実ユーザーデータを蓄積後、v1.1 以降で課金/広告を設計
  • ストア表示名一言日記・写真日記 - 人生アルバム（サブタイトル「一行でいい。週末の振り返りと気分ログ」。1.0.2 で変更）
  • ステータス公開中は 1.0.2（1.0.0 を 2026-09-02 に公開）。1.1.0 (11) を TestFlight 配信済み・未公開（2026-10-24。ブランチ improve/score80-2026-10。内容は下の「1.1.0 の変更」）
  • 技術スタックSwift 6 / SwiftUI / SwiftData / XcodeGen（2026-06-15 に Flutter から全面移行済み）
  • デザインテーマC案「ダーク天体」— 墨と藍、琥珀の真鍮、明朝×ゴシック二層。1.1.0 で明るい表示（書斎トーン＝生成りの紙・墨藍の文字・濃い真鍮）を追加（既定は暗い表示のまま）
コンセプト一文:「記録するアプリ」から「定期的に立ち止まり、人生を振り返るアプリ」へ。
日々の記録は素材集め。アプリの主役を 週次・月次・年次の振り返り（リフレクション） に据える。

デザインシステム補足（共通ナビゲーションUI）

2026-07-26 改訂: iOS 26 では UINavigationBarAppearance.largeTitleTextAttributes にカスタムフォントを載せてもタイトルが描画されず、 全タブが「タイトル分の余白だけ空いた無題画面」になっていた。Appearance でのフォント指定をやめ、 タイトルは ToolbarItem(placement: .principal) に自前で置く方式（minchoNavigationTitle(_:)）に変更した。
要素仕様
ナビゲーションバー背景ダーク天体背景色（night1: #10141C）。UINavigationBarAppearance で configureWithOpaqueBackground() + backgroundColor = UIColor(AppColors.night1)。
タイトルの描画方式Views/Shared/MinchoNavTitle.swift の minchoNavigationTitle(_:)。ToolbarItem(placement: .principal) に AppFont.mincho(17, relativeTo: .headline)・kerning 0.8 の Text を置く。VoiceOver の二重読み上げを避けるため accessibilityHidden(true) を付け、戻るボタンのラベルと読み上げ用に navigationTitle 自体は残す。
明朝フォントHiraMinProN-W3（AppFont.swift）。W6 は使わない。
Appearance 側の役割背景色と文字色（moonWhite）のみ。フォント指定は持たせない。
tint（戻るボタン・ツールバー）moonWhite（#EAE6DC）。.tint(AppColors.moonWhite) と bar.tintColor = AppColors.moonWhiteUI。
以前は amber だったが、それだと人生タブの設定歯車が金になり、同画面の週グリッド「今週」マーカーと合わせて金が2点になる。「1画面につき金は1点」というアートディレクション規律に反するため月白に落とした。
大タイトル使わない。全画面 .navigationBarTitleDisplayMode(.inline)。

Launch 画面

コールドスタート時の白フラッシュを抑止するため、Launch 画面をダーク天体の基調背景色（night1: #10141C）で塗る。 実装は project.yml の UILaunchScreen に UIColorName: LaunchBackground を指定する方式で、 storyboard は使わない。カラーセット LaunchBackground.colorset が実体。 オンボーディング画面の背景も同色で統一されているため、起動から最初の操作まで一貫したダーク天体体験になる。
