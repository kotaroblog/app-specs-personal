ゲームプレイ画面

SceneKit を使った 3D ボクセルワールドのメインプレイ画面。操作・HUD・各種モーダルを含む

画面ID: VG-GAME-01

目的・役割

ゲームの中核となる画面。SceneKit のレンダリングレイヤー（SCNView）の上に SwiftUI の HUD・操作ボタンレイヤーをオーバーレイする構成をとる。2026-09-16 の建築特化への転換で、この画面の主題は「生き延びる」から「素材を集めて建てる」へ変わった。既定視点は一人称で、メニューから三人称へ切り替えられる（三人称のときだけカメラ距離を選べる）。サバイバルとクリエイティブの2モードは引き続き切り替え可能だが、サバイバル側から体力・空腹・死亡は無くなっている。

HUD（ヘッドアップディスプレイ）

要素位置説明
メニュー／クラフトボタン左上常時表示は2つだけ。低頻度操作（視点・距離・モード・作品カード・目印・設定・終了）はメニューへ集約し、高頻度のクラフトのみ独立させている
天気アイコン右上晴れ/雨/雪。日付の変わり目に 70%/20%/10% で自動変化（体力・空腹バーは廃止済み）
クリエイティブ表示右上クリエイティブ時のみ天気アイコンの隣に「∞」を表示
探索HUD右上時間帯・方位・高度・バイオームのラベル
ビーコン／目印右上設定した目印・ランドマークの方角と距離
パフォーマンス表示右上（下段）設定でONの場合のみ FPS・メモリ(MB)・チャンク数・初回生成時間を等幅小型テキストで表示
ツールバー2段目解放済みツール（素手＋ツルハシ3種）を横並びで選択する行。剣は廃止したため並ばない
目標ガイド3段目6段階の目標を1件だけ表示。既定は展開（アイコン＋タイトル＋進捗バー＋操作/場所ヒント）、タップで折りたたみ。目標が進むと6秒だけ自動展開する。クリエイティブ時は非表示。詳細は目標ガイド
ホットバー下部固定5枠（石 / 板材 / 石レンガ / ガラス / 松明）＋固定枠外を選択中のときだけ出る追加枠＋所持品ボタン。枠数は390pt端末の可視幅から決めた算術上の上限
照準（クロスヘア）中央画面中央に固定表示。採掘進捗リングと連動
設置プレビュー（ゴースト）3D空間置ける場所は選択中ブロックの色、置けない場所は赤の半透明立方体。設置不可・在庫0・設備を狙っているときは出さない

シートトリガー内容

クラフト画面クラフトボタンツールレシピ3種とアイテムレシピ8種（設備4＋建材4）。詳細はクラフト
かまどかまどブロックをタップ鉄鉱石/金鉱石/砂/石 をそれぞれ 鉄インゴット/金インゴット/ガラス/レンガ へ即時精錬（燃料：石炭）
チェストチェストブロックをタップ中身一覧（容量制限なし）。1個/半分/全部単位で出し入れ
メニュー（ポーズ）メニューボタン視点（一人称⇔三人称）・距離（三人称時のみ。近い5m/中12m/遠い25mをタップで巡回）・モード（確認ダイアログ付き）・作品カード・目印の設定/解除・設定・終了して戻る
作品カードメニュー → 作品カードワールド名・累計設置ブロック数・制作日数・よく使った材料 上位3種・直近14日の設置数バー。詳細は作品カード
設定画面メニュー → 設定マスター音量・視点感度・移動デッドゾーン・採掘ボタン強調・左利き配置・操作ボタンサイズ・操作方法を再表示・パフォーマンス表示・画質プリセット・実験的設定（検証用）

Dynamic Type（最大文字サイズ）対応: 各モーダルは ScrollView でラップされ、最大文字サイズでも全項目・全ボタンへ到達できる。メニューは三人称時に最大7行となり標準文字サイズでもスクロールが必要になるため、スクロールインジケータを常時表示する。

状態

状態表示内容
初回ワールドロード中黒オーバーレイ＋「ワールドを生成中…」＋ProgressView。初回同期ロード分のメッシュ適用完了でフェードアウト（保険として入場8秒で強制解除）。表示中は入力を遮断
初回操作ヒント初めてプレイする場合のみ「視点操作」→「移動」→「採掘」の3段ヒントを各3秒ずつ順送り表示（設定から再表示可）
サバイバルモード採取と在庫の消費が有効。体力・空腹・落下/溶岩/サボテンのダメージ・死亡は存在しない
クリエイティブモード「∞」表示。飛行（上下ドラッグで昇降、Y0〜63にクランプ）・破壊0.05秒・所持数を消費しない・所持品は全ブロック・目標ガイド非表示
目標達成時チャイム＋上部中央に達成バナー（「次は『○○』」＋操作ヒント）。折りたたみ中でも6秒だけ目標が自動展開する
ブロック破壊中照準ブロックにひび割れオーバーレイ（4段階、閾値0.25/0.5/0.75）。完了時にブロック色の破片パーティクルがバースト
シート表示中ゲームループを一時停止（カメラ・チャンクストリーミング・メッシュ適用のみ継続）。昼夜サイクル・動物の更新・採掘進行が停止し、操作コントロールは無効化

遷移

操作遷移先
メニュー → 終了して戻る（確認ダイアログで「保存して戻る」）ワールド選択画面へ pop。進行状態を保存し、最終プレイ日時を更新してから遷移する
各シートを閉じるゲームプレイ画面に戻る（ゲームループ再開）
メニュー → 作品カードメニューを閉じて作品カードを表示

所持品・解放ツール・進行フラグ・設置の集計（PlacementTally）とUI状態（GameInput）の詳細はデータモデルを参照。

実装メモ

  • SCNView を UIViewRepresentable でラップし、SwiftUI の ZStack 上に HUD をオーバーレイする構成をとる
  • ゲームループは Coordinator（SCNSceneRendererDelegate）の renderer(_:updateAtTime:) で毎フレーム実行する
  • 入力は GameInput（NSLock保護のrequestXxx/consumeXxxパターン）でUIスレッドとレンダースレッドを仲介する
  • シート表示中は GameInput の isPaused ミラー経由でレンダーループを早期 return させる
  • ホットバーのブロックアイコンは TextureAtlas（起動時コード生成の1枚絵）から切り出して表示する
  • ホットバーの横スクロール位置は保存し、追加枠から別ブロックを選び直したときに古い追加枠へ戻らないよう補正する
  • セッション統計（所持品シートを開いた回数・スポイト/アンドゥ回数・夜間の設置数など）はワールドに保存せず、退出時に Logger へ1行出力するだけの内部計測である（ユーザー向けの表示は無い）
