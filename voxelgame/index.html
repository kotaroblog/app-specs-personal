CraftFrontier

Swift 6 / SwiftUI / SceneKit 製の レトロボクセル・建築ゲーム（旧称 VoxelGame） · Bundle ID: 未定

概要

素材を集め、自分の作品を建てるためのボクセルゲーム。2026-09-16 にサバイバル型から建築特化へ全面転換し、戦闘・体力・空腹・死亡を廃止した。「自分の作品・アートを作る」という作り手の動機と、サバイバル実装（戦闘・生存）の方向がズレていたためである。設計の核心は「達成感の源泉は危険を越えることではなく、不可逆な投資（量と時間）が目に見えること」（Fable 5.1、2026-09-16）で、目標ガイドの終着点も作品カードの表示も「これまでに置いた量」に置き換えている。2026-09-27 以降は「決まった地図」を増やす方針（本人）で、ステージ「岬の灯台」・島の世界・群島の世界（本島と雪山の島を船で渡る）を足している。2026-10-26 からは、ステージと別に自由に遊ぶワールドの3マップ（群島・密林・渓谷）を高さ128・体力と満腹あり（死なない作り）・水車の機械とトロッコつきの正式な形で作っている（本人決定。ステージは建築特化の決まりのまま）。

  • カテゴリゲーム / シミュレーション（建築）
  • 対応OSiOS 18.0+
  • 言語日本語
  • マネタイズ未定
  • ステータス開発中（TestFlight build 54 を 2026-10-28 に配信。その後ワニ＝密林の段6を main に入れた）
  • リリース予定未定
  • 技術スタックSwift 6 / SwiftUI / SceneKit / SwiftData
本ポータルの内容は2026-10-28 時点の実装（TestFlight build 54 と、その後 main に入れたワニ）を反映したもの。将来の拡張予定は原則として書かない（設計はリポジトリの docs/ の設計案＝密林・群島の作り直し・渓谷・運ぶ遊び・水車工房・ステージの2作目が正）。
