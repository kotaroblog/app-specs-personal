ワールドの決まり

ワールドの3マップ（群島・密林・渓谷）で共通に使う決まり: 持ち物36枠・体力と満腹・道具の段・畑の水・食べ物・罠と飼育・ワニ・暮らしの道具

機能ID: VG-FEAT-WORLD-RULES

概要

2026-10-26 の本人決定で、ワールド（ステージ以外の自由に遊ぶ地図）は「高さ128・体力と空腹あり・動物を捕まえる罠あり」の正式な形で作り直すことになった（CF84・CF85・CF90）。ここに書く決まりはワールドの決まりを使うワールドだけにかかり、ステージ・以前に作った群島・島・どこまでも続く世界は今のまま（建築特化の決まり）。

  • かかるワールド密林・渓谷・新しく作った群島（terrainLift > 0）。判定は WorldRecord.usesWorldRules
  • かからないものステージ6つ・2026-10-28 より前に作った群島・島・どこまでも続く世界・試作の水車工房（畑の水だけはかかる）
  • 考え方マイクラと同じ考え方に寄せる（本人 10-27「マイクラ方式を採用でいきましょう」）。ただし死なない作り（体力は落下・溺れ・空腹で1まで）

関連画面

  • ゲームプレイ画面（ホットバーの上の体力・満腹・息のゲージ・食べる・ロープでつなぐ）
  • ホーム（新しいワールドの種類）
  • 地形生成（3マップの地形）
  • 機械とトロッコ / 杭とひな形・作品カードの画廊

持ち物（36枠・1枠64）

項目決まり
枠36枠（手元9＋袋27）。ブロック・素材はどれも1枠64、道具は重ねない。背負い袋など枠を増やす手段は置かない（本人 10-27）
いっぱいのとき掘った物は6マス以内のチェスト・樽へ入る。近くに無ければ壊さずに「持ち物がいっぱいです」と知らせる（CF86 b）。満杯なら掘り始めに知らせる
作る・焼く・出すチェストから出す・作業台で作る・かまどで焼くも入る分だけ。できた物が入らないときは作業台・かまどに残し、空いたら受け取る（CF-052・053）。空き枠は描画スレッド側の正の写しで数える
機械機械の出す先のチェストがあふれた物は、機械が覚えた中身へ足す（失わない）
ステージ上限なし（ステージにはかけない。本人 Q10）

体力・満腹・息

項目値
体力・満腹どちらも10。ホットバーの上にゲージ（息は水の中だけ）
満腹が減る動いた量が360たまると1減る。毎秒の量は 掘る・走る1／泳ぐ・登る0.5／歩く0.25。立っているだけなら減らない
空腹満腹0のとき30秒ごとに体力1減るが、1で止まる（死なない）
回復満腹6以上のとき30秒ごとに体力1
落下3.5マスを超えて落ちると、超えた分2マスごとに1。浅い水への着地は落下にしない
溺れ息は15秒で尽き、そのあと2秒ごとに体力1
ワニ噛まれると2（下記）。体力が0になる原因はワニだけ（落下・溺れ・空腹は体力1まで）

倒れたとき

  • 持ち物を「持ち物の袋」（Block 226 lostBag）に入れてその場に置き、地図に目印を出す。袋は開けて取り出すか、壊すと中身ごと戻る。袋は持ち上げられない
  • ベッド（無ければ最初の場所）で起きる。道具は持ったまま。倒れたらすぐ保存する
  • 最上段で倒れても袋は落ちない位置に置く
stateDiagram-v2 [*] --> 元気 元気 --> 空腹: 満腹0 空腹 --> 元気: 食べる 空腹 --> 空腹: 30秒ごとに体力-1（1で止まる） 元気 --> 倒れた: ワニで体力0 空腹 --> 倒れた: ワニで体力0 倒れた --> 元気: ベッドで起きる（袋と目印を残す）

道具の段（マイクラ式・CF6）

  • ワールドの決まりを使うワールドでは、段の低いツルハシで掘れない鉱石がある: 木のツルハシでは鉄・銅、石のツルハシでは金・ダイヤが掘れない
  • ステージは今まで通り、段の違いは掘る速さだけ
  • 斧・シャベル・鉈は作らない（ツルハシ1本。本人 10-27 Q19）。下草・つる・葉・木・狩りもツルハシか素手

畑の水

耕した土から横4マス以内（畑と同じ高さか1段上）に水があると小麦が育つ。無いと育つのが止まる（枯れない）。ワールドの決まりを使うワールドと水車工房にかかる。以前に作ったワールドは今のまま水なしで育つ。

食べ物

食べ物を選んで置くボタン（「食べる」）を押すと食べる。満腹でも、煮込みの効き目が切れていれば煮込みは食べられる。

食べ物満腹手に入れ方
ベリー+2林床のベリーの茂みを摘む（2つ）。実のない茂みが残り、夜明けにまた実る
バナナ+3密林の大木の3本に1本（幹の西・根の上）の房を摘む（2つ）。茎が残り夜明けにまた実る
卵+2鶏が夜明けに足元へ産む（CF87）。数に上限あり
生の肉 / 焼いた肉+2 / +6動物を倒す → かまどで焼く
生の魚 / 焼いた魚+2 / +5魚の罠 → かまどで焼く
パン+5小麦 →（製粉機）小麦粉 → かまど
煮込み+8 と10分間 満腹が減らない作業台で 焼いた肉1＋ベリー2＋小麦粉1。満腹の横に残りの時間を出す。Block 256（2バイトの番号の最初のブロック）

狩り・罠・飼育

項目決まり
狩り壊すボタンで手前の動物を叩く。与える量は 素手1・木2・石3・鉄4、動物の体力は 鶏2・羊4・豚5・牛6。倒すと生の肉。つないだ動物は叩かない
魚の罠繊維4で作る。水の横に置くと夜明けに魚が入る（魚の入った罠を壊すと生の魚2と罠）
くくり罠板2＋ロープ1。踏んだ野生の動物が動けなくなる（通り抜けられる）。数に上限あり
つなぐロープを持って［ロープでつなぐ］と付いてくる
増やす小麦の餌を2匹にやると1匹増える（30秒以内・4マス以内・増えたら5分は食べない）
保存飼った動物は保存する（上限24。tamedMobsData）。野生は64m 離れると消え、近くに湧く
素材下草を刈ると繊維1・つるは繊維2。繊維3→ロープ

ワニ（密林だけ・段6）

  • 密林の川辺にだけ湧く（地面は草・土・砂・泥、5×5に地面と同じ高さの水が6マス以上、ほかのワニから8マス、最大2匹）。ふつうの湧きには混ぜない
  • 寝ていて動かない。3マス以内（高さの差2未満・間に壁が無い）に入ると、0.7秒置いてから噛む（体力-2・1.5秒ごと）。離れれば追わない。船・リフト・トロッコに乗っている間は噛まない
  • 壊すボタンで叩いて倒す（体力8）と、生の肉2とワニの皮1。くくり罠にかかると動けず噛まない。飼えない（ロープ・餌の操作も出さない）
  • 皮の使い道は皮の敷物（皮2→1。床に敷く飾り・上を歩ける）。背負い袋は作らない（本人 10-27）

上り下り（つる・はしご）

  • つる（密林）: 中にいて前へ進むかジャンプで登る（秒速3）・離すと秒速1.5で滑り下りる・てっぺんで上の段へ出る
  • はしご（渓谷の決定で追加・どのワールドでも作れる）: 板3→3。壁の横の面に付け、つると同じ操作で上り下りする。渓谷の花崗岩の山には付けない
  • 下草は中を歩くと半分の速さ

暮らしの道具（群島の段5・CF78）

物決まり
焚き火丸太3＋石炭1。夜の灯り。［使う］で座ると時間が12倍で進む（動くと立つ）。新しい群島はスポーン地点の右前に消えた焚き火があり、［使う］で火が入る（保存値 0x04 が消えた焚き火）
ジョウロ銅3。水を汲むと水入りに。まわり3×3の作物・苗木・実った後の茂みを1段育てる
身じたくメニューから開く。帽子3種をその場で作る（麦わら＝小麦3・毛糸＝羊毛2・鉱夫のヘルメット＝鉄3＋松明1＝頭の灯り）。上着を染料1つで7色に。帽子と上着はブロックにしない（outfitData）

ビジネスルール

  • ワールドの決まりは新しく作ったワールドだけにかける。以前の保存データのワールドは遊び方を変えない（既定値 terrainLift = 0 で判定）
  • 死なない作り: 落下・溺れ・空腹では体力1で止まる。家畜の餌切れで死ぬ仕様は入れない（本人 10-27）
  • 追いかけてくる敵は入れない。縄張り型のワニ1種だけ

エラー処理

  • 体力・満腹（survivalData）・飼った動物（tamedMobsData）が読めないときは既定値で始める（ワールドは開く）
  • 飼った動物が上限24を超えて保存されていたら、超えた分は戻さずログに残す

実装メモ

  • 判定: WorldRecord.usesWorldRules（密林・渓谷・terrainLift > 0 の群島）。GameSceneView で枠の上限・体力・飼育・トロッコの読み込みをこの印で切り替える。ワニは worldKind == .jungle のときだけ湧かせる
  • 体力・満腹: SurvivalState（JSON）。ワニ: MobType.crocodile。飼育の上限 MobManager.maxTamed = 24
  • 初期の持ち物: 密林は木のツルハシ、渓谷は木のツルハシ・パン3・板8
