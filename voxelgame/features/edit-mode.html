編集モード

置いたブロックを配置しなおす操作。置き換え・持ち上げて別の場所へ置く・置いたまま回す

機能ID: VG-FEAT-EDIT

概要

本人の要望（2026-09-27「ブロックを配置しなおす操作もできたらすごくいい」）から入れた操作（CF17）。本人の決定で a 置き換え・b 向きの変更・c 移動のすべてを、編集ボタンで切り替える方式にした。編集モードのあいだは、緑のボタンが「置き換え」（持ち上げ中は「ここに置く」）、赤のボタンが「持ち上げる」になり、回せる物を狙うとスポイトの位置に「回す」が出る。

置き換え・持ち上げは壊すのと同じ時間がかかる（地形の石を一瞬で取れる抜け道を作らない）。クリエイティブは一瞬（0.05 秒）。回すはどちらも一瞬。

関連画面

  • ゲームプレイ画面（編集ボタン・置く／壊すボタン・回すボタン・十字の下の案内）

処理フロー

sequenceDiagram participant U as User participant GI as GameInput participant GV as GameSceneView participant CM as ChunkManager U->>GI: 編集ボタン（isEditMode = true） Note over GI: 押している途中の操作をすべて止める U->>GV: 赤「持ち上げる」を長押し GV->>GV: holdBlockedReason（できない理由があれば1回だけ知らせる） loop 壊すのと同じ時間 GV->>GV: 進捗を進める end GV->>CM: detachBlock（向き・チェストの中身を控えて外す） GV->>GI: setCarried（持ち上げ中。所持品にも世界にも無い） U->>GV: 紫「ここに置く」 GV->>GI: takeCarried alt 置ける GV->>CM: 持ち上げたときの向き・中身のまま置く else 置けない GV->>GI: setCarried（持ち上げたままに戻す）・理由を知らせる end U->>GI: 編集ボタン（isEditMode = false） GI->>GI: 持ち上げ中の物があれば所持品へ戻す

切り替えと表示

項目仕様
編集ボタン鉛筆の丸（pencil.circle。オンは塗りつぶし・紫・白い地）。44pt。読み上げ「編集モード」・値「オン／オフ」・ヒント「オンにすると、置き換え・持ち上げる・回すが使えます」
切り替えたとき押している途中の「壊す／持ち上げる」「置き換え」「ジャンプ」をすべて止める（同じボタンの意味が変わるため。残すと、オフにしたあと持ち上げのつもりで掘り続けたり、オンにした瞬間に押していないのに置き換えが進んだりした）。VoiceOver のトグルも止めた状態へ戻す
オフにしたとき持ち上げ中の物があれば所持品へ戻し「持ち上げていた◯◯を所持品に戻しました」（置く手段が無くなるため）
赤のボタン「壊す」→「持ち上げる」
緑のボタン持ち上げていないとき＝長押しの「置き換え」。持ち上げ中＝紫の「ここに置く」（読み上げ「持ち上げた◯◯をここに置く」）
回すボタン編集中に回せる物（階段・1マスの家具）を狙っているあいだだけ、スポイトの位置に出す（arrow.clockwise）
十字の下の案内持ち上げていないとき「編集中 ─ 長押しで［置き換え］［持ち上げる］」、持ち上げ中「持ち上げ中：◯◯ ─ 置く場所を狙って［ここに置く］」（紫の地）
編集中に出さないもの使える物（作業台・チェスト・船・リフトの乗り場など）を狙ったときの「使う／乗る」（緑は置き換えなので）。羊の毛刈りもしない（CF-015）

操作

操作入力結果
置き換え緑を長押し（壊すのと同じ時間）狙ったブロックを、選んでいる建材にその場で差し替える。向きは今の向き（通常の置き方と同じ）。元のブロックは所持品へ戻り、選んだ建材を1つ減らす。クリエイティブは所持品を動かさない。🔴 中身の入ったチェストは置き換えられない（2026-10-02 本人決定・CF-028。クリエイティブで中身が所持品へ戻らず消えていた）。設置の集計に数える
持ち上げる赤を長押し（壊すのと同じ時間）狙ったブロックを状態ごと外して持つ（向き・チェストの中身）。持っているあいだ、その物は所持品にも世界にも無い。2マスのベッドは両方外してベッド1つとして持つ
ここに置く紫をタップ（持ち上げ中）狙った所へ、持ち上げたときの向きとチェストの中身のまま置く。ベッドだけは2マスなので今の向きで置く。置ける場所の条件は通常の設置と同じ。置けなければ持ち上げたまま
回す回すボタンをタップ狙った物を置いたまま 90 度回す（保存している向き +1）。チェストの中身は位置で記録しているのでそのまま残る。船は3マスの胴が桟橋・岸・ほかの船にかからない向きにだけ回し、かかる向きは飛ばす（2026-10-02 修正・CF-027）

長押しの時間

置き換え・持ち上げは、狙ったブロックを今の道具で壊す時間（miningDuration）と同じ。例: 土・砂 0.3 秒、素手の石 5 秒。クリエイティブは 0.05 秒。進捗の扱い（別のブロックへ狙いを移したときの退避・猶予）も壊すと同じ。

回せる物

階段（すべての階段）・チェスト・かまど・作業台・石切台・船（Block.isRotatable）。2マスのベッドは頭側のマスが動くので回さない（持ち上げて置き直す）。

対象外の物

物持ち上げ・置き換えの対象理由
空気・水・溶岩対象外掴めない
小麦（育ち中・実った）対象外成長の状態を持ち運べない（壊して植え直す）
扉（下・上のマス）対象外2マスの高さ。壊して置き直す（2026-10-04、CF40）。回すこともしない
染料の植物の若芽（いちご・ひまわり・藍の種）対象外小麦と同じく成長の状態を持ち運べない（CF29）
実った染料の植物（野いちご・ひまわり・藍）対象外摘んで実と種にする物。所持品に入ると置けず何にも使えない物になっていた（build 22 のパス5）
船対象外（回すのは可）水の上にしか置けない。陸へ置けないよう、壊して拾う（CF31）
リフトの乗り場対象外（壊すのも不可）最初から置いてある物。動かすとリフトが動かなくなる（CF32）
世界の底対象外壊せない段

置き換えに使えない建材（選んでいる側）: ベッド・小麦・船・植物と種（下の土が要るため通常の置き方で置く）、およびもともと置けない物。

できない理由の知らせ

長押しを始められないときは、押しているあいだに1回だけ知らせる。この押し続けで持ち上げ・置き換えを終えた直後の所では知らせない（終えた直後から断る知らせが出て、うまくいったのに断られたように見えたため。CF-014。持ち上げのあとは離すまで、置き換えのあとはそのマスの上だけ止める）。

持ち上げ中の物とチェストの中身

場面扱い
持ち上げ中所持品にも世界にも無い。チェストは中身ごと持つ（チェストの記録は消す。報酬チェストの台座＝レンガの上は空の記録を残して中身の再生成を防ぐ）
ワールドを出る・アプリが裏へ回る（非アクティブになる）保存の前に、持ち上げ中の物と中身を所持品へ戻す（戻さずに終えると消えるため）
編集モードをオフにする所持品へ戻す
置くのと所持品へ戻すのが重なった取り出しはロックで一方だけが受け取る（takeCarried）ので、置いたうえに所持品にも戻る二重取りは起きない
置き換えでチェストを差し替えた空のチェストだけ差し替えられる（所持品へ戻す。クリエイティブは戻さない）。中身の入ったチェストは断る（CF-028）

取り消しとの関係

  • 取り消し（直前の1手を戻す、深さ1）は、通常の設置・破壊だけが対象
  • 持ち上げ・置き換え・ここに置く・回すをすると、取り消しの履歴を空にする（それより前の1手を戻せないようにする）。直後に取り消しを押すと「戻せる操作がありません」
  • リフトに乗っているあいだは、取り消しも含めて編集の操作を受けない（乗り物）

ビジネスルール

  • 置き換え・持ち上げは壊すのと同じ時間がかかる（クリエイティブは一瞬）。回すは一瞬
  • 持ち上げた物は向き・チェストの中身を保ったまま置き直す。物が失われる経路を作らない（オフ・退出・裏へ回る、いずれも所持品へ）
  • 置ける場所の条件は通常の設置と同じ（ランタンの支え・植物の土・体との重なり・足場積み）
  • 成長の状態を持つ物・水の上にしか置けない物・最初から置いてある物は持ち上げ・置き換えの対象にしない
  • 編集の操作は取り消しの対象にせず、行うと履歴を空にする

発生条件対応

実装メモ

  • 長押しの種類・できない理由: GameSceneView.swift（currentHoldAction・holdBlockedReason・isQuietAfterFinishing）
  • 操作本体: GameSceneView.swift（liftBlock・replaceBlock・placeCarried・rotateAimed・detachBlock・placeEditedBlock）
  • 状態: GameInput.swift（isEditMode・setReplacing・setCarried・takeCarried・returnCarriedToInventory・aimedRotatable）
  • 対象の判定: GameRules.swift（Block.isEditable・isRotatable・canReplaceInto）
  • 画面: GameControls.swift（EditModeButton・RotateButton・EditModeHint・置き換えボタン）
  • 船は回す対象だが、回したあとに胴が桟橋・岸にかかるかは確かめていない（乗り物参照）
