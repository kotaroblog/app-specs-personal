地形生成

ワールドの種類（群島／島／無限）ごとの地形と、洞窟・木・最初から置いてある物のチャンク単位の生成

機能ID: VG-FEAT-TERRAIN

概要

ワールドは作成時に選ぶ ワールドの種類（WorldKind）で地形の作り方が変わる。新しいワールドの既定は群島（島を並べ、船で渡る設計した地図）。ほかに島（海に囲まれた1つの島）と無限（どこまでも続く、以前からの世界）を選べる。

どの種類も WorldRecord のシード値から GameplayKit の GKNoise（GKPerlinNoiseSource ベース）2枚（起伏・地域）をサンプルし、列ごとの高さ・地域（biomeT）・道（pathT）・目印（IslandFeature）を決める。群島は島ごとに設計した式（ArchipelagoTerrain）、島は通常の生成を島の形へ変換する式（IslandTerrain）で列を決め、ノイズは揺らぎにだけ使う。チャンクは 16×64×16 ブロック単位で管理し、プレイヤー中心に viewRadius チャンク（標準5・高画質6）を動的にロード・アンロードする。メッシュ生成は Greedy Meshing で頂点数を削減する。

ワールドの種類（WorldKind）

種類rawValue作成画面の説明スポーン地点

どこまでも続くinfiniteどこまでも続く世界（以前と同じ）従来どおり
  • WorldRecord.worldKindRaw: String? を既定値 nil つきで追加（軽量マイグレーション）。nil・読めない値は 無限 として扱う＝この項目が無い既存ワールドはすべて無限のまま
  • 種類は作成時に setKind で1回だけ決める。新しい群島は archipelagoRevision を最新（現在1）にして作る（入れ直し不要）
  • 生成・目印の置き場所・地図の式はすべて同じ TerrainGenerator（kind を持つ）を通るので、どれも同じ地形を見る

共通の値

  • チャンクサイズは 16（X）× 64（Y）× 16（Z）ブロック固定。高さは 1〜63 にクランプ
  • viewRadius はチャンク単位で標準5・高画質6（正方形範囲。標準は11×11=121チャンク、高画質は13×13=169チャンク）
  • 起伏ノイズ: GKPerlinNoiseSource（frequency 0.025, octaveCount 5, persistence 0.5, lacunarity 2.0）。地域ノイズ: 別シード（seed+31337）の GKPerlinNoiseSource（frequency 0.004 ≒ 250ブロック周期, octaveCount 2）
  • ノイズはワールド全体で1枚の 1024×1024 共有マップをワールド座標でサンプルする（±512ブロック程度が連続・範囲外は1024周期で繰り返し）
  • 海面 seaLevel=9。列の高さが9未満なら、高さ〜8 を水で埋める。島・群島の海底は 4
  • 地域の分類（biomeT）: <0.10=砂漠、>0.75=雪原、それ以外=平原
  • 地表: 道（pathT>0.55 かつ高さ≥9）は土、高さ<11 は砂（浜。雪山の島の陸は除く）、砂漠は表面5段が砂、雪原は頂上が雪で下4段が土、平原は頂上が草（biomeT>0.6 かつ y>42 は雪）で下4段が土、その下は石

無限の世界（infinite）

  • 低地: 砂漠 8〜12（ほぼ平ら）、平原 8〜16（一部だけ海面を割り浅い池になる）
  • 山岳: 18 + terrainT1.25×32（18〜50）。重み smoothstep((biomeT−0.66)/0.24) で低地と混ぜ、biomeT がかなり高い地域だけを遠景の目印の山にする
  • 自然道: 96ブロック間隔の縦横の網を正弦波で蛇行させ、幅3〜5ブロックだけ pathT を返す。道の上は周囲より平らにし、海面より上へ保つ
  • 地上の目印（巨木・岩の柱・坑道と報酬チェスト）を置く

群島（archipelago。CF31・CF32）

1つの地図に島を並べ、海を船で渡る（本人決定 2026-09-30）。設計は docs/群島と雪山の島_設計案_2026-09-30.md。列の高さ・地域・目印は島ごとの式で決め、ノイズは海岸線や高さの揺らぎにだけ使う。地上の目印（巨木・岩の柱・坑道）はばらまかない。今ある島は本島と北の雪山の島。南（火山）・西（資源の島）は後の版。

要素実装の値
世界の端x −675〜325・z −700〜700（島から200ブロックほど先）。泳いでも船でもこの外へは出られない（プレイヤーの水平位置をこの範囲にクランプ）。火山・資源の島の分まで先に取ってある
海どこも海底4・海面9。島のまわりは岸から1ブロックごとに 0.3 深くなる。どの島の範囲にも入らない列は海底4
群島全体の地図中心 (−150, 0)・1024ブロック四方を 256 ピクセル（1ピクセル4ブロック）で、設計した地形の式から一度だけ描く（建てた物・読み込んだチャンクは入らない）。地図のいちばん広い段からさらに縮小すると表示。桟橋と山小屋の方角・距離を出す

航路標と航路岩

  • 本島の北の桟橋の先端と雪山の桟橋の先端を結ぶ線の、進む向きの右（北へ進むので東）へ4ブロック。40ブロックごと（終点の20手前まで）に石レンガの柱（y4〜10）と、その上 y11 にランタン。霧（晴れの昼 56〜76）の中でも次の柱が見える間隔
  • 線の真ん中の西12ブロックに航路岩（7×7 の石の山。頂は海面+2）
  • どちらも「水・空気のマスだけ置き換える」
  • 本島の北の桟橋から雪山の島まで約215ブロック（船 8 m/s で約27秒）

最初から置いてある物（IslandStructureBlock）

  • 桟橋・船着き場（島）、群島では桟橋・船・航路標と航路岩・山小屋・橋・凍った滝・山頂のケルン・リフト。1ブロックごとに位置・ブロック・向き（階段の高い側など）・「水と空気だけ置き換えるか」を持つ
  • 海岸線から初回に一度だけ求めてキャッシュし、チャンクごとに分けて持つ。生成時はそのチャンクに入る分だけを、木・草花より後に置く（通り道の上は空気で空ける）
  • 群島の船: 各桟橋の先端の階段の3段目の横（床から2列外）に、へさきを沖へ向けて浮かべる（3マスの船の前後も海のときだけ）。ここが係留の場所（降りると近くならここへ寄せる）
  • まとまりごとの外接矩形の近くには木・草花を生やさない（広葉樹は2ブロック、針葉樹は葉が広がるので5ブロック）

既存のワールドへの入れ直し（ArchipelagoMigration）

保存済みのチャンクは生成し直さない（プレイヤーが手を入れたチャンクだけが保存される）。そのため「最初から置いてある物」を改訂すると、すでに行って手を入れた場所には新しい物が入らない。群島では改訂番号 WorldRecord.archipelagoRevision（Int・既定0。軽量マイグレーション）を持ち、ワールドを開くときに現在の番号（currentRevision）より古ければ一度だけ入れ直して番号を上げる。

改訂入れ直す物決まり（プレイヤーが置いた物は消さない）
1（build 24）凍った滝水のマスだけ氷に置き換える
1（build 24）崖のリフト地形のままのマス（空気・草・土・石・砂・雪・水・溶岩・氷・原木・葉・鉱石・草花・染料の植物）だけ置き換える
2（build 28）鉱石を増やした（CF39）保存済みの全チャンクの石のうち、元の地表より下で、まわり6面がふさがっていて（空気・水に面していない）、生成したときに洞窟でなかった所だけ鉱石にする（置いた石・地下室の壁・埋めた洞窟は変えない）。全チャンクを1回で読み、変えたものだけ書き換えて最後に1回保存する（WorldStore.rewriteSavedChunks。所要時間をログに出す）
  • 対象は改訂した物が入るチャンクのうち保存済みのものだけ。保存されていないチャンクは次に生成するとき最新の物で作られるので触らない
  • 新しく作る群島は最初から最新の番号で作る

海藻と魚（見るだけの飾り・2026-10-03〜、CF38）

本人（10-03）「海のところは海藻とか魚とかが表現できたらもっといい」→ 案A（見るだけ・取れない）。ブロックにはしないので、泳ぐ・船・掘る・保存に影響せず、作ったワールドにもそのまま出る（入れ直し不要）。

要素仕様
海藻（Seaweed）深さ2〜7の水の列の底（砂・土・石・草・雪。置いた物の上には生やさない）に、6列に1つ前後、高さ1〜3マス（水面に出ない）。交差した2枚の板を時間で揺らす（根元は動かない）。チャンクの形を作り直すたびに、そのチャンクの水の列から決め直す（チャンクのノードの子 seaweed）
魚の群れ（FishSchools）プレイヤーから10〜26m の深さ3以上の海に、最大4群れ（6匹ずつ・橙/黄/白）。中心が水の中（上も水）を1.4m/s で進み、1.2m 先が水でなければ向きを変える。4.5m より近づくと2秒逃げる（4m/s）。44m 離れた群れは消す。🔴 長さ 0.26 では6m先でも気づかないほど小さかったので 0.42 にした
UI テストDEBUG の --ui-testing-fish-ahead で目の前（5m 先）に群れを出して写真で確かめる

木・植生

場所植生条件
平原（無限・島）広葉樹陸地の列のうち約1/30（treeHash % 30 == 0）。島の林は約1/7、石切り場には植えない
群島の本島広葉樹林の中は約1/7、林の外は約1/48。城山の頂・スポーン地点のまわり（整地）には植えない
平原背の高い草・花・キノコ木も染料の植物も置かなかった陸地の列に、専用ハッシュで約1/9・1/13・1/40（地表が grass の場合のみ）
平原・砂漠の水辺染料の植物野いちご・ひまわり（高さ30以上の草地）・藍の草（水辺の砂）。詳細はクラフト側の仕様を参照
砂漠サボテン陸地列のうち約1/18
雪山の島の森針葉樹約1/9の列
雪山の島のほかの雪の陸針葉樹約1/54の列（まばら）。整地・凍った湖・浜（高さ11未満）には生やさない
雪原（無限）なし植生を配置しない
  • 広葉樹: 幹（原木）4段、葉は幹の上部に3段＋頂上1つ。基部が air でない列（目印の構造物・報酬チェスト等）には植えない
  • 針葉樹: 幹（針葉樹の原木）6〜8段、葉は上から半径1・2を交互に広げた円すい（角を落とす）。葉が2マス広がるので、周り2列の木もこのチャンクに入る分だけ置く（どのチャンクからも同じ木になり、境目で切れない）。建設地・桟橋・山小屋など最初から置いてある物のまとまりから5ブロック以内には生やさない
  • 幹を切ると葉が少しずつ消える（LeafDecay・CF18）: 原木（広葉樹・針葉樹）を壊したとき、その周り各軸 ±5 の葉を調べ、葉だけを伝って幹へ10歩以内に届かない葉を、0.5〜6.0秒にばらして消す（消す直前にもう一度つながりを確かめる）。自分で置いた葉を消さないよう、調べるのは幹を壊したときのその周りだけ

凍った湖の張り直し（2026-10-02・本人 10-01 決定）

  • 夜明け（日付の変わり目・ベッドで眠って朝にしたとき）に、湖の列（地形が凍った湖の列＝表面が氷になる列）の氷の段（y12）のうち、空気か水のマス（掘った穴）だけを氷に戻す。プレイヤーが置いた物は上書きしない（FrozenLake.cellsToRefreeze）
  • プレイヤーが湖の中（足が氷の面 y13 より下で、湖の列かその隣の上）にいる夜明けは張り直さず、次の夜明けへ回す（氷の下に閉じ込めない）。氷の上に立っているだけなら張り直す
  • 湖を読み込んでいない間に夜明けが来たら WorldRecord.lakeRefreezePending を立て、次に湖のチャンクがすべて読み込まれたとき（プレイヤーが湖の中にいなければ）張り直して下ろす
  • 湖の列は地形の式で一度だけ求めて覚えておく（TerrainGenerator.frozenLakeColumns）。群島では最初の読み込みのあいだに先に求める（初めての夜明けに張り直しと同じコマで求めると引っかかりうるため）。群島以外の世界では何もしない。書き換えはチャンクごとにまとめて行い（ChunkManager.setBlocks）、変えたチャンクは保存される

世界の底と、世界の外へ出たとき（CF-003）

  • 高さ0（WorldFloor.unbreakableY）は壊せない。地形は高さ0から地表まで必ず固体で埋まる（地表の最低は海底の4、洞窟は高さ5から上、溶岩は0〜3の空気だけ）ので底は抜けない
  • 足元が高さ −4 より下になったら世界の外に出たとみなし、落ちた列の周り3×3で一番高い地表へ戻す（無ければスポーン地点）。その3×3の高さ0が空気・水なら石でふさぐ。「世界の外に出たので、地上へ戻しました」と表示

実装メモ

  • TerrainGenerator は @unchecked Sendable。GKNoise の遅延生成と、最初から置いてある物のキャッシュの読み書きは NSLock（noiseLock）で直列化する。🔴 キャッシュを作るときに stageNoise を呼ぶので、ロックを持ったまま呼ばない（NSLock は再入できない）
  • 種類ごとの列の式は TerrainGenerator.columnData の1か所で分岐する（群島は ArchipelagoTerrain.column、島は IslandTerrain.zone/biomeT/pathT/height）。地図の未読み込み部分の色（generatedTopBlock）も同じ列から決めるので、生成の地表の決め方を変えたら合わせる
  • 地形の主なコード: TerrainGenerator.swift（ノイズ・種類の分岐）、IslandTerrain.swift（WorldKind・島・桟橋）、ArchipelagoTerrain.swift（群島・最初から置いてある物・入れ直し）、Chunk.swift の generate（ブロック配置・洞窟・木）、GameRules.swift（LeafDecay・WorldFloor）
  • Greedy Meshing は ChunkMesher.buildGeometry に集約。1チャンクにつき opaque/water 最大2枚の SCNGeometry に結合する
  • メッシュ生成はバックグラウンドキュー（meshQueue）で非同期実行し、完成分を applyPendingGeometries がレンダーループから毎フレーム引き取って SCNNode に適用する
  • 植生（花・草・キノコ・松明）は greedy mesh結合済みジオメトリとは別の独立ノードとして管理し、種別ごとにジオメトリ/マテリアルを共有する（高密度配置によるノード数爆発を防ぐため）
  • チャンクロード時の装飾ブロック走査は scanChunkDecorations(in:) の1パスに集約する。松明・植生・若芽は同一セルに同居しない排他的なブロックのため、1回の走査で switch 振り分けできる（種別ごとに 16×64×16 の全走査を独立に回さない）
  • 装飾走査のループ順は y→z→x とし、x を最内に置く。Chunk.blocks は y * sizeX * sizeZ + z * sizeX + x の並びのため、この順序が連続アクセスになる
  • 装飾ノードは decorationKeysByChunk（チャンク座標 → ワールド座標キー集合）で逆引きできるようにし、アンロード時は該当チャンク分のキーだけを引いて破棄する（松明ノード辞書・植生ノード辞書の全キー走査はしない）。松明と植生は同居しないためインデックス1本で両方を引ける
