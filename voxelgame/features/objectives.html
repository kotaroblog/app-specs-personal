目標ガイド

「素材を集めて建てる」までを最短で通すための6段階ガイド

機能ID: VG-FEAT-OBJECTIVES

概要

ゲームプレイ画面の上部に「いま何をすればよいか」を1件だけ表示する進行ガイド。2026-09-16 の建築特化への転換で、サバイバル型の16段階（終着点はダイヤの剣と討伐）から建築特化の6段階へ作り直した。終着点は「実際に積んだ量」（設置ブロック数100個）で、危険を越えたことではなく不可逆な投資（量と時間）が目に見えることを達成感の源泉に置く設計に合わせている。

関連画面

6段階の定義

順タイトル達成条件進捗表示操作ヒント / 場所ヒント
1木を集める木を5個所持所持数 / 5木に近づいて画面を押し続ける（赤い「壊す」でも可）／ 木のある平原・森へ
2石を集める石を10個所持所持数 / 10足元を数マス掘り、灰色の石を「壊す」／ 地面を掘り下げる
3石のツルハシを作るstonePickaxe が解放済み10 / 10（固定）左上「クラフト」→石のツルハシ
4かまどを作るかまど所持 or 設置履歴あり石の所持数 / 8石を8集め「クラフト」→かまど→地面に設置
5ガラスを作るガラス精錬履歴あり（hasSmeltedGlass）なし（バーを出さない）かまどに照準を合わせてタップ→砂を精錬。窓や明かり取りに使える／ 砂は砂漠・浜辺で採れる
6自由に建てる累計設置ブロック数 ≥ 100（objectiveBuildTarget）累計設置数 / 100集めた材料で好きなものを建てる。壊せば材料は戻る／ 見晴らしのいい場所へ
100 は「小屋が1軒建つ」量の目安（壁1面 5×3＝15 ブロック × 四方＋屋根・床で 100 前後）。🔴 M1（2026-10末）で実際に建てて実測し、快く終えられる量に調整する。

処理フロー

stateDiagram-v2 [*] --> 目標1: 石のツルハシ未解放・木<5・石<10 目標1 --> 目標2: 木を5個集めた（または石を掘り始めた） 目標2 --> 目標3: 石を10個集めた 目標3 --> 目標4: 石のツルハシを解放 目標4 --> 目標5: かまどを所持または設置 目標5 --> 目標6: 砂をガラスへ精錬 目標6 --> 達成: 累計設置 100 個 達成 --> [*]: ガイド非表示（hasCompletedAllObjectives）

ビジネスルール

  • 判定は「ツール解放状態」と「永続フラグ（設置・精錬の履歴）」を第一キーにした if の連なりで行い、厳密なステートマシンにはしない。採掘中に素材を持ち直す等の揺り戻しは許容する
  • かまど（設置で所持数0に戻る）とガラス（精錬後に消費し得る）は所持数だと巻き戻るため、hasPlacedFurnace / hasSmeltedGlass の履歴フラグで判定する
  • 表示は常に1件。全6段階を達成すると nil になりガイド自体が消える（hasCompletedAllObjectives で達成トーストは一度だけ）
  • クリエイティブモード中は非表示（目標はサバイバル側の導線）
  • 達成チャイムは order が増えたときだけ鳴らす（揺り戻しでは鳴らさない）
  • 達成時は上部中央に GoalBanner（「目標達成！ 次は『○○』」＋操作ヒント）を数秒表示する
  • レビュー依頼は目標6へ進んだ瞬間に端末ごと一度だけ要求する（チャイム・バナーと重ならないよう約2秒置いてから。実際に表示するかは StoreKit 側が判断する）。ワールド再開時の初回表示（直前の order が nil）は達成ではないため出さない

表示形式

状態表示
展開（既定）アイコン＋タイトル＋進捗数＋進捗バー（136×6pt）＋操作ヒント＋場所ヒント
折りたたみアイコン＋進捗数のみの小チップ（情報量を最小化）
一時展開目標が進んだ直後に6秒だけ自動展開。畳んでいる人にも「次に何をどうするか」を一度は見せる。ユーザーの畳んだ設定自体は書き換えない
  • 既定は展開（初見ではアイコンだけでは何をすべきか読めないため）。畳んだ選択は UserDefaults キー voxel_objectiveExpanded に記憶する
  • 一時展開中に折りたたみ操作をした場合は、まず一時展開だけを解除する（見えている状態と操作結果を一致させる）
  • 一時展開には世代トークンを持たせ、目標が連続で進んだとき古い自動折りたたみが新しい展開を消さないようにする

横向きでの扱いとメニューの「現在の目標」

項目仕様
横向き（縦が compact）画面上の目標ガイドは出さない（2026-09-19）。展開時に約90ptを占め、残すと操作クラスタが画面外へ押し出されて移動できなくなったため
メニューのカードメニュー（ポーズ）の先頭に「現在の目標」カード（ObjectiveMenuCard）を常に出す（2026-09-24）。縦向き・横向きを問わず、アイコン・タイトル・進捗数（例 37/100）・進捗バー・操作ヒント・場所ヒントを、折りたたみ状態に関係なく全部表示する
目標が無いときクリエイティブ中（メニューへ目標を渡さない）と全6段階の達成後は「現在、表示する目標はありません。自由に建築できます。」
読み上げカード全体を1要素にまとめ「現在の目標、○○、進捗、操作ヒント、場所ヒント」の順で読む。UIテスト用の識別子は currentObjectiveMenu

横向きで目標ガイドを消したままだと、横向きで遊ぶ人は次に何をすればよいかを確かめる手段が無かった。常時表示のコントロールは増やさず、既存のメニューに確認先を置いた。

外部連携

連携先用途備考
GameInput.inventory / unlockedTools目標1〜4の進捗判定所持数・解放ツールを参照するのみ
WorldRecord.hasPlacedFurnace / hasSmeltedGlass目標4・5の巻き戻り防止一度 true になったら戻らない
作品カード（VG-FEAT-WORKCARD）目標6の進捗＝累計設置ブロック数権威は PlacementTally。ガイドはキャッシュ値 tally.total を読むだけ
StoreKit（requestReview）目標6到達時のレビュー依頼端末ごと一度だけ要求する

エラー処理

発生条件対応
素材を消費して所持数が条件未満に戻る揺り戻しとして許容し、達成チャイムは鳴らさない（order 増加時のみ発火）
目標が連続で2段進む一時展開の世代トークンで後発の展開を優先する

実装メモ

  • 目標の算出は ContentView の currentObjective（computed property）。毎フレームではなく SwiftUI の再評価タイミングで計算される
  • しきい値 objectiveBuildTarget = 100 は GameObjectives.swift のトップレベル定数で一元管理する
  • ステージ（舞台とお題のワールド。CF13）でも同じ6段階を出す（ステージ専用の分岐は無い。ステージではクリエイティブにできないので、ガイドは常に対象になる）
  • 🔴 P3（2027-01〜02）で「最初の設計図」を5段目へ差し込み、6段目を設計図の完成に置き換える計画がコード側コメントに記載されている（現時点では未実装）
